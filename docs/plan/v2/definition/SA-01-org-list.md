# SA-01 · 기관 목록

## 1. 한 줄

**기관을 만들고 상태를 본다.** 슈퍼어드민의 실질 홈.

## 2. 진입 · 이탈

로그인 직후 · 좌측 네비(항목 하나) → 행 클릭 → **SA-02**.

## 3. 뷰

```
기관  총 14개                                    [+ 기관 생성]
  검색 · 상태 ▾(활성·정지) · 정렬 ▾                     (툴바 전부 좌)
──────────────────────────────────────────────────────────────
  그린컴퍼니 부트캠프   활성   기수 3   교육생 480   ₩1,240,000
  파이널랩             활성   기수 1   교육생 120   ⚠ 오퍼레이터 미배정
  블루아카데미         정지   기수 0   교육생 0     —
──────────────────────────────────────────────────────────────
  1–14 / 14                        [< 1 >]
```

**`오퍼레이터 미배정`이 이 목록의 핵심 신호다.** 기관을 만들어도 오퍼레이터가 없으면
아무것도 시작되지 않는다.

### 생성 모달

기관명 · 도메인만. 확정 시 `활성` + **오퍼레이터 미배정** 상태로 목록에 들어온다.

## 4. 데이터

기관명 · 상태 · 기수 수 · 교육생 수 · 이번 달 비용 · 오퍼레이터 배정 여부.

## 5. 액션

생성 · 행 클릭 · 필터.

## 6. 상태 — 왜 그렇게 정했나

> **케이스 표는 목업에 있다** — [`superadmin/console.html#cases-sa01`](../wireframe/superadmin/console.html#cases-sa01).
> 표는 목업 한 곳에만 두고, 이 절은 표로 설명이 안 되는 판단만 적는다.

### 중복 기관명은 제출 전에 막는다

생성 모달이 *"입력 중 실시간 중복 확인"*이라고 써 놓고 **✗ 화면이 없었다.** 눌러 보고 실패하면 그때까지 입력한 것이 헛일이 된다 — **입력 중에 알려주고 제출 버튼을 잠근다.**

### 정지 기관을 목록에서 숨기지 않는다

숨기면 *"우리 기관이 안 보인다"*는 문의가 왔을 때 **정지된 것인지 지워진 것인지 화면으로 확인할 방법이 없다.** 행을 흐리고 배지를 단다.

### 생성 실패는 아무것도 남기지 않는다

`활성 · 오퍼레이터 미배정` 상태로 목록에 들어오는 것이 정상 흐름이라, **반쯤 만들어진 기관**이 목록에 있으면 그것이 정상인지 실패인지 구분되지 않는다.
