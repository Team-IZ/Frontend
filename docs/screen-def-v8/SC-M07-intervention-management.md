# SC-M07 · 개입 관리

> 소스: 기능명세서 v8 INTV-04(시그널 기반 개입 생성) + INTV-05(상태 전이) + INTV-06(효과 판정) + INTV-07(취약 축 export) + INTV-08(상담 기록). **명세만 보고 재설계**(옛 버전 골격 미참조 · D35).
> 배치: P0(INTV-04)/P1(05·06)/P2(07·08). 매니저 앱 셸 공유.

## 2. 목적 & UX 설계 근거

- **이 화면의 핵심 질문 = "무슨 개입을 하고 있고, 뭐가 효과 있었나".** 후자(효과 판정 INTV-06·중요도 상)가 폐루프를 닫고 추천 성능(DASH-07)으로 피드백되는 제품 차별점 → **효과를 1급 컬럼으로 앞세운 정보-우선 테이블**을 채택(칸반은 효과를 완료 열에 숨김·건수 modest라 파이프라인 과함).
- **효과 판정 전면화.** **완료 개입만** 회복/부분회복/미회복/악화/판정대기를 컬럼으로(대기·진행은 효과 없음=—). 회복=Δ≥1 AND post≥3(B7). 완료됐으나 후속 회차 전이면 판정대기(회복 판정 금지). **악화(개입 후 더 나빠짐)는 최우선**(정렬·색·상단 알림, INTV-06 case7 우선 재알림). 효과에 **대상 축 명시**("설계논리 회복").
- **⚠️ 팀 개입 효과 판정 = 명세 공백(보완 제안).** INTV-06은 개인 축 pre/post 기반인데 **팀조정 개입은 개인 축으로 판정하면 안 됨** — 팀 지표(분산·설명력 갭 개선) 기준이어야. 백엔드: 팀 개입 효과 판정 로직 별도 정의 필요(v1은 팀 개입 효과 "판정대기/수동" 처리).
- **방치 방지.** "만들어놓고 방치"가 실패모드 → **경과일 컬럼** + 오래된 대기·진행은 강조 + 상단 **"방치 N건"** 알림.
- **생성 = 근거 먼저.** 시그널-개입 연결 필수(INTV-04). 생성 패널이 근거 시그널(유형·근거 축·회차·심각도)을 폼보다 먼저 표시, 근거 없으면 차단. 중복 활성 개입은 기존 건 안내(case 5).
- **자동확정 금지.** 생성·상태 전이는 매니저 액션으로만(GOV-02).
- **진입 통합(D31).** M07·M06·M01·M04 어디서 열든 같은 생성 패널, 프리필만 다름.

## 3. 정보 구조 & 레이아웃 (매니저 앱 셸 · 데스크톱)

**헤더:** "개입 관리" + [개입 생성].
**(조건부) 방치 알림:** "N건 방치 — 오래 상태 변화 없음" (있을 때만).
**필터·툴바(한 줄):** 상태(전체/대기/진행/완료) · 유형 · 효과 · **담당(내 담당/전체)** · **정렬(우선순위=악화·방치 먼저 / 경과 / 상태)** · [우측] 건수.
**빈 상태:** 개입 0건이면 "등록된 개입이 없습니다. 위험 시그널에서 개입을 만드세요" + [개입 생성].
**개입 테이블:**
- 컬럼: **대상**(학생/팀·반) · **유형**(면담/멘토링/보강/팀조정/모니터링) · **근거 시그널**(위험·불균형·팀 이상, 서술형) · **담당** · **상태** · **경과** · **효과**
- 상태 = 배지 + 인라인 [상태 전환]. 효과 = 완료 건만(대기·진행은 —).
- 행 클릭 → **상세 패널**(우측 · D45). **보여줄 것(우선순위·크기):** ①**상태·다음 행동**(대기→진행→완료 스텝 + 전이 버튼, 최상단 크게) ②**근거 시그널**(축·회차·심각도 + SC-M04 링크) ③**효과 판정**(완료면 회복/부분/미회복/악화+전후·Δ, 미완료면 "완료 후 판정" 약하게) ④**실행 초안·제안조치**(INTV-02) ⑤**활동 기록**(면담·관찰 로그 + [＋ 기록 추가], M06과 같은 레코드) ⑥**관리 정보**(하단·약하게: 담당자[변경]·생성자·시각·상태 이력). **기능:** 상태 전이 · 활동 기록 추가 · **담당자 변경**(위임·인수인계) · 취약축 export · 교육생 상세 이동. **하드 삭제 제외**(명세에 없음, 상태로만 관리·GOV-02).
**생성 흐름(D37·D40):** 헤더 [개입 생성] → **STEP1 시그널 선택**(활성 시그널 목록에서 대상 고름, 이미 개입 있는 건 제외) → **STEP2 폼**(근거 시그널 확정·읽기전용 → 유형 radio 5종 고정+**추천 배지 INTV-01** · 담당자 · **실행 초안 INTV-02 자동 생성·편집**). M01·M04·M06 시그널의 [개입 생성]은 대상 프리필이라 STEP1 건너뜀. **백지 폼이 아니라 제안(추천+초안) 검토·확정**(D40). 근거 없는 개입 구조 차단.
**취약 축 export(INTV-07):** 별도 화면 아님. **다이얼로그**(포함 항목 확인 · 원문·근거 "포함 불가" 명시) + **문서 구성 미리보기**(①요약 ②취약 축 ③취약 기술영역 ④확인 필요 ⑤개입 이력·효과, D41) → PDF 다운로드 / 만료형 공유 링크.
**역할 분리(D38):** 개입 *생성*=시그널 경로(한 경로) / *추적*=M07 / 준비·기록=M06. 면담은 개입 한 유형, 두 화면은 같은 개입을 추적 vs 준비·기록으로 볼 뿐.

반응형: 웹 기준. 페이지네이션 하단 중앙(D22).
