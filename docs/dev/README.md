## 화면별 진행 상황

**그 화면을 이어서 만들 때 이 파일부터 읽는다.** 무엇을 어디까지 했고, 왜 그렇게 했고, 무엇이 남았는지.

- [**OP-01 대시보드**](op-01-dashboard.md) — 목업 대조로 잡은 기획 결함 3건 · 반 비교 기준선 · 파이프라인 단위 · 렌더에서만 잡힌 것들
- [**OP-02 분석**](op-02-analysis.md) — 탭마다 갈라 쓰는 색 체계 · 계층 전환 · 도달 단계 계단 · 화면이 정한 값 1건
- [**OP-03 · OP-04 프로젝트**](op-projects-progress.md) — 무엇을 어디까지 했고 왜 그렇게 했나 · 남은 것
- [**OP-06 운영 관리**](op-06-admin.md) — 매니저 배정 모델(1:N) · 기수 스코프 · 비용 월별·매트릭스 · 두 번 틀린 자리
