## 0. 이 화면의 성격

OP-03과 짝인데 **성질이 반대다.**

| | OP-03 목록 | OP-04 상세 |
|---|---|---|
| 조회 단위 | 조건이 바뀌면 같은 것의 다른 조각 | **다른 회차 = 다른 것** — `placeholderData`를 쓰면 안 된다 |
| 조회 수 | 셋(고정) | **조건부 다섯** — 탭·모달이 열릴 때만 |
| 쓰기 | 생성 1종 | **5종**(개념 확정 · 교안 변경 · 요구사항 · 일정 · 삭제) |
| 실패 단위 | 목록만 | 상세가 실패하면 **화면 전체**, 탭 조회는 그 탭만 |
| 주소 | 조건이 쿼리스트링 | **탭이 경로에** (`/projects/:id/:tab`) — OP-01이 특정 탭으로 딥링크한다 |

여기서 처음 나오는 축이 셋이다.

1. **쓰기가 다섯이고 전부 되돌리기 어렵다.** 개념 확정은 서버가 409로 재확정을 막고,
   삭제는 이름·순번을 점유한 채 남는다(9차 §10).
2. **조회가 화면 상태에 달려 있다.** 탭을 열어야 부르고, 모달을 열어야 부른다 —
   `enabled`가 다섯 군데다. 「기다리는 중」 판정이 그만큼 자주 틀릴 수 있다.
3. **한 화면이 두 기수를 섞을 수 있다.** 조회 기준이 「지금 보는 기수」가 아니라
   「응답이 알려준 기수」여야 한다(과거에 실제로 섞였다 — 코드 주석에 남아 있다).

```
useProjectDetail(id)                              항상
useProjectStatus(id, 현황탭 && 개념 3건)           탭 조건부
useProjectList({cohortId, sort:'DUE'}, 개요탭 && 마감있음)   형제 회차(다음 마감)
useConceptCandidates(id, 개념모달 열림)
useLinkableCurricula(cohortId, 개념모달 || 교안모달)
useCohortScope(cohortId, 일정모달 열림)
```

## 2. 실측

측정 — 9기 · 회차 7개. 상태별로 하나씩 골라 돌렸다(종료 1차 · 준비됨 투투투 · 진행 중 6차).

### 2-0. 진입 타임라인 (목록 → 6차)

```
0ms      클릭
85ms     GET /projects/{id}          → 200 (2597ms)
2716ms   GET /cohorts/{id}/projects  → 200 (1713ms)   형제 회차(다음 마감)
2700ms   머리·탭·본문이 한꺼번에 생김
```

CLS **0** — 밀림은 없다. 다만 **2.7초 동안 화면에 아무 구조가 없다**(스피너 하나).
무엇을 여는 중인지도 안 보인다.

### 2-1. ⚠ 없는 회차를 열면 **영원히 로딩** — 서버가 404를 안 준다

| 브라우저 | curl (70초 상한) |
|---|---|
| 40초까지 스피너, 본문 백지, 요청은 나감(1+재시도 1) | **HTTP 000 · 70초 타임아웃** |

```
00000000-0000-0000-0000-000000000000  (형식 O · 없음)  → 무응답
073c7e8b-…                            (존재)           → 200 · 2.10초
abc                                   (형식 X)         → 400 · 0.70초
```

**형식이 틀린 값은 0.7초에 400으로 정확히 온다.** 존재하지 않는 값만 무응답이다 —
OP-03의 `/sections`와 **같은 증상**이다(18차 R1·R7).

전역 재시도(5xx·네트워크 3회)도 여기서는 안 걸린다 — 실패로 판정될 일이 없다.

### 2-2. 딥링크·탭 — 다 맞는다 ✅

| | 결과 |
|---|---|
| `/status` 직접 진입 | 현황 탭이 바로 열리고 그 탭 조회만 나감 |
| 모르는 탭 `/bogus` | **주소까지** `/overview`로 되돌림 ✅ |
| 탭 왕복(구성→개요) | 구성 0건 · 개요 1건(형제 회차) — 캐시 정확 |
| 두 기수 섞임 | 없음 — 조회 기준이 응답의 `cohortId`다 ✅ |

### 2-3. 상태별 잠금 — 다 맞는다 ✅

| 회차 | 구성 탭 | 일정 수정 |
|---|---|---|
| 준비됨 | 변경·변경·편집·삭제 **전부 열림** | 열림 |
| 진행 중 | **전부 잠김** + 「응시가 시작돼 바꿀 수 없습니다」 | 열림(마감 미루기만) |
| 종료 | 잠김 | 잠김 |

현황 탭도 갈린다 — 종료는 반별 표(제출/분석/응시), 진행 중은 「아직 제출한 학생이
없습니다 + 마감일」, 준비됨은 「아직 집계할 것이 없습니다 + 구성 탭으로」.

### 2-4. ⚠ 모달 둘이 「없다」고 먼저 말한다

교안 변경 모달을 연 **1초 시점**:

```
교안 변경 · 검증 개념의 출처 · 1개 연결
등록된 교안이 없습니다 — 운영 관리 › 교안에서 먼저 등록하세요   ← 12초 뒤 7개가 온다
```

**OP-03 생성 모달에서 고친 것과 같은 버그**다. 거기서 고칠 때 이 파일을 안 훑었다
(→ 절차에 「같은 것이 다른 화면에도 있는지 그 자리에서 grep」을 넣은 이유).

개념 선택 모달도 같은 뿌리 — `loadingCandidates={candidates.isLoading}`인데
`enabled: pickOpen`이라 **열기 전에는 `false`**다.

같은 모달에 OP-03에서 고친 것 둘이 더 있었다 — 쪽수 없는 `쪽`, 분석 전 교안 잠금 없음.

| | 발견 | 누가 | 왜 |
|---|---|---|---|
| 2-0 | 2.7초 구조 없음 | **① 우리 코드** | 머리·탭은 어느 회차든 같다 — 미리 그려도 거짓말이 아니다 |

**왜 타임아웃으로 끊지 않나** — 잠든 서버가 깨는 데 **최대 76초**가 걸린다(App Runner).

사실과 주소 확인을 안내**하고, 기다릴지 나갈지는 사용자가 정한다.

### 4-3. 화면이 **틀린 규칙을 말하고 있었다**

측정 규칙·일정 문구를 TR-03·TR-04 확정본과 대조하니 넷이 옛 기획이었다. 오퍼레이터가
학생 문의에 이 값으로 답하는 자리라 **연동 결함보다 무거운 종류**다.

| | 화면에 있던 것 | 확정본 |
|---|---|---|
| 힌트 | 단계당 2회 · 재진술만 · 감점 없음 | **질문당 2개 · 3점 미만이면 자동 지급 + 요청도 가능 · 둘 다 쓰고 미달이면 다음 개념으로** |
| 시간 | 70분 하드캡 | **세션 60분 · 문제당 20분** |
| 채점·도달 | 없음 | **0~5점 · 3점 미만 실패** / **0~4단** |
| 단계 | 「앞 둘 필수」(근거 없음) | 단계마다 **시도 최대 3회** |

재시험은 두 문서가 서로 다른 말을 해서 **사용자에게 물어 확정**했다(2026-08-12).

| | 답 |
|---|---|
| 대상 | 도달 **0·1단만**(2단은 합격) |
| 문항 | **같은 문항**을 1단부터 다시 |
| 힌트 | **없음 — 자력만** |
| 창 기산점 | **리포트 발행**(내가 제안 → 채택) |

**타임라인 순서도 바뀌었다** — `… 응시 창 → 재시험 창 → 리포트 발행`이었는데,
재시험은 리포트가 있어야 성립하므로 `… 응시 창 → 리포트 발행 → 재시험 창`이다.
근거는 `tr-03-session.md` §2-5에 남겼다.

### 4-4. 상세만 스피너였다

OP-01·02·03은 스켈레톤으로 옮겼는데 **여기만 스피너**였다. 세 탭 각각 모양으로
스켈레톤을 만들어 넣었다(개요=카드3+타임라인 · 현황=반별 표 9행 · 구성=4구획).
**주소가 가리키는 탭의 모양**으로 그린다 — 개요 자리에 현황 모양을 그리면 도착 순간
구조가 통째로 바뀌어 스피너와 다를 것이 없다. CLS 0 유지.

### 4-5. 값을 읽고 나서 갈 곳이 없었다

| | 무엇 | 어디로 |
|---|---|---|
| 개요 · 검증 개념 카드 | 개수만 있었다 → **개념 이름 3개** | 눌러서 구성 탭 |
| 개요 · 교안 카드 | | 눌러서 구성 탭 |
| 구성 · 교안 이름 | 읽고 끝 | `/operator/admin/curricula` |
| 구성 · 개념의 출처 교안 | | 〃 |

카드는 `div`가 아니라 **버튼으로 감쌌다** — 핸들러만 달면 Tab으로 닿지 못한다.

### 4-6. 날짜에 연도가 없었다

`formatDue`가 `07-21`로 잘라 **어느 해 7월인지 알 수 없었다.** 기수가 해를 넘겨
이어지고 종료 회차는 몇 달 전 것이라 목록·상세·타임라인이 전부 같은 값을 말했다.
연도를 살리고, 폭이 좁은 목록 표만 `compact`로 둔다.

**시각은 아직 못 쓴다** — 서버 컬럼이 `DATE`라 마감 시각이 존재하지 않는다(18차 R5).
`23:59`을 지어내지 않는다 — 화면이 그렇게 말하면 학생은 그때까지 낼 수 있다고 믿는데
서버는 그 약속을 모른다.

### 4-1. 검증 못 한 것

### 4-2. 재실행이 흔들린 것

상태별 스윕을 두 번 돌렸는데 두 번째는 **탭이 60초 안에 안 떴다.** 서버를 연속으로
때린 뒤라 프록시·콜드스타트 쪽으로 보인다(15차 R3·G5). 코드 변경 없이 결과가 갈리므로
**측정값은 한 번으로 확정하지 않는다** — 이상하면 다시 돌린다.
