# TR-04 · 내 리포트 — 마스터-디테일

## 1. 한 줄

**어디까지 이해했고 무엇을 다시 보면 되는지**를 회차별로 읽는다.

## 2. 진입 · 이탈

상단 `내 리포트` · TR-01의 지난 회차 링크.

## 3. 뷰 — 좌 회차 목록 / 우 본문

```
회차            │ 미프 3차                    발행 07-15 · 교안 AI_LLMOps
────────────    ├──────────────────────────────────────────────────────
미프 3차 ●      │ ↻ 다시 볼 수 있는 문제가 2개 있어요      [다시 보기]
 다시 볼 문제 2 │   7월 24일까지 · 지금 결과는 그대로예요
미프 2차        ├──────────────────────────────────────────────────────
미프 1차        │ ●  HITL Trigger 조건       [무엇을 하는지까지]
                │ 무엇을 하는지는 설명했어요. 다만 교안의 세 번째
                │ 조건을 왜 넣지 않았는지는 확인되지 않았습니다.
                │ 🔒 자세한 해설은 다시 보기를 마치면 열려요
                │    지금 보면 답을 알고 다시 보게 되니까요
                │    교안 3장 · 36~46쪽
                │ ─────────────────────────────────────────
                │    내 답변 3개                    펼치기 ▾
                ├──────────────────────────────────────────────────────
                │ ●  State 관리              [언제 깨지는지까지]
                │    언제 문제가 되는지까지 이야기했어요.
                │    내 답변 2개                    펼치기 ▾
```

**좌측 회차 목록이 곧 아카이브다**(10-5). 별도 화면을 만들지 않는다. 최신 회차가 기본 선택.

### 숫자 대신 학생 언어 라벨

`2단`이라고 쓰면 그것도 숫자이고(A1·A2), 서술만 두면 개념 셋을 견줄 수 없다.
**계단 4단을 "어디까지 갔는지"를 말하는 단어로 바꾼다.**

| 내부 | 학생 화면 |
|---|---|
| 1단 | 무엇을 하는지까지 |
| 2단 | 왜 그렇게 했는지까지 |
| 3단 | 다른 방법까지 |
| 4단 | 언제 깨지는지까지 |

**"못했다"가 아니라 "확인되지 않았다".** 측정은 관찰이지 판정이 아니다.

**상단 요약을 두지 않는다.** `3개 중 1개 도달` 같은 것을 올리면 성적표가 된다.

### 막힌 만큼 두꺼워진다

도달한 개념은 라벨 + 한 줄, 막힌 개념은 **해설 + 교안 위치**가 붙는다.
**분량 차이 자체가 어디를 봐야 하는지 알려준다** — 시스템이 "이것부터 하세요"라고
순서를 정하면 처방이 된다(G5).

### 개념 구분 — 번호가 아니라 레일

**세 개념은 순서가 없다.** 1번이 2번보다 중요하지 않으므로 `01/02/03`을 붙이면 **없는
서열을 만든다.** 대신 **좌측 세로 레일과 점(●)** 으로 시작과 범위를 그린다.

점 색은 어디까지 갔는지에 따라 갈리되(주황/파랑/초록) **라벨이 같은 정보를 글자로 말하므로**
색만으로 구분하지 않는다(F4).

### 교안은 위치까지만 — 링크를 걸지 않는다

**교안 본문을 이 서비스가 갖고 있지 않다.** 파일이 크고 열람 대상도 아니라, 11절이 정한
것도 `교안 참고 위치`뿐이다. 학생은 자기가 가진 교안에서 그 쪽을 편다.

| | |
|---|---|
| 교안 | `3장 · 36~46쪽 사람 확인이 필요한 순간` — **텍스트.** 클릭 대상이 아니다 |

### 내 답변 — 개수를 드러낸다

`▸ 내가 뭐라고 답했는지 보기` 같은 문장형 안내를 쓰지 않는다. **`내 답변 3개 · 펼치기 ▾`**
가 정보를 준다 — 몇 개인지 보이면 열지 말지를 열기 전에 정한다.

### 해설은 다시 보기 대상 문항만 잠긴다

다시 보기가 **같은 문항**이라 해설을 먼저 주면 답안지가 된다(11절).

**잠기는 것은 다시 보기 대상 문항의 상세 해설뿐이다.** 나머지는 전부 즉시 공개.

| 즉시 | 다시 보기 후 |
|---|---|
| 어디까지 갔는지(라벨) · **어디서 막혔는지** · 교안 위치 · **내 문답** | 문항별 상세 해설 |

**대상이 아닌 개념은 처음부터 해설이 열려 있다.**

**잠긴 이유를 함께 쓴다** — *"지금 보면 답을 알고 다시 보게 되니까요."* 이유 없는 자물쇠는
불신을 만든다.

### 다시 보기를 마치면

해설이 열리고 **처음 / 다시 봤을 때**가 나란히 붙는다. 이때 반드시 적는다 —
**"다시 본 결과는 성적에 반영되지 않아요."** 없으면 *"다시 봤는데 왜 그대로지"* 가 된다.

## 4. 데이터

회차별 개념 도달 · 서술 · 교안 위치 · 재시험 지정과 마감 · 문답 원문.

## 5. 액션

회차 전환 · `[재시험]` → TR-03 · `[문답 보기]` 토글.

## 6. 상태 — 왜 그렇게 정했나

> **케이스 표는 목업에 있다** — [`trainee/report.html#cases`](../wireframe/trainee/report.html#cases).

### 못 보는 이유를 구분한다

| | 무엇을 기다리나 |
|---|---|
| **발행 전** | 회차가 아직 안 끝났다 — 마감 후 한꺼번에 발행된다 |
| **공개 범위 미지정** | **결과는 나와 있다.** 매니저가 여는 시점만 남았다 |

둘을 같은 화면으로 그리면 학생이 **누구를 기다려야 하는지** 모른다.

### 응시 상태 세 가지를 다르게 쓴다

| | 학생 화면 | 매니저가 보는 사유 |
|---|---|---|
| **미응시** | `응시 기록이 없어 리포트가 없습니다` | 안 들어옴 |
| **중단** | `답한 데까지만 기록됐어요` | 하다가 나감 |
| **무효 응시** | `응시 기록을 확인하고 있어요` | 들어왔지만 답이 거의 없음(9-4) |

**중단은 결과가 남는다** — 답한 문제까지는 리포트에 들어간다. 나머지 둘과 다른 점이다.

### 해설은 다시 보기 뒤에 열린다

먼저 보여주면 **답을 알고 다시 보게 되어** 다시 보기의 의미가 없어진다.

### 교안 위치가 없으면 그 줄을 뺀다

빈 칸을 남기면 학생이 **뭔가 빠졌다**고 읽는다 — 해설만 보여준다.
## 7. 안 하는 것

| | |
|---|---|
| 히트맵 · 반 평균 · 다른 학생 | **보여주지 않는다** |
| 점수 · 루브릭 · 채점 근거 원본 | **없다** |
| 처방 | **위치 안내까지.** "이렇게 공부하세요"는 하지 않는다 |
