개입 관리

개입(면담·멘토링·보강·팀조정·모니터링)을 실행하고 효과를 검증하는 화면. 이 화면의 핵심 질문 = "무슨 개입을 하고 있고, 뭐가 효과 있었나" → 유형×축 회복률 집계를 1급 정보로 앞세운 정보-우선 테이블(D131). 생성 진입점은 M07에 없다 — 근거 없는 개입 차단(시그널-개입 연결 필수)은 위험 트리아지(M04)·조치 큐(M01)·개별 상세(M06)가 이미 더 잘함, M07은 그 결과를 추적·검증만(D131). 자동확정 금지.
