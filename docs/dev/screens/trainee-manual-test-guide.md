# 교육생 화면 손으로 확인하기 — 계정별 안내

> **왜 이 문서가 필요한가.** 화면이 서버 상태에 따라 갈리는데, **상태를 만드는 권한이
> 우리에게 없다.** 목이던 시절에는 주소에 `?state=`를 붙여 아무 상태나 볼 수 있었지만
> 실서버에 붙은 뒤로는 그 계정이 실제로 그 상태여야 한다.
>
> 그래서 백엔드가 **상태별 계정**을 심어 주었다. 이 문서는 *"어느 계정으로 들어가
> 어디를 눌러야 무엇이 보이나"* 를 적는다.
>
> 계정 상태는 **2026-08-17 실측**이다. 상태는 시간이 지나면 바뀐다(§5).

---

## 1. 들어가는 법

로그인 화면 아래 **역할별 바로 입장** 버튼, 또는 로그인 후 **우측 상단 `역할 전환 (dev)`**.

```
로그인 화면        →  버튼을 누르면 그 계정으로 바로 들어간다
로그인한 뒤        →  상단 아이콘 → 목록에서 고른다
```

비밀번호를 칠 필요가 없다. 이 버튼은 개발 환경에서만 나온다.

---

## 2. 교육생 계정 여덟 — 무엇이 보이나

| 버튼 이름 | 홈 카드 | 무엇을 확인하나 |
|---|---|---|
| **교육생(미제출)** | 코드를 제출할 차례예요 | 제출 폼 · GitHub 탭 잠금 · 50MB 차단 |
| **교육생(분석실패)** | 코드를 분석하지 못했어요 | 실패 안내 · 제출한 파일 · 재제출 폼 |
| **교육생·분석중** | 코드 분석이 진행 중이에요 | 버튼이 비활성 · *"분석이 끝나면 열려요"* |
| **교육생·응시가능** | 이해도 확인을 시작할 차례예요 | **카운트다운** · 시작 전 안내 화면 |
| **교육생·응시완료** | 리포트를 기다리는 중이에요 | 버튼 비활성 · *"발행되면 알려드릴게요"* |
| **교육생·다시보기** | 다시 볼 수 있는 문제가 N개 있어요 | 이번 회차 리포트 카드 · 다시 보기 버튼 |
| **교육생·창닫힘** | 응시 기한이 지났어요 | 경고 배지 · 버튼 없음 |
| **교육생** | 코드를 제출할 차례예요 | 지난 회차 5건 · 리포트 열람 |

> ⚠️ **`교육생·응시중`은 지금 못 쓴다.** 세션 상한(60분)을 넘겨 서버가 닫았고, 홈이
> `리포트를 기다리는 중`으로 바뀌었다. 그 상태를 보려면 새 계정이 필요하다(§5).

## 3. 화면 세 개를 어떻게 도나

### TR-01 홈 — `/trainee/home`

**볼 것**

- 위쪽 **진행 바** 네 칸(제출 → 분석 → 확인 → 리포트) 중 지금 칸이 강조되나
- **남은 시간**이 상태에 맞는 마감을 가리키나
  - 제출 전이면 *제출 마감*, 응시 가능이면 *응시 창 마감*
- **버튼**이 눌리는가, 안 눌리면 그 옆에 이유가 있는가
- 아래 **지난 회차** 목록이 최신순인가

**특히 봐 주실 것** — `교육생·응시가능`에서 안내문이 **"코드 2군데"** 라고 나온다.
서버가 실제로 준비한 문제 수다. 전에는 `3`이 박혀 있었다.

### TR-02 제출 — `/trainee/submission`

**볼 것**

- `교육생(미제출)` → 폼이 뜨고 **GitHub 탭이 잠겨** 있나
- ZIP 파일을 골랐을 때 이름·크기가 뜨나
- **50MB 넘는 파일**을 고르면 업로드 전에 막히나

> 🔴 **제출 버튼을 눌러도 접수되지 않는다.** 서버 설정 문제로 요청이 브라우저에서
> 막힌다(백엔드에 요청함). *"지금은 제출이 접수되지 않아요"* 가 뜨면 그게 정상이다 —
> 다시 눌러도 같다.

### TR-04 리포트 — `/trainee/report`

**볼 것**

- 왼쪽 **회차 목록**에서 회차를 바꾸면 오른쪽이 바뀌나(요청은 처음 한 번뿐)
- 발행된 회차에서 개념 카드마다 **도달 단계 배지**와 설명이 있나
- **요약만 공개된 회차**는 잠금 안내가 **맨 위에 한 번만** 뜨나
  (개념마다 자물쇠가 세 번 뜨면 잘못된 것)
- `교육생` 계정의 지난 회차 넷을 눌러 보면 상태가 다 다르다

### TR-03 세션 — `/trainee/session`

**지금은 시작 전 안내까지만 실서버다.**

- `교육생·응시가능` → 시작 전 안내가 뜨나
- `교육생·응시완료` → *"이해도 확인을 마쳤어요"*
- `교육생·창닫힘` → *"응시 기한이 지났어요"*
- `교육생·분석중` → *"아직 분석이 끝나지 않았어요"*

**세 문구가 서로 다르게 나오는지**가 핵심이다. 전부 같은 문구가 나오면 잘못된 것이다.

> 🔴 **`전체화면으로 시작하기`는 아직 누르지 마세요.** 그 버튼부터는 목이고, 실제로
> 누르면 **되돌릴 수 없습니다** — 20분·60분 시계가 돌기 시작하고 그 계정은 다시 시작
> 전으로 돌아가지 않습니다. 지금 응시 가능한 계정은 아홉이라 아껴야 합니다.

## 4. 이상하면 알려 주실 것

무엇이 이상한지 몰라도 됩니다. **아래 중 하나라도 걸리면 그대로 알려 주세요.**

| 무엇 | 예 |
|---|---|
| 두 화면이 같은 것을 다르게 말한다 | 홈은 "미응시"인데 리포트는 "발행 전" |
| 숫자가 안 맞는다 | "3군데"라는데 문제가 2개 |
| 버튼을 눌렀는데 아무 일도 없다 | 누른 뒤 화면이 그대로 |
| 글자가 잘리거나 겹친다 | 좁은 화면에서 특히 |
| 문구가 스스로 부딪힌다 | "0개 있어요"라면서 목록이 비어 있다 |
| 오래 기다린다 | 10초 넘게 도는 화면 |

**첫 접속이 느린 것은 정상입니다.** 서버가 잠들어 있다가 깨어나느라 20초쯤 걸립니다.
*"서버가 깨어나는 중일 수 있습니다"* 가 뜨면 기다리시면 됩니다.

## 5. 계정 상태는 변한다

세 가지 이유로 바뀝니다.

| | |
|---|---|
| **시간** | 응시 창은 분석이 끝난 뒤 24시간, 세션은 60분·문제당 20분 |
| **누군가 썼다** | 세션을 시작하면 그 계정은 다시 시작 전으로 안 돌아간다 |
| **세션 화면에 들어가는 것만으로** | 서버가 그 자리에서 상한을 정리한다(아래) |

> 🔴 **세션 화면 진입에는 부작용이 있다.** 상한을 넘긴 세션을 그 자리에서 닫는다.
> 실제로 `응시중` 계정이 그렇게 닫혔다. 의도된 설계지만(새로고침만 해도 상한이
> 반영되게 한 것) **테스트할 때는 계정이 소모된다는 뜻이다.**

상태가 표와 다르면 **이 문서가 낡은 것**입니다. 그때는 계정 목록을 다시 재야 합니다.

## 6. 아직 못 보는 화면

| 상태 | 왜 |
|---|---|
| 제출 마감 지남 | 그 상태인 계정이 없다 |
| 진행 중인 회차 없음 | 위와 같다 |
| 응시 중(이어하기) | 있었는데 상한을 넘겨 닫혔다 |
| 리포트 — 공개 범위 미지정 · 무효 응시 · 중단 | 계정이 없다 |
| 생성 실패로 개념이 빠진 리포트 | 계정이 없다 |

이것들은 **백엔드에 계정을 요청해 둔 상태**이거나, 요청 목록에 올릴 후보입니다.
