# SC-M06 · 개별 교육생 상세

> 소스: 기능명세서 v8 DASH-16(개별 상세) + ENG-02(회차 변화·추이) + ENG-03(기여 편차·귀속) + RPT-03(온디맨드 면담 체크리스트) + INTV-08(상담·메모) + AUTH-11(이력 권한).
> 배치: P0 · 매니저 조회 종착. **매니저 전용** — 교육생 리포트(T05)와 정반대로 점수·세션 전문·근거가 보인다.

## 2. 목적 & UX 설계 근거

- **한 사람을 통째로 이해하는 화면.** **종합·세션·개입 3탭**(근거·귀속은 별도 탭이 아니라 종합·세션에 흡수·D21). 매니저가 근거를 눌러 확인하며 판단.
- **매니저 전용 = 근거가 보인다.** 교육생에겐 숨기는 점수·세션 전문·채점 근거를 여기선 노출(DASH-16·DASH-09). 단 **교육생 직접 접근은 차단**.
- **추이는 스냅샷 의미론(B1) + 프로젝트 경계 존중(B2·D105).** 기수 평균 대비는 회차별 스냅샷 기준. 절대 점수·직전 대비·최초 대비를 분리 표시(ENG-02). **1회차 단독은 판정 금지**(표본 부족). **추이 라인은 여러 프로젝트를 가로지를 수 있다**(회차별 제출물이 시간순 다른 프로젝트·05-project-flow). 프로젝트 전환 지점에 세로 구분선·밴드 라벨을 넣어 "경계 넘는 등락은 퇴보가 아니라 과제 난이도 변화일 수 있음"을 명시 — 회차 측정 독립(B2)을 시각화가 존중.
- **귀속은 낙인 금지(B5) + 커밋 귀속 신뢰도 경고(A8·D105).** 기여 편차를 단독으로 프리라이더라 부르지 않는다. 기여×이해도×지속성 교차, **서술형 표현**("기여·이해도 불균형"). **기여 편차는 커밋 이메일 귀속 기반**이므로, 커밋 이메일 미검증(AUTH-07)이면 기여 카드에 **정확도 주의 경고**(A8: 미검증 커밋이메일→귀속 경고). 확정 판단 전 검증 유도. 기여 신호가 어느 프로젝트·팀 것인지도 카드에 명시(팀=프로젝트 종속).
- **면담 준비는 온디맨드(RPT-03).** 자동 생성 금지 — 개입 탭 [＋ 면담·관찰 기록 추가] 시 요약·체크리스트가 프리필됨(**별도 '면담 질문 추출' 버튼 폐기·D34/D43**). 코드 재질문 아님.
- **상담 메모는 이력 보존(INTV-08).** 작성자·시각 보존, 수정 시 이력 추가.

## 3. 정보 구조 & 레이아웃 (매니저 앱 셸 · 데스크톱) — 3탭 + 종합 컴포넌트 스택(D21·D107)

**종합 탭 = 컴포넌트 스택 고정, 값만 적응(D107).** D106에서 상태 6종을 각각 다른 레이아웃(히어로 색·차트 데이터·카드 유무)으로 만들었던 걸 재검토 — "화면 타입별 분기 아니라 값만 적응"이라 해놓고 실제로는 6개의 다른 화면을 태그만 바꿔 만든 것이었음(사용자 지적). **재설계 원칙: 종합 탭은 어느 학생 상세에 들어가도 항상 같은 컴포넌트 스택 + 순서. 상태에 따라 달라지는 건 "그 컴포넌트가 보이는지 안 보이는지"와 "안의 값"뿐, 컴포넌트 자체를 새로 만들지 않는다.**

**타당성 재검토 결과 — 상태 taxonomy 단순화:** 매니저 지시로 **"일반 학생은 배지 없음, 위험·에이스만 표시"**로 확정. 이러면 D106의 판단유보·개입진행·회복·안정 4종이 별도 배지 없이 자연스럽게 해소됨:
- **판단유보** = 표본 부족(회차<2)이라 ⑥5축표의 기수대비 칸이 "—"로 자연 표시. 별도 배지 불필요.
- **안정** = 위험도 에이스도 아닌 대부분 학생 = "일반"과 동일. 별도 배지 불필요.
- **개입진행** = ④컨텍스트 라인이 상태 무관하게 "진행 중 개입 있으면 항상" 뜨므로 별도 배지 불필요.
- **회복** = 위험(DASH-05 신호) 계열의 한 타이밍일 뿐 — ①상태 배지가 그 시점의 DASH-05 문구를 그대로 반영(즉시/관찰/회복/추가확인), 별도 컴포넌트 불필요.

**폐기(D106→D107):** ~~레이더 차트~~(5축 통합표 ⑥와 완전 중복, 같은 5숫자를 도형으로 또 그림 — 제거) · ~~종합점수(총점) 추이 그래프~~(자기 캡션이 "종합은 축 등락을 가림"이라 자인하던 오해 유발 차트 — 제거, ③ 포커스 축 그래프로 대체: 뭉뚱그린 총점 대신 실제 문제/강점 되는 그 축 하나를 정확히 보여줌) · ~~2점 스파크라인의 장식적 총점 차트~~ · ~~신뢰도 경고를 귀속 카드 안에 매몰~~(② 별도 스트립으로 승격 — "사람 문제"와 "데이터 문제"는 다른 카테고리).

**헤더:** 아바타·이름·기수·**반**·계정 상태 + **참여 프로젝트(팀) 라인**(D105). 팀은 안정 정체성이 아니라 프로젝트마다 재편성되는 유동값(TeamMembership 프로젝트 종속·D77~90)이므로 헤더에 단수로 박지 않고 "참여 프로젝트: MSA 배포 실습(팀A) · API 서버(팀C)"처럼 **프로젝트 컨텍스트와 함께** 표기(리스트 D104 팀 제거와 동일 규범). (면담 버튼 없음 — 면담 준비는 개입 탭 기록 추가에 흡수·D34/D43.)

**나머지 2탭(세션·개입) — 이번 재설계 범위 밖, 기존 유지:**
2. **세션(근거 흡수):** 회차 선택 → **DP별 접힘 카드**(주제·근거코드 위치·도달 depth 핀·판정 색). **SURFACE 지점 경고색으로 강조** → "어디서 막혔나" 즉시 스캔. 펼치면 질답 전문 + **근거 구간**(ENG-01, 별도 탭 아님 — 점수·턴에 붙음)
3. **개입(행동·기록 · D43 재구성):** **개입별 활동 카드 스트림.** 개입 하나 = 카드, 그 안에 **근거 시그널 · 활동 기록(면담/멘토링 후기/관찰) · 상태(진행/완료 전이) · 효과 판정**이 한 덩어리. + 하단 **일반 메모**(개입 무관 관찰, INTV-08 비연결). **"면담 준비" 별도 버튼 폐기** → [＋ 면담·관찰 기록 추가] 시 면담이면 AI 요약·체크리스트 프리필(RPT-03 흡수).

**귀속 = 독립 탭 없음(D21).** 코드량은 품질·적극성의 지표가 아니므로(B5·ENG-03/04) 라인·파일 표를 전면에 두지 않는다. 기여 데이터는 **⑦ 귀속 신호 카드**에서만 — 기여편차 AND 이해도저조 AND 지속성 **세 조건 동시 충족 시에만**, "낮은 기여량 ≠ 낮은 실력" 명시, 원시 숫자는 "참고용" **접기(disclosure)**. 카드에 **어느 프로젝트·팀** 기여인지 컨텍스트(팀=프로젝트 종속) 표기. **커밋이메일 검증 경고는 ②로 분리**(D107 — 사람 신호와 데이터 신뢰도 신호를 같은 카드에 섞지 않음).
**개입 데이터 흐름 (D43·D44 — 한 실체, 두 화면):** `Intervention`은 **학생(targetId)으로 묶인 하나의 서버 레코드.** 생성(시그널 경로)·상태 전이(진행/완료)·활동 기록 추가는 **M06(이 학생 맥락)·M07(전체 관리) 양쪽 어디서나** 같은 레코드에 반영. M07 = 담당 전체 개입 관리(테이블·정렬·방치·export), M06 = 이 학생 개입의 활동·기록. **효과 판정은 완료 후 다음 회차에만**(진행·대기 중엔 없음).

**면담 준비(RPT-03) = 면담 기록 추가 시 프리필:** 별도 버튼 아님. [＋ 면담·관찰 기록 추가]에서 면담 유형이면 입력창에 ①상황 한 줄 요약(코드 용어 없이) ②확인 체크리스트(학습 페이스·도움요청·계기·지속의지, AI가 못 보는 것·코드 재시험 아님)가 프리필. 매니저가 코드를 몰라도 지원 대화 가능. 질문 대본 생성 아님.

**세션 질문 수(예산 N):** M06은 소비만. **N은 회차별 설정(기본 4)** — SC-M03 소관(D28). 상대 위치 표기는 **점수 대비 기수 평균(같은 5점 단위·차이)**, σ·순위 배제(D29). 반응형: 웹 기준.
