제출 코드를 근거로 한 소크라틱 검증. 왼쪽 = 지금 질문의 근거 코드(고정), 오른쪽 = 질답. 코드 없이는 답할 수 없는 질문만(MEAS-06). 진행 표시는 결정지점 = 정직한 분수(고정 예산 N, D110), 깊이 = 비분수 인디케이터(적응형이라 분모 없음, D109). 깊이는 L1 기본 → L2 대안·트레이드오프 → L3 반례로 "이해의 종류"를 캐는 축이지 난이도가 아니며(D109), 5축 채점은 세션이 끝난 뒤 대화 전체에 적용된다(D108) — 세션 중 점수·평가·루브릭은 절대 비노출(A5).
