요구사항 ≠ 질문 초점 (D80)

요구사항(프로젝트): "목적대로 제대로 했나" — 필수 조건(JWT·PostgreSQL) 단위별 O/X+비고. 질문 초점(회차·구 "결정 지점"/"검증 포커스" 통합): "질문을 어디 치중할까" — 비우면 AI 자율 추출, 지정하면 그 영역 치중. 판정 대상 vs 질문 방향으로 별개.

허브 ≠ 모놀리식 (D78)

워크스페이스는 프로젝트 컨텍스트 허브 + 탭. 각 탭은 자기 SC-ID: 개요·팀레포=SC-M13, 측정계획=SC-M03, 결과=SC-M08. 위계(측정계획⊂프로젝트)와 화면 분해는 별개 축.

권한

저작 = 총괄, 실행 = 담당(FB-F5·D90). 총괄: 프로젝트 생성·요구사항 정의/편집·측정 설계(회차 수·질문 초점=측정 축)=무엇을 잴지(측정 무결성·담당이 자기 잣대 못 바꾸게). 담당: 팀·레포 편성·체크포인트 열기(이 반 진도에 맞춰 언제)·독촉·모니터링·개입=이 반에서 언제·누구를(규모상 반마다 생기는 운영을 총괄이 다 할 수 없음). 회차 수는 총괄 설계지만 담당이 가감 제안 가능(코호트 비교 흔들림 방지). 관련: D75·D76·D77·D78·D80·D90.
