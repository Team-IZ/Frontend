# MG-08 · 프로젝트 상세 (매니저) — 탭 3

## 1. 한 줄

이 회차를 **굴리는** 화면 — 팀을 짜고, 밀린 사람을 밀고, 끝나면 리포트를 본다.

## 2. 진입 · 이탈

MG-07 행 → 여기. `결과` 탭의 개인 → MG-06.

## 3. 뷰

```
미프 3차 · A반 25명 · 교안 AI_LLMOps v2
검증 개념 HITL Trigger 조건 · Graph 구성 · State 관리 · 마감 07-14
[ 팀 8팀 ] [ 제출 현황 6/8 ] [ 결과 발행 전 ]
```

**탭 순서가 회차 진행 순서다** — 팀 편성(한 번) → 제출 현황(매일) → 결과(마감 후).
기본 탭은 회차 상태를 따라간다.

**`구성` 탭이 없다.** 교안·검증 개념·요구사항은 오퍼레이터가 정하고 매니저는 읽기만
하므로 **헤더 한 줄**로 끝낸다.

### 팀 편성이 끝나야 제출이 열린다 — 세 국면

**미배정 인원이 있는데 이미 제출한 팀이 있는 상태는 존재할 수 없다.** 편성 → 제출 →
분석 → 응시가 순서이기 때문이다. 화면도 그 순서를 따른다.

| 국면 | 팀 탭 | 팀 편집 | 제출 |
|---|---|---|---|
| **① 편성 전**(팀 0) | 자동 배분 · 팀 추가 | 자유 | 잠김 |
| **② 편성 중**(미배정 있음) | 미배정 경고 · 팀에 넣기 · `팀 편성 완료` **비활성** | 자유 | 잠김 |
| **③ 확정 직전**(전원 배정) | `팀 편성 완료` **활성** | 자유 | 잠김 |
| **④ 확정됨 · 제출 전** | 🔒 · `편성 다시 열기` | **잠김** | **열림** |
| **⑤ 제출 시작됨** | 🔒 · `팀 이동`만 | **잠김** | 진행 |

### 편성 완료는 명시적 버튼이다

**전원 배정되었다고 자동으로 열지 않는다.** 매니저가 아직 조정하는 중에 마지막 한 명을
넣는 순간 제출이 시작되면, 그 뒤의 팀 변경이 전부 사고가 된다.

**되돌리기는 제출 전까지만.** ④에서는 `편성 다시 열기`로 ③으로 돌아갈 수 있고, ⑤에서는
막힌다 — 이미 낸 코드가 팀에 묶여 있기 때문이다.

**완전 잠금은 하지 않는다.** ⑤에서도 `팀 이동`은 남긴다 — 학생 이탈·반 이동은 실제로
일어나고, 그때 대응할 방법이 없으면 운영이 막힌다. 다만 **그 사람이 새 팀이 낸 코드로
응시하게 된다**는 것을 경고한다.

### 제출은 팀 단위, 응시는 개인 단위

**팀 중 한 명이 내면 팀원 전원이 같은 코드를 쓴다.** 그래서 같은 팀에서 제출 상태가
갈릴 수 없고, 표가 **팀 그룹 + 개인 행** 2계층이 된다.

```
▾ 3팀   제출 07-13 · 분석 완료      github.com/team-a/mif3-3 · 임채원이 제출
    김민준    응시 완료          ✓ 2 · ✗ 1
    이서준    응시 가능 D-19h    ✓ 2 · ✗ 1     ← 같은 코드라 요구사항 결과가 같다
    정하늘    미응시             ✓ 2 · ✗ 1
▾ 4팀   미제출 ⚠                    아직 아무도 제출하지 않았어요
    박도윤    —
    최유나    —
```

| 층 | 값 |
|---|---|
| **팀** | 제출 · 분석 · 레포 · **요구사항 충족** |
| **개인** | 응시 · 다시 보기 |

**독촉 대상도 이 구조에서 나온다** — 미제출은 **팀 전원에게**(누구든 한 명이 내면 됨),
미응시는 **개인에게**.

### 요구사항은 팀 행을 펼쳐서 본다 — 모달이 아니다

팀이 낸 **한 코드**에 대한 판정이라 팀 행에 속한다. 별도 모달을 열면 **진입점을 따로
만들어야** 하고, 어느 팀 것인지가 흐려진다.

### 요구사항 충족 — 시스템이 정하고 이유를 말한다

**`?`(확인 필요) 등급을 없앤다.** 매니저는 강사가 아니라 코드를 보고 판단할 수 없다 —
판단할 수 없는 사람에게 판단을 넘기면 아무도 결정하지 못한다.

| 판정 | 조건 | 화면 |
|---|---|---|
| **충족** | 이름 매칭 + **동작 연결**(호출·상태변경·API) | `✓` + 무엇이 이어지는지 |
| **미충족** | 변수·타입만 있고 **쓰이지 않음** | `✗ 자리는 만들었지만 쓰이지 않았어요` |
| 〃 | 껍데기·TODO | `✗ 함수는 있지만 안이 비어 있어요` |
| 〃 | 매칭 0 | `✗ 관련된 코드를 찾지 못했어요` |

14번 8-2가 걱정한 False Positive(`handleLike` 껍데기가 P)는 **충족 조건에 동작 연결을
요구**해서 막힌다. 매니저는 이유를 **읽고 학생에게 전달**만 한다 — 그게 할 수 있는 일이다.

**표기는 `✓ 2 · ✗ 1`.** `✓✓✗`는 순서에 의미가 없는데 있어 보인다.

> ⚠ **14번 8-2 수정 필요** — `?` 등급과 "매니저 확인" 문장을 지워야 한다.

### 결과 탭 — 집단 미달만 경고하고 나머지는 히트맵으로

**개념별 분포를 여기서 그리지 않는다.** 반 × 개념 패턴은 MG-02 히트맵이 담당한다(D1).

여기서 필요한 것은 셋뿐이다.

| | |
|---|---|
| **요약 3칸** | 응시 · 막힌 개념 2개 이상 인원 · 다시 보기 대상 |
| **집단 미달 경고** | 반 절반 이상이 한 개념에서 막히면(9-6) — **개인 위험 사유에서 뺀다** |
| **개념별 표** | 막힌 사람 수 · **코드에 없던 사람 수** · 명단 |

`코드에 없던 사람`을 따로 세는 이유 — 문항이 만들어지지 않은 것이라 **못한 것이 아니다**(F3).

**좌측 개인 목록이 이 탭의 본체다.**

### 개인 결과 표기 — 5-2 그대로

```
HITL Trigger 조건                      1단 도달 · 다시 설명 2회
  코드이해    혼자      요소들이 어떻게 이어지는지 설명했다
  설계논리    2회 도움  고려사항을 나열했으나 선택과 연결되지 않았다
  ─ 설계논리에서 멈춤 — 대안비교·반례대응은 묻지 않았습니다
```

| 어디서 왔나 | |
|---|---|
| `1단 도달 · 다시 설명 2회` | **5-2 화면 표기** — `4단 도달 · 힌트 0회` |
| `혼자 / 1회 도움 / 2회 도움` | **4-2 기록** — `자력 / 재진술1 / 재진술2 / 미달` |
| `설계논리에서 멈춤` | **4-1 흐름** — 미달하면 그 문제 종료, 위는 안 묻는다 |

**단계마다 도움 횟수가 붙는 게 핵심이다.** 매니저가 읽는 것은 "혼자 했는가, 두 번
도와줘야 했는가"이고, 그게 면담에서 물을 것을 정한다.

**멈춘 지점을 명시한다** — 안 쓰면 매니저가 `대안비교`가 비어 있는 것을 "못했다"로
읽는다. 실제로는 **묻지 않은 것**이다.

**힌트는 감점이 아니다**(5-2) — 정렬 키일 뿐이다. 화면에서도 경고 색을 쓰지 않는다.

**원문 문답은 없다**(10-3). 그 사실을 화면에 적어, 면담에서 학생이 *"리포트에서 봤는데요"*
할 때 어긋나지 않게 한다.

### 팀 편집 — 행 클릭 → 모달

25명·8팀 규모라 OP-06의 반 배정(250명·모드)과 달리 모달로 충분하다.
**좌우 리스트 + 이동 버튼**(dual list). 왼쪽 팀원 / 오른쪽 팀 없는 사람, 체크해서 옮긴다.
칩(알약)으로 만들면 인원이 늘 때 줄바꿈이 지저분하고 **선택 상태가 안 보인다.**

미배정 인원에 **직전 회차 도달 단계**를 같이 띄운다 — 실력이 한쪽에 몰렸는지 확인하는 값이다.

**편성이 끝나기 전에는 자유롭게 바꾼다.** 제출이 시작된 뒤 팀 간에 옮기면 그 사람은
**새 팀이 낸 코드**로 응시하게 된다 — 본인이 쓰지 않은 코드를 설명해야 하므로 경고한다.

**미배정 인원을 제출한 팀에 넣는 상황은 없다** — 미배정이 남아 있으면 제출 자체가 열리지 않는다.

**팀 탭에 레포 컬럼이 없다.** 레포는 제출의 결과라 제출 현황 소관이다(D1).

## 4. 데이터

팀 편성 · 제출/분석/응시 상태 · 개념별 도달 집계 · 리포트 본문 · 재시험 지정과 결과.

## 5. 액션

| | |
|---|---|
| 팀 추가·편집 | 모달 |
| **자동 배분** | **팀이 하나도 없을 때만 버튼이 나온다.** 짜인 팀을 뒤엎는 액션을 상시 노출하지 않는다 — 이후 조정은 팀 편집으로. 도달 단계 순 **뱀 배분**(1·2·3·3·2·1) → 이전 회차와 2명 이상 겹치면 그 팀만 재추첨(최대 20회) → 안 되면 그대로 두고 알림. **이미 제출한 팀은 건드리지 않는다** |
| **독촉** | 상태별 **고정 문구**. 미제출은 팀 전원, 미응시는 개인 · 문구 커스텀 없음(개별 메시지는 면담에서) |
| 리포트 발행 | 결과 탭 · 마감 후 일괄 |
| **다시 보기 발송** | 자동 지정 + **매니저가 버튼을 누른다.** 체크 해제로 제외 · 기한은 계산된 날짜로 표시 |
