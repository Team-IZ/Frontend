# SC-T01 · 교육생 홈 (회차 · 응시 상태)

> 소스: 연계 FR **미지정**(D6로 정의). 상태는 인접 FR에서 파생 — MEAS-01(제출)·MEAS-06(세션)·MEAS-07(리포트)·AUTH-07(커밋 이메일)·GOV-03(열람 범위)·PLAN-01(체크포인트).
> 배치: P0 · 진입 순서 9번. **교육생 앱 셸이 처음 등장**(T02·T04·T05 공유). 교육생 로그인 착지점.

## 2. 목적 & UX 설계 근거

- **"지금 뭘 해야 하나"를 한 화면에.** 교육생의 핵심 질문은 "이번 회차 제출했나 / 세션 응시하나 / 결과 나왔나". → 진행 중 회차를 가장 크게, **다음 행동 CTA 하나**(제출/세션/결과)로 명확히.
- **회차가 시간의 축.** 회차별 카드로 진행중·예정·완료를 시간순 정렬. 각 회차 = 프로젝트·기한·제출/세션/결과 상태.
- **매니저 전용 정보 비노출(A5·GOV-03).** 점수 근거·루브릭·시그널은 안 보인다. 결과 리포트도 GOV-03 열람 범위(전체/요약/비공개)에 따라 노출.
- **커밋 이메일은 측정 정확도의 전제.** 미검증이면 귀속 분석이 부정확 → **상단 안내 배너**로 검증 유도(AUTH-07).
- **차분한 학습자 톤.** 매니저 콘솔보다 밀도를 낮추고 카드 중심. 단 브랜드 토큰은 동일.

## 3. 정보 구조 & 레이아웃 (교육생 앱 셸 · 데스크톱)

**교육생 앱 셸(신규, 공유):** 상단바(IZ-Get · 홈 / 내 리포트 · 교육생 이름·기수·반 · 알림·로그아웃). 매니저 콘솔의 좌측 네비 셸과 다른 **경량 상단 셸**.

홈은 체크포인트 대시보드가 아니라 **"지금 뭘 해야 하나"에 답하는 단일 초점 화면**이다(D112).

**콘텐츠:**
1. (조건부) **커밋 이메일 검증 배너** — 미검증 시(AUTH-07)
2. **"지금 할 일" 히어로 — 딱 하나(강조):** 현재 가장 급한 단일 액션만 크게. 회차·프로젝트(유형 배지)·응시 기한(D-n) + 큰 헤드라인(무엇을 할 차례인지) + **3단계 진행 스트립**(코드 제출 → 검증 세션 → 결과 리포트, done·now·**analyzing**·wait) + **CTA 하나**.
   - **CTA는 파생상태 기계의 "지금" 상태 하나에 묶인다**(§6): 미제출→[코드 제출](T02) / **분석중(H-10)→비활성 "분석 중 · 준비되면 알림"**(거짓 어포던스 차단) / 제출완료·세션대기→[검증 세션 시작](T04) / 세션진행중→[세션 이어하기] / 할 일 없음→휴지 히어로(다음 예정 안내).
   - **검증 세션은 한 번에 하나.** 프로젝트는 시간순 반복(02-domain §5), 세션은 단일 착석. 활성 체크포인트가 둘이어도 **히어로는 항상 1개(가장 급한 것)**, 다른 하나는 아래 목록에 배지로 조용히(두 번째 히어로 금지 — D6 "다음 행동 CTA 하나" 원칙).
   - **세션 톤 선제 완화:** 세션 대기 히어로에 "코드를 보며 설명하는 시간 · 점수는 표시되지 않아요 · 약 10~15분"(D108~111). 홈이 세션 불안 완화의 첫 접점.
3. **그 외 회차 — 조용한 목록(히어로와 경쟁 안 함):** 예정(회차·측정 기간, 액션 없음, 최종 배지) · 지난 회차(최근 몇 건 + **[전체 보기 → 내 리포트]**, [결과 보기]→T05, GOV-03 비공개면 잠금).

**마감 표기:** 재응시 없음(H-5)이라 마감은 1급 정보지만, **임박(D-1/당일)에만 경고색**, 평소엔 차분한 뉴트럴(상시 경고 = 불안 누적 방지).

반응형: 웹 기준, 모바일은 히어로·목록 세로 스택.

## 6. 상태별 UI (파생 상태 — 연계 FR 없음, 근거 명시)

SC-T01은 직접 연계 FR이 없어 명세 예외 case가 없다(게이트 A는 인접 FR 소관). 대신 **파생 상태**를 정의:

**히어로 CTA는 이 표의 "지금" 상태 하나에 묶인다** — 특히 H-10은 세션 CTA를 활성화하지 않는다(거짓 어포던스 차단). 활성 회차가 여럿이어도 히어로는 항상 1개(가장 급한 것), 나머지는 아래 목록.

| # | 상태 | 표현 / 히어로 CTA · 다음 행동 |
|---|---|---|
| — | 정상(진행 중 회차 있음) | 히어로 1개(가장 급한 것) + 나머지 회차는 목록 배지 |
| H-1 | 진행/예정 회차 없음 | 빈 상태 "예정된 회차가 없어요" |
| H-2 | 커밋 이메일 미검증 | `warning` 배너 + [지금 인증](→AUTH-07) |
| H-3 | 미제출 · 기한 내 | CTA **[코드 제출하기]**(→T02) |
| H-4 | 응시 기한 임박(D-1/당일) | 마감 라인만 `warning`(평소 차분) |
| H-5 | 응시 기한 마감 | "마감됨" · 제출 불가(재응시 없음) |
| H-6 | 제출 완료 · 세션 대기 | CTA **[검증 세션 시작하기]**(→T04) |
| H-7 | 세션 진행 중 | CTA **[세션 이어하기]** · 저장 지점 안내 |
| H-8 | 회차 완료 · 결과 공개 | [결과 리포트 보기](→T05) |
| H-9 | 회차 완료 · 결과 비공개(GOV-03) | 잠금 "결과가 아직 공개되지 않았어요" |
| H-10 | 분석 진행 중(제출 후 DP 추출) | 스트립 `analyzing` + CTA **비활성 "분석 중 · 준비되면 알림"**(세션 CTA 활성화 안 함) |
| H-11 | **분석 실패**(제출 후, MEAS-02A/02B 실패) | `warning` 히어로 + CTA **[확인하러 가기]** → SC-T02 S8 복구 경로. **H-10 스피너에 영구 정지하지 않도록 반드시 분리**(T02 S8과 짝) |

## 7. 인터랙션 & 화면 전이

- 진행 회차 CTA → 미제출 **SC-T02** / 제출완료 **SC-T04** / 세션완료 후 회차완료 → **SC-T05**.
- 지난 회차 [결과] → **SC-T05**(GOV-03 공개 범위).
- 커밋 미검증 배너 → **SC-T02**(AUTH-07).
- 회차 반복: 다음 회차 도래 → 홈에서 새 진행 회차로 갱신(신규 커밋 스냅샷·B2).
