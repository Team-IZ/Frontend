측정 계획 (체크포인트 · 추출범위 · 검증포커스 · 응시현황) 워크스페이스 경유 진입

ℹ 이 화면(SC-M03)은 프로젝트 워크스페이스 › 측정 계획 탭을 통해 프로젝트 컨텍스트로 진입하는 독립 화면입니다(D77·D78). 측정계획은 프로젝트 하위(위계)지만 화면·정의서·예외(PLAN 30건)는 독립 유지 — 워크스페이스에 흡수된 게 아님. 응시 분모만 팀·레포 탭의 단위 N에서 상속(옛 "48/48" 고정 분모 오류 교정). 이 단독 버전은 컨텍스트 없는 참고용.

측정의 언제(체크포인트)·무엇을(추출범위)·어디에 초점(포커스)을 정하고, 진행 중 회차의 응시를 모니터링. 검증 포커스는 교육생 비노출(A4 — 미리 알면 게이밍). 최종 회차는 단 1건. 매니저 앱 셸 공유.
