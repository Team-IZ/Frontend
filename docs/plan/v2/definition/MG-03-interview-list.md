# MG-03 · 면담 목록

## 1. 한 줄

**위험 판정이 켜진 학생의 작업 큐.** 상태를 여기서 관리한다.

> 위험 = 면담 대상이다. 위험 유형이 켜지면 자동 등재되므로 **별도의 위험 목록을
> 두지 않는다**(17번 5절).

## 2. 진입 · 이탈

| | |
|---|---|
| 진입 | 좌측 네비 · MG-01 행 |
| 이탈 | `[브리프 열기]` → **MG-04 모드** |

### 체크박스를 두지 않는다

행마다 체크박스를 달았다가 지웠다. **위험 판정이 켜지면 자동 등재되므로 여기 있는
사람이 곧 대상이다** — 체크가 뜻하는 바가 없다. *"체크를 풀면 제외"* 도 어색하다.
**액션은 버튼을 누르는 것**이지 체크 상태를 바꾸는 것이 아니다.

| | |
|---|---|
| 제외 | 행의 **`[제외]` 버튼** → 상태가 **`제외`**로 바뀐다 · `[되돌리기]` |
| 정렬 | **이미 급한 순으로 온다.** 사용자가 고를 일이 아니다 |

**상태 3종이 된다 — 예정 / 종결 / 제외.**

| 상태 | 뜻 |
|---|---|
| **예정** | 등재됐고 아직 안 만남 |
| **종결** | 만났다 |
| **제외** | 매니저가 이번 회차 대상에서 뺐다 (되돌릴 수 있다) |

**`진행 중`이 없는 이유:** 면담하는 30분 동안만 존재하고 그동안 매니저는 화면을 안 본다.

### `후속 필요`를 만들지 않는다 — 만나면 종결이다

16번 ②가 `진행 중` 대신 `후속 필요`를 제안했다. *"해결하지 못한 면담"* 을 관리하자는
것이었고, 뜻은 맞다. **그런데 그 상태를 목록이 들고 있으면 안 된다.**

`다음에 할 것`을 확인하는 시점은 **다음 회차**다(16번 4-3 — *"다음 회차 브리프 ①칸 위에
⚠와 함께 뜬다"*). 그러면 **이번 회차 목록 안에서는 그 행을 닫을 방법이 없다.**

```
미프 3차 목록   박도현 [후속 필요]  ← 미프 4차 면담 때까지 안 바뀜
                                  ← 미프 4차에 위험이 안 켜지면 영영 안 바뀜
```

**작업 큐에 처리 불가능한 항목이 쌓인다.** 큐는 비워져야 큐다.

확인 액션(`[확인 기록]`)을 새로 만드는 안도 검토했다가 접었다 — **없는 기능을 화면이
만드는 쪽**이고, 시스템이 *"흐름을 그려왔다"* 를 알 방법도 없다.

> **만나면 종결이다.** 약속 추적은 **브리프가 한다** — 다음 회차에 브리프를 열면
> ①칸 위에 ⚠로 뜬다(16번 4-3). 목록은 **이번 회차에 누구를 만나야 하는가**만 답한다.

**대신 종결 행에 `다음에 할 것`을 그대로 보여준다.**

```
종결  박도현 B반  [단계 하락]  2단 이하 1 → 2  7/24 면담 · 다음에 할 것 — "흐름 그려오기"
종결  서지훈 C반  [단계 하락]  2단 이하 1 → 2  7/22 면담 · 다음에 할 것 — 없음
```

**상태가 아니라 기록**이다. 다음 면담을 열 때 무엇을 이어받는지 목록에서 바로 읽힌다.

### 대기는 개인별이 아니라 회차 경과다 — 그리다가 발견한 것

목록에 `대기 6일 / 2일 / 1일` 열을 넣었다가 지웠다. **리포트가 회차 마감 후 일괄
발행되므로**(14번 10-2) 위험 판정도 **그 순간 한꺼번에 켜진다.** 등재일이 회차 안에서
전부 같다.

```
미프 3차 마감 → 리포트 일괄 발행 7/21 → 위험 판정 등재 7/21 (전원 동일)
```

**그러면 개인별 대기 일수는 모두 같은 값이라 열이 낭비고 정렬 키로도 쓸모없다.**
16번 4-1의 `대기 최장 N일`은 개인 편차를 가정한 것인데, 일괄 발행 구조에서는 그 편차가
안 생긴다.

| | |
|---|---|
| 상단 경고 | **`미프 3차 면담이 6일째 안 끝났습니다`** — 개인 최장이 아니라 **회차 경과** |
| 정렬 | 대기가 아니라 **위험 유형 → 2단 이하 개수** |
| 마지막 활동 | `7/21 등재`(예정) / `7/24 면담 · 다음에 할 것 — "흐름 그려오기"`(종결) — **한 열에 통합** |

**면담일은 사람마다 다르다.** 그래서 `마지막 활동` 열은 예정에는 등재일, 종결에는
면담일과 약속을 쓴다 — 상태 열이 옆에 있어 어느 쪽인지 읽힌다.

### 면담 효과(회복 여부)를 표시하지 않는다

`종결` 행에 `다음 회차 3단 회복 ↑`을 그렸다가 지웠다. **두 가지 이유로 만들 수 없다.**

**① 회차를 건너 개념을 비교할 수 없다.** 회차마다 검증 개념이 통째로 바뀐다 — 미프
3차의 `HITL Trigger`와 미프 4차의 `인증 흐름`은 다른 것이고, `2단 → 3단`은 **같은 것이
나아진 게 아니라 다른 것을 물은 결과**다. MG-06 격자에 *"가로로 이어 읽지 않는다"* 고
써 놓고 여기서 가로로 읽는 셈이 된다.

**② 면담이 원인이라는 주장이 된다.** 16번 ①이 정반대로 말한다 — *"면담 30분으로 학생이
개념을 이해하게 만들 수는 없다. 그건 교안과 강사와 학생 본인의 시간이 하는 일이다."*
면담이 바꾸는 것은 **다음 한 주를 어디에 쓰는가**이지 도달 단계가 아니다.

> **회차를 건너 비교되는 값은 하나뿐이다** — `n = 그 회차의 2단 이하 개념 개수`.
> 9-2가 개념 이름이 아니라 **개수**로 정의된 이유가 이것이다. 개념은 매번 바뀌지만
> *"3개 중 몇 개에서 멈췄나"* 는 회차가 달라도 같은 질문이다. 그래서 **위험 판정은
> 성립하고 회복 판정은 성립하지 않는다.**

**16번의 *"회복 여부는 다음 회차 도달 단계가 이미 말해준다"* 는 완료율을 만들지 말라는
논거**였지 회복 배지를 달라는 뜻이 아니다.

**게다가 중복이다.** 다음 회차에 그 사람이 다시 등재됐는지는 **목록에 이미 드러난다** —
회차 필터를 미프 4차로 바꾸면 재등재된 사람이 `예정`에 있다.

종결 행에 남는 것은 **면담일과 `다음에 할 것` 확인 여부**뿐이다.

## 4. 데이터

위험 유형 · `2단미달 n/3`(하락은 `이전 → 이번`) · 등재일 · 상태 · 마지막 면담일 ·
`다음에 할 것` 확인 여부.

**효과·회복 판정은 데이터에 없다**(위 절). 다음 회차 도달 단계는 **다음 회차 목록의
등재 여부**로만 나타난다.

## 5. 액션

| | |
|---|---|
| `[브리프 열기]` | **그때 브리프를 만든다**(미리 만들어 두지 않는다) |
| `[무효 확인]` | **무효 응시는 자동 확정하지 않는다**(9-4) — 결과를 지우는 일이라 오탐 비용이 크다. 모달에서 **시스템이 본 것**(무응답 문항 수·복사 여부·응답 시간)을 보여주고 묻는다. 브리프보다 **먼저** 처리할 일이라 그 행의 버튼이 바뀐다. **목록 맨 위**에 온다 — 9-4가 *"못하는 것보다 안 하는 것이 더 급하다"* |
| `[제외]` | 상태를 `제외`로. **되돌릴 수 있다** |
| 체크 해제 | 대상에서 제외 |
| 회차 필터 | 주·월이 아니라 **프로젝트 회차** |
| 이름 클릭 | **MG-06 교육생 상세**(조회) — `[브리프 열기]`(작업)와 목적지가 다르므로 **행 전체 클릭은 만들지 않는다** |

## 6. 상태 — 왜 그렇게 정했나

> **케이스 표는 목업에 있다** — [`manager/interviews.html#cases`](../wireframe/manager/interviews.html#cases).

### 대상은 자동 등재된다

매니저가 고르는 목록이 아니라 **이해도 확인 결과가 만든 목록**이다. 그래서 회차 결과가 나오기 전에는 **비어 있는 것이 정상**이고, 그 사실을 화면이 밝힌다.

**대상 0일 때** — `2단 이하가 1개인 사람은 다시 보기로 처리된다`를 함께 쓴다(9-2). 안 쓰면 *"위험한 사람이 정말 없나"* 를 의심하게 된다.

### 무효 응시는 자동 확정하지 않는다

시스템은 **본 것**만 보여준다 — 무응답 문항 수 · 응답 시간. **판정은 사람이 한다**(9-4).

`못한 것`과 `안 한 것`은 다르고, 그 차이는 화면이 알 수 없다. 그래서 `[무효로 처리하고 재응시 안내]`와 `[그대로 두기]`를 나란히 둔다.

### 제외는 되돌릴 수 있다

체크박스가 아니라 **버튼**이다 — 누르면 상태가 바뀌고 `되돌리기`가 남는다. 잘못 눌러 사라지면 **그 사람은 이 회차에서 아무도 안 본다.**

### 1차에는 위험 유형을 붙이지 않는다

유형이 **직전 회차 대비**라 비교 대상이 없다(9-5). `관찰` 배지 + `2단 이하 n개`만 쓰고 안내 줄로 밝힌다.
