#상태처리표현 / 다음 행동
1최초 로그인 판정 실패처리 보류자동 실행 보류 · 수동 진입(도움말) 제공
2이미 완료 사용자 자동 재실행처리 차단자동 실행 차단(수동만)
3중간 이탈예외 처리마지막 완료 단계 저장 · 재접속 시 이어보기
4설정 화면 접근 권한 없음상태 표시해당 단계 설명만 표시 · 직접 이동 생략
5진행 상태 저장 실패기존 유지현재 세션 진행 유지 · 재저장
6튜토리얼 콘텐츠 조회 실패예외 처리기본 도움말 링크 제공(폴백)
7재열람 요청예외 처리완료 이력 변경 없이 수동 실행
