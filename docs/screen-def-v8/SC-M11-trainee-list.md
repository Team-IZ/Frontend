# SC-M11 · 교육생 리스트

> 소스: 기능명세서 v8 DASH-17(교육생 리스트·검색·페이지네이션) + AUTH-11(관리 이력 접근권한 통제).
> 배치: P0 · 매니저 조회 경로 진입점. 매니저 앱 셸 공유.

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 역할 | **매니저** (담당 기수·범위) |
| 진입 경로 | 매니저 셸 좌측 네비 '교육생' |
| 연계 FR | **DASH-17**, **AUTH-11**(이력 열람 권한), 전역: SYS-02·AUTH-09 |
| 이번 배치 범위 | 이름·이메일 검색·반 필터·계정 필터·페이지네이션, 개별 상세(SC-M06) 진입. **측정과 독립된 순수 디렉터리**(D104) |
| 안 하는 것 | **위험도 정렬·판정 없음**(DASH-17 — SC-M01 전담) · **팀·회차·제출·점수 없음**(측정 상태는 프로젝트 워크스페이스·대시보드·상세 소관·D104) |
| 다음 화면 | 행 클릭 → SC-M06(개별 상세). 파고들기는 전부 상세로(마스터-디테일·D89) |

## 2. 목적 & UX 설계 근거

- **순수 디렉터리다: 찾아서 상세로 가는 통로(D104).** 정체성(이름·반)이 척추. 이름으로 특정 교육생을 찾아 SC-M06으로. **위험도 정렬은 일부러 뺀다**(DASH-17) — 위험 우선순위는 SC-M01 전담, 역할 중복 방지.
- **측정과 독립(D104).** 회차·제출·세션·점수·팀은 목록에 안 넣는다. 이유 셋: ① 원 규정이 "디렉터리·결과 뷰어 아님" ② **관심사 분리** — 회차/제출 현황은 프로젝트 워크스페이스(PLAN-04)·대시보드 SC-M01 소관, 리스트에 넣으면 기능 중복·동기화 부담 ③ **측정 독립** — 명단·활성화·반 배정·이탈/복귀 같은 학생 관리는 회차 0개·측정 시작 전에도 필요. 목록엔 정체성 + 계정 상태(활성/초대/비활성)만.
- **파고들기는 상세로(마스터-디테일·D89).** 리스트는 "찾기"까지. 회차별 제출·커밋이메일 검증(AUTH-07)·반 이동 이력·프로젝트별 팀은 전부 상세(SC-M06). 리스트는 극단적으로 얇게(4컬럼).
- **팀 컬럼 제거(D104·G3).** 팀은 프로젝트마다 재편성되는 유동값(TeamMembership 프로젝트 종속·D77~90). 디렉터리 척추는 안정 정체성(이름·반)이어야 하므로 유동값인 팀은 목록에서 뺀다(02-domain-hierarchy §3 안정/유동 분리). 팀은 상세에서 프로젝트별로.
- **규모 대응.** 이름·이메일 검색·반 필터·계정 필터(기본=활성)·페이지네이션(중앙 정렬, D22).
- **v1 조회 범위(D20):** 매니저는 **자기 기관 내 모든 교육생**을 봄. 권한 토글 없음. AUTH-11의 세밀한 타 매니저 이력 열람 통제는 **고도화 보류**(재개 조건: 프라이버시 이슈·기관 요청). SYS-02 테넌트 격리·조회 AuditLog는 유지.

## 3. 정보 구조 & 레이아웃 (매니저 앱 셸 · 데스크톱)

**콘텐츠(4컬럼·D104):**
- 상단 **툴바(한 줄):** 이름·이메일 검색 · 반 필터 · 계정 필터(기본=활성) · **정렬(이름순 등 중립 축만)** · [우측] **결과 건수(1–20/48)**
- **리스트 테이블:** 교육생(아바타·이름 링크·이메일) · 반 · 계정 상태(비활성 시 사유·일자) · (진입). **팀·회차·제출·점수 없음**(측정 독립·D104)
- 하단 **페이지네이션(중앙 정렬, D22)**. 건수는 툴바 우측(D23)

행 클릭/이름 링크 → SC-M06. 반응형: 웹 기준.

> **접근성(D104·G5):** 이름=`<a>` 링크+`aria-label`(접근名)·포커스링, 아바타 이니셜·화살표 `aria-hidden`. 행 전체는 보조 클릭영역.
> **정렬(D104·G7):** "최근 활동순"은 약한 위험 신호(DASH-17 위험 정렬 배제와 회색지대)라 제외. 이름 등 중립 축만.
> ⚠️ 트랙 재조정(D16): DASH-17은 "트랙 필터"라 표기. 본 설계는 **반 필터**로 두고, 트랙(전공 축) 확정 시 필터 축 추가/병합.
> 조회 범위 토글·잠금은 제거(D20) — v1 기관 내 개방.
