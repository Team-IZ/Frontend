## 2. 목적 & UX 설계 근거

- **리포트는 문서형 + 앵커 목차 + 온디맨드 근거 패널.** 한 번에 스캔이 아니라 읽는 문서다(view-patterns). 종합 리포트는 좌측 앵커 목차로 섹션 이동, 각 수치는 **클릭해야 근거가 뜬다**(RPT-05). "근거 없는 수치 표시 금지"(A2)의 **유일한 예외** — 클릭 전에는 근거 데이터를 렌더링하지 않는다(성능·정보과다 방지, RPT-05 규칙).
- **세 리포트는 같은 집계원천(SSOT)에서 나온다(B8).** 종합(RPT-01)·체크포인트(RPT-04)가 **동일 지표를 다른 값으로 보이면 안 된다** — 공통 집계 함수 결과를 단일 진실원천으로 저장하고 RPT-04는 그 스냅샷을 재사용(RPT-01 case7·RPT-04 case4). 화면에 "단일 집계원천(SSOT)" 배지로 명시.
- **종합(RPT-01) = 현재 기수 상태.** 이해도 분포·성장 추이·취약 단계·개입 효과·회복률 + AI 자연어 요약·커리큘럼 보완 제안. **AI 요약은 원본 집계값과 일치 검증을 통과한 문장만** 노출, 불일치 문단은 재생성, AI 실패 시 정형 지표는 유지(RPT-01 case3·RPT-04 case7).
- **체크포인트(RPT-04) = 회차 종료마다 자동생성된 변화 피드.** 직전 회차 대비 **위험 증가·회복 개선·응시 변화** 하이라이트, 매니저 알림. 1회차는 직전 스냅샷이 없어 diff 생략(case2).
- **개인 최종(RPT-02) = 과정 종료 리포트, 매니저용/교육생용 버전 분리.** 5축 최종 점수·등급·강약점. **최종 등급은 최종회차 완료자만**(B3). 매니저용은 루브릭·채점 근거 포함, **교육생 공개용은 GOV-03 허용 범위만·루브릭 제거**(A5). GOV-03 미지정 시 기본 비공개(case4).
- **회복률은 자연빈도 병기(B4).** "8/11" 분수를 항상 함께 표시, 표본이 더 적으면 백분율 대신 분수만(RPT-01 case4). 진행 중 개입은 판정 전이라 분모에서 제외.
- **탭 구성:** 종합 리포트 · 체크포인트 · 개인 최종 리포트 3탭 + 공용 근거 패널.

## 3. 정보 구조 & 레이아웃 (매니저 앱 셸 · 데스크톱)

**3탭 + 온디맨드 근거 패널.**

**종합 리포트(RPT-01):** 상단 리포트 헤더(범위·집계 스냅샷 시각·SSOT 배지·[PDF 내보내기]). 본문 = **좌측 앵커 목차 + 문서**. 섹션:
- AI 자연어 요약 + 일치검증 경고 + 커리큘럼 보완 제안
- 이해도 분포(구간별 인원 히스토그램, 결측 병기)
- 성장 추이(회차별 평균 라인, 축 눈금 실제 범위)
- 취약 단계(5축 평균 막대, 최약 단계 강조)
- 개입 효과·회복률(지표 카드 + 자연빈도)
- 각 수치에 [근거 열람] → RPT-05 패널.

**체크포인트(RPT-04):** 좌측 회차 리스트(자동생성 상태·시각) + 우측 선택 회차 스냅샷. **회차 리포트는 "이번 회차에 무엇이 바뀌었고 누구를 조치할지"까지 담는다**(카운트만으로는 실행 불가):
- 회차 메타(검증 포커스·기준 회차·집계 버전·알림 상태)
- 응시 현황(응시/미응시/총원 + 직전 대비 응시 변화, 미응시 명단 드릴)
- AI 변화 요약(회차 diff 서술 + 일치검증)
- **이번 회차 스냅샷 Δ 표**(지표별 이번/직전/Δ, change-first, 종합과 동일 SSOT)
- **변화 하이라이트 → 대상 명단**(회복자·신규 위험자·미응시자, 각 명단 → SC-M06/M04 드릴)
- **이번 회차에 판정된 개입**(개입별 회복/미회복/다음 회차 대기 = 회복률의 근거)

"종합과 동일 집계(SSOT)" 배지. 1회차는 직전 스냅샷이 없어 'diff 없음'.

**개인 최종(RPT-02):** 좌측 교육생 리스트(완료/최종 미완료 배지) + 우측 최종 리포트. **숫자 표가 아니라 서사가 있는 리포트**:
- **총평·성장 서사**(강점·회복 스토리 요약 — 명세 "최종 성장 추이·강점·보완 영역 요약 구성")
- 최종 등급(최종회차만·B3) + 매니저용/교육생 공개용 **버전 토글**
- 5축 회차 추이·최종 점수 표 + **주요 전환 구간**(명세 "주요 전환 구간 계산"; 개입과 연결 — 예: 반례대응 "2회차 개입 후 ↑")
- 강점/보완 영역
- **받은 지원·개입 이력**(어느 회차에 무슨 개입 → 효과, INTV 연결 — 매니저가 성장의 인과를 봄)
- 매니저 전용 루브릭 블록(공개 전환 시 자동 제거 안내)

**RPT-05 근거 패널(의사결정 중심):** 밑줄 친 **수치** 또는 [근거·명단 ▸] 버튼 클릭 시 우측 슬라이드 패널(배경 딤, 클릭 전 미렌더). **백엔드 산출식을 나열하지 않고 매니저가 쓰는 증거를 앞세운다**:
- 신뢰 한 줄(표본 수·일치검증 ✓)
- **결과별 명단**: 미회복(=조치 대상, 최상단 강조·재개입 링크) / 회복 / 판정 대기
- **개입 방식별 회복 효과**(멘토링 4/4·코칭 2/3·과제 2/4 → 다음 개입 방식 선택 근거)
- 산출식·집계 버전은 **각주로 강등**(신뢰 확인용, 헤드라인 아님)
- 명단 → SC-M06/M04/M07 드릴, 대량 이력 페이지네이션.

반응형: 웹 기준.
