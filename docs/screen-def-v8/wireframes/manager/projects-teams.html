프로젝트 · 팀 워크스페이스 경유 진입

ℹ 이 화면(개요·팀·레포)은 프로젝트 워크스페이스의 [개요]·[팀·레포] 탭으로 진입합니다(D77·D78). SC-M13 정의서는 독립 화면으로 유지(ORG-03 프로젝트 + ORG-02 팀 = 예외 16건) — 워크스페이스는 프로젝트 컨텍스트를 고정하는 허브일 뿐, 이 화면을 흡수한 게 아님. 측정계획은 별개 화면(SC-M03), 결과는 SC-M08. 이 단독 레이아웃은 컨텍스트 스위처 없는 구 버전 참고용.

SC-M02에서 분리된 운영 화면(D18). 프로젝트는 기수 내내 여러 개(개인/팀). 레포는 프로젝트가 아니라 팀별·학생별 — 목록엔 유형·대상 반·기간·레포 연결 현황(N/M)만, URL은 팀 카드/학생별에서. 팀은 프로젝트마다 새로 편성(D16).
