## 2. 목적 & UX 설계 근거

- **히트맵은 "어디서 무너지는가"를 한눈에.** 대시보드가 위험 학생을 인박스로 보여준다면, 히트맵은 **단계·영역 단위의 공통 취약 패턴**을 색으로 드러낸다(view-patterns: 히트맵). 색이 곧 우선순위 — 빨간 셀이 커리큘럼·개입 보강 지점.
- **이해 단계(DASH-14) = 깊이 사다리.** L1(코드이해)→L2(설계논리)→L3(대안비교)→L4(반례대응)→L5(자기수정). "이 기수는 L2까지 가는데 L3에서 무너진다"를 즉시 읽게 한다. **단 L1~L5는 별도로 측정한 축이 아니라 5축 점수를 깊이 순서로 재배열한 파생 표현**(B6) — 화면에 상시 명시해 "새로 측정한 지표"로 오해되지 않게 한다.
- **기술영역(DASH-15) = 답변 기준 취약도.** 인증·동시성 등 영역별 취약. **핵심 함정: 취약은 코드가 아니라 답변에서 일어난다.** "인증 파일에서 질문받았다"와 "인증을 이해 못 했다"는 다른 사실 — 취약도는 **ENG-01 축별 채점의 failure_tag enum을 GROUP BY**한 집계(답변 기준)여야 하며, 질문받은 파일 비율을 취약으로 집계하면 안 된다. 미분류는 `unmapped`로 별도 표기(품질 지표).
- **회차 비교는 직전에 고정하지 않는다(ENG-02).** 현재 상태(절대 수준) 외에, **존재하는 임의 두 회차를 골라 비교**(직전 2→3 / 최초 1→3 / 임의 구간). ENG-02 표시 권고("현재값·직전 대비·최초 대비 누적 동시 제공")를 그대로 구현 — 셀 클릭 시 세 값을 함께 보여준다. 선택 회차 중 하나라도 데이터 없으면 회색·산출 불가(B4).
- **기수 › 반 › 개인 드릴다운.** 24명을 한 번에 나열하지 않는다. 기수 평균 + 반별을 기본으로, **반 행 클릭 → 그 반 학생 히트맵, 학생 클릭 → 개인 페이지**. 개인 페이지 = **회차(행) × 이해 단계(열) 궤적** + 개입 마커(회복 원인 추적). 세부(세션 원문·근거)는 SC-M06, 최종 등급·총평은 SC-M08 — 이 페이지는 회차×단계 히트맵 궤적에 특화(중복 아님).
- **진단은 액션으로 이어진다.** "L3에서 무너진다"·"동시성이 최대 취약"에서 멈추지 않고 **[교안 보강 검토(CUR)]·[취약 대상 개입(INTV-01)]** 로 연결. 히트맵은 진단이자 조치 진입점.
- **근거 없는 색은 없다(A2).** 셀 클릭 → 그 셀을 만든 대상·세션·근거 팝오버(취약 학생 명단 → 개별 상세). 근거 trace 없는 셀은 표시하지 않는다. DASH-15 취약도는 **자연빈도 병기**(예: 관련 세션 40건 중 24건).
- **표본 부족은 회색(B4).** 세션 N<5 영역·1회차 단독은 산출 유보·회색 셀.
- **축→단계 매핑은 가정임을 표기.** L1~L5 = 5축을 인지 깊이 순서로 정렬한 것 — 순서 자체는 인지 난이도 가정이므로 명세 최종 확인 필요(정직한 플래그).
- **탭 구성:** 이해 단계 · 기술영역 2탭 + 회차 비교 모드 + 개인 페이지(드릴 대상).

## 3. 정보 구조 & 레이아웃 (매니저 앱 셸 · 데스크톱)

**2탭 + 공용 컨트롤(행 단위·표시 모드·범례).**

**이해 단계 히트맵(DASH-14):** 행 = 기수 평균 + 반별(또는 개인 토글), 열 = L1~L5. 셀 = 축 평균 점수, 5단계 색(취약 빨강 ~ 양호 초록), 표본 부족 회색. 상단 insight 문구("L3에서 무너진다"). B6 파생 명시 각주.

**기술영역 히트맵(DASH-15):** 행 = 기술영역(동시성·인증·비동기·상태관리 등), 열 = 반별 + 기수 전체. 셀 = 취약 세션 비율(%), 색. **caveat 배너**(답변 기준·failure_tag, 질문 파일 아님). 표본 부족(N<5) 회색.

**표시 모드(ENG-02):** 현재 상태 ↔ **회차 비교**. 회차 비교 = 두 회차 선택기([A회차] vs [B회차]) + 프리셋(직전 2→3 / 최초 1→3 / 구간). 셀 = ▲개선(초록)/▼악화(빨강)/±0.

**개인 페이지(드릴 대상):** 드릴 breadcrumb(기수 › 반 › 개인) + 학생 선택기 + **회차(행) × L1~L5(열) 궤적 히트맵** + 개입 마커(개입 회차 표시) + 개입 이력 줄 + SC-M06/M08 링크.

**셀 근거 팝오버(A2):** 취약 셀 클릭 → 대상 통계(N명 중 M명 / 세션 자연빈도)·취약 대상 명단(→ SC-M06)·근거 요약·B6 파생 명시.

**진단 액션:** insight에서 [교안 보강 검토(CUR)]·[취약 대상 개입(INTV-01)] 진입.

반응형: 웹 기준. 히트맵은 가로 스크롤 컨테이너.

## 7. 인터랙션 & 화면 전이

- **드릴다운:** 기수 › 반(행 클릭) › 개인(학생 클릭 → 개인 궤적 페이지) → SC-M06.
- 셀 클릭 → 근거 팝오버 → 취약 대상 명단 → **SC-M06**(개별 상세 세션 탭, 근거 원문).
- 취약 영역(동시성·인증 등) → **INTV-01** 개입 유형 추천의 "특정 기술영역 집중" 분기 근거. 취약 단계 → **CUR 교안 보강** 검토(flow-contract 환류).
- 개인 궤적의 개입 마커 → **SC-M07/M08** 개입·리포트 연결.
- 표시 모드로 현재 ↔ 회차 비교(임의 두 회차·ENG-02).
