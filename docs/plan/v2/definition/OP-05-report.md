# OP-05 · 리포트 (오퍼레이터) — 마스터-디테일

## 1. 한 줄

기수 단위 **고정 시점 스냅샷.** 외부에 내놓는 산출물이다.

> 분석(OP-02)과 겹쳐 보이지만 상태가 다르다 — 분석은 **실시간 탐색**, 리포트는
> **그 시점 값으로 얼린 것**이다. 본문은 분석 컴포넌트를 재사용하고 새로 그리지 않는다.

## 2. 진입 · 이탈

좌측 네비 → 좌 목차에서 섹션 전환.

## 3. 뷰

```
리포트 · 7기                                   [생성 시점 2026-07-31]

좌 목차                       우 본문
──────────────               ─────────────────────────
기수 종합                     선택한 섹션 하나
  개념별 도달 분포
  반 비교
  집단 미달
  회차별 추이
개인 최종 (250명)             개인 선택 → 그 사람 최종 리포트
```

**섹션 전환이지 앵커 스크롤이 아니다.** 목차를 눌렀는데 스크롤이 튀면 지금 어디인지가
사라진다.

**숫자 점수는 없다.** 도달 단계 분포와 서술로 쓴다.

## 4. 데이터

기수 종료 시점으로 고정된 집계 · 개인 최종 회차 결과. **재시험은 조직 단위 수치에
넣지 않는다**(1차만) — 하위권 개선분만 평균을 밀어 올린다.

## 5. 액션

섹션 전환 · 개인 선택 · 내보내기(PDF).
