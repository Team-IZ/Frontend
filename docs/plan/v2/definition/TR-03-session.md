**자기 코드의 특정 지점에 대해, 그 자리에서, 왜 그렇게 됐는지 말한다.**

## 2. 진입 · 이탈

|---|---|
| 진입 | TR-01 `[세션 시작]` · 시작 전 안내 화면 |
| 이탈 | 3문제 종료 또는 하드 상한 70분 |

## 3. 뷰 — 한 문제 = 한 화면

**세 문제는 서로 다른 개념이고 코드 지점도 파일도 다르다.** 같은 대화의 연속이 아니므로
문제가 바뀌면 화면을 갈아탄다. **끝난 문제는 다시 열 수 없다** — 지금 문제와 무관한 데
시간을 쓰고, *"아까 그거 틀린 것 같은데"* 만 남는다.

```
문제 2/3 ▬▬▬                          12분 경과 · 시간 제한 없어요
──────────────────────┬───────────────────────────────────────
 HITL Trigger 조건     │  ◆ 질문 1
 nodes.py             │  이 함수는 무슨 일을 하나요? 어디에서
                      │  쓰이는지도 같이…      ↳ nodes.py:12–20
  8 MAX_ITERATIONS=3  │            내 답변 · state를 받아서…
 12 def should_...    │
 14   if retry>MAX: ← │  ◆ 질문 2
 15     return True ← │  교안은 세 조건을 봤는데 여기선 둘만…
 17   if REJECTED:  ← │                    ↳ nodes.py:14, 17
 18     return True ← │
 20   return False    │
                      ├───────────────────────────────────────
 ▸ 이 함수를 쓰는 곳    │ ┌───────────────────────────────────┐
   graph.py:41        │ │ 답을 입력해 주세요                  │
                      │ └───────────────────────────────────┘
                      │ 0자 · 3~5문장       붙여넣기는 막혀 있어요
                      │ [다시 설명]  제출하면 고칠 수 없어요 [제출]
```

**코드는 왼쪽에 고정, 대화는 오른쪽.** 학생은 **코드를 보면서 답을 쓴다** — 위아래로
쌓으면 "설명 대상"과 "설명 쓰는 곳"이 멀어져 계속 스크롤하게 된다. 좌우로 두면 둘 다
시야에 있고, 스크롤은 대화 쪽에서만 일어난다.

### 코드는 블록 전체를 준다

**몇 줄만 떼어 주면 L1을 물을 수 없다.** L1의 정의가 *"무엇을 하고 어디랑 연결되는지"*
인데, 함수 시그니처와 호출부가 없으면 연결을 말할 근거가 없다.

**반대로 레포 전체를 주면 이해도가 아니라 코드 찾는 속도를 잰다**(7-5). 그래서
`expand_to_block`이 잡은 **함수·클래스 단위**를 주고, 200줄이 넘으면 `line ± 30`으로 자른다.

| | |
|---|---|
| 블록 전체 | 함수·클래스 단위. 보통 20~40줄 |
| 주변 몇 줄 | 상수 정의 등은 **흐리게** — 맥락이지 대상이 아니다 |
| **호출부** | `context.imported_by`(7-6). **접어 두고** 필요할 때 편다 |
| 하이라이트 | 지금 질문이 가리키는 줄. **질문마다 옮겨간다** |

**코드는 문제 내내 고정(sticky)된다.** 질문마다 다시 그리면 "같은 코드를 계속 보고
있다"는 사실이 흐려진다. 스크롤은 하나이고 대화만 아래로 흐른다.

### 제출은 되돌릴 수 없다 — 매 턴 알린다

세션 시작에 한 번 고지하고 끝내지 않는다. 확인 모달을 매번 띄우면 30~40분간 열 번 넘게
뜨므로, **버튼 옆 한 줄**로 상시 알린다.

| | |
|---|---|
| 보통 | `제출하면 고칠 수 없어요` |
| **마지막 문제의 마지막 답변** | 라벨이 **`답변 제출하고 마치기`** 로 바뀌고 `마지막 답변이에요 · 제출하면 끝납니다` |

**계단 4단** — 코드이해 → 설계논리 → 대안비교 → 반례대응.
L1·L2 필수 / L3·L4 선택. **힌트를 다 쓰고도 미달이면 그 문제는 거기서 끝난다.**

**힌트는 재진술만.** 질문을 다르게 말할 뿐 코드 위치·선택지·답의 방향을 주지 않는다.
단계당 2회. **써도 점수가 깎이지 않는다** — 버튼 아래에 상시 적는다.

**2회를 다 쓰면 버튼을 없애지 않고 문구로 바꾼다** — *"더 이상 설명해 드릴 수 없어요.
아는 만큼만 써 주세요 — 빈칸으로 두지 않는 게 좋아요."* 버튼이 사라지면 왜 사라졌는지
모르고, 마지막 문장이 없으면 포기하고 빈칸을 낸다(무효 응시가 된다).

**답변이 짧으면 알리되 막지 않는다.** 15자 미만은 무효 응시 신호이므로(9-4) 제출 전에
`조금 더 써 볼까요? 지금은 짧아요`를 띄운다. **강제하면 의미 없는 글자를 채운다.**

**시간은 안내만 하고 강제로 끊지 않는다.** 계단은 능력 검사이지 속도 검사가 아니다.

## 4. 데이터

| 읽는다 | 문항 3(개념 × 코드 지점) · 교안 재료(gap · siblings · warns) |
|---|---|
| **쓴다** | 답변 원문 · 도달 단계 · 힌트 사용 · **이탈 기록(답변 단위)** · 첫 타이핑 지연 |

**이탈은 세션이 아니라 답변에 붙인다.** 세션 단위로 "이탈 3회"만 남기면 어느 답변이
의심스러운지 알 수 없다.

## 5. 액션

답변 제출 · 힌트 요청(≤2). **뒤로 가기·중단 버튼 없음.**

## 6+. 다시 보기 — 같은 화면의 변형

**별도 화면이 아니다.** 1차와 다른 점만 갈아끼운다(14번 11절).

| | 1차 | 다시 보기 |
|---|---|---|
| 문항 수 | 3개 (개념 3건) | **막힌 개념만** — 1~3개 |
| 문항 내용 | — | **같은 문항** |
| 힌트 | 단계당 2회 | **없음 — 자력만** |
| 판정 | 반영 | **반영 안 됨 · 기록만** |
| 끝나면 | 리포트 발행 대기 | **해설이 열림** → 리포트로 |

### 통과하면 거기서 끝 — 더 깊이 가지 않는다

**11절: "재시험은 재측정이 아니라 리포트를 읽고 이해했는가를 확인하는 것."**

막힌 질문을 통과하면 **그 개념은 끝**이고 다음 개념으로 간다. 계단을 더 올라가지 않는다.

| | |
|---|---|
| 1차 | 막힐 때까지 올라간다 — L1 → L2 → L3 → L4 |
| 다시 보기 | **막혔던 질문 하나.** 통과하면 다음 개념 |

**올라가면 재측정이 된다.** 1차에서 물어본 적도 없는 층을, 판정에 반영하지도 않으면서
묻는 셈이라 학생 시간만 쓴다. `개념당 1회`(11절)와도 어긋난다.

리포트의 비교 표기가 이 규칙과 맞는다 — `처음: 무엇을 하는지까지 → 다시: 왜 그렇게
했는지까지`. **딱 한 칸 오른다.**

### 1차 답변을 세션 안에 보여주지 않는다

막혔던 **질문만** 다시 던진다. 통과한 앞 질문도, 그때 쓴 답변도 화면에 없다.

| | |
|---|---|
| 통과한 앞 질문 | 다시 물을 이유가 없다 |
| **1차 답변** | 리포트에서 이미 볼 수 있다. **세션에 띄우면 그대로 베껴 낸다** |

질문 머리는 `◆ 질문 2`가 아니라 **`◆ 지난번에 막혔던 질문`** 이다 — 번호가 1차와 어긋나면
학생이 "질문 1은 어디 갔지"를 찾는다.

**힌트 버튼을 그냥 없애지 않는다.** 없으면 고장으로 보인다 — 자리에 이유를 적는다:
*"이번에는 다시 설명해 드리지 않아요. 지난번과 같은 질문이라 이미 한 번 들었어요."*

**상단에 `기록에만 남아요` 배지를 상시 띄운다.** 이 사실을 시작 안내에서 한 번만 말하면
20분 뒤에 잊는다 — *"열심히 했는데 반영이 안 된다고?"* 가 되면 다음 회차 참여가 준다.

**시작 안내는 1차보다 짧다.** 전체화면·이탈 기록은 이미 겪었으므로 **달라진 것만** 말한다 —
같은 질문 / 힌트 없음 / 결과는 기록만 / 마치면 해설이 열림.

**무효 응시(0단)는 다시 보기가 아니라 재응시다**(11절). 1차로 취급하므로 1차 화면을 그대로 쓴다.
