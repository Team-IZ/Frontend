# TR-01 · 교육생 홈

## 1. 한 줄

**지금 내가 무엇을 해야 하는지** 카드 하나로 알려준다.

## 2. 진입 · 이탈

로그인 직후 · 상단 `홈`. → TR-02 제출 · TR-03 세션(모드).

## 3. 뷰

```
미프 3차 · AI_LLMOps                              마감 7/14 18:00

┌──────────────────────────────────────────────────┐
│  코드를 제출해 주세요                             │
│  마감까지 1일 4시간                    [코드 제출] │
└──────────────────────────────────────────────────┘

지난 회차   미프 2차 · 리포트 있음 →
```

**상태별 카드 하나만 크게.** 한 번에 하나만 해야 하므로 목록이 아니다.

| 상태 | 카드 |
|---|---|
| 미제출 | `[코드 제출]` · 남은 시간 |
| 제출됨 · 분석 중 | `분석 중이에요. 끝나면 알려드릴게요` · **CTA 없음** |
| 분석 실패 | `다시 제출해 주세요` + 사유 · `[다시 제출]` |
| **응시 가능** | `[세션 시작]` · **남은 시간 D-19h** |
| 응시 완료 | `리포트는 마감 후 함께 발행돼요` |
| 재시험 대상 | `[재시험]` · 마감 **날짜로** 표시 |
| 응시 창 마감 | `응시 기한이 지났습니다` · 담당 매니저 문의 |
| 진행 중인 회차 없음 | `지금은 예정된 일정이 없어요` |

**24시간은 분석 완료 시점부터다.** 제출 기준이면 분석에 2시간 걸린 학생과 20분 걸린
학생의 실제 응시 시간이 달라진다. 창이 열리면 알린다 — 학생이 상태를 폴링하지 않게.

**재시험 마감은 규칙이 아니라 날짜로 쓴다.** `3일 또는 다음 제출일 중 빠른 쪽`을
학생에게 설명하지 않는다.

## 4. 데이터

이번 회차 · 제출/분석/응시 상태 · 응시 창 잔여 · 재시험 지정과 마감 · 지난 회차 링크.

## 5. 액션

`[코드 제출]` → TR-02 · `[세션 시작]` → TR-03(전체화면 · 되돌아올 수 없음 안내 후).

## 6. 상태 — 왜 그렇게 정했나

> **케이스 표는 목업에 있다** — [`trainee/home.html#cases`](../wireframe/trainee/home.html#cases).

### 미제출과 미응시는 다르다

| | 무엇이 끝났나 | 매니저가 보는 사유 |
|---|---|---|
| **제출 마감 지남** | 회차가 **통째로** 끝났다 — 제출이 없으면 분석도 응시도 없다 | `미제출` |
| **응시 창 마감** | **응시만** 놓쳤다 — 제출·분석은 됐다 | `미응시` |

같은 화면으로 그리면 학생이 **무엇을 놓쳤는지** 알 수 없고, 매니저가 보는 기록과도 어긋난다.

### 남은 시간을 모를 때는 말하지 않는다

분석 시간은 코드 크기에 따라 달라 **예측이 틀린다**(A4). `조금 더 걸리고 있어요`도 아니라 **끝나면 알려준다**고만 쓴다.

반대로 **마감은 정확히 쓴다** — 응시 창은 초 단위로(`19:12:04 남음`), 제출은 날짜·시각으로.

### 되돌릴 수 없는 것은 시작 전에 말한다

이해도 확인은 **중간에 나갈 수 없다**. 그 사실을 버튼 위에 먼저 쓴다 — 30~40분이 걸린다는 것과 함께(B5).
