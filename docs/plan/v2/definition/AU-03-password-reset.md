# AU-03 · 비밀번호 재설정

> **v1 그대로.** 바뀐 것 없음.

## 1. 한 줄

메일 링크에서 **새 비밀번호를 정한다.** 요청 → 설정 두 단계.

## 2. 진입 · 이탈

AU-01의 `비밀번호를 잊으셨나요?` → 요청 → (메일) → 링크 → 설정 → AU-01.

## 3. 뷰

```
① 요청                        ② 설정 (링크 진입)
이메일 [           ]          새 비밀번호     [        ]  정책 힌트
     [재설정 메일 보내기]      새 비밀번호 확인 [        ]
                                          [비밀번호 변경]
메일을 보냈습니다.
받은 편지함을 확인해 주세요.
```

**요청 결과는 계정 유무와 무관하게 같은 문구다.** 다르게 답하면 어떤 이메일이 가입돼
있는지 알려주는 셈이 된다.

## 4. 데이터

이메일(요청) · 토큰 + 새 비밀번호(설정). 성공 시 **기존 세션 전부 만료.**

## 5. 액션

메일 발송 · 비밀번호 변경 · 재발송.

## 6. 상태

| | |
|---|---|
| 토큰 만료·재사용 | `링크가 만료되었습니다` + 재요청 |
| 미활성 계정 | 재설정이 아니라 **활성화 안내**(AU-02)로 보낸다 |
| 정책 미충족 | 못 채운 기준만 표시 |
| 변경 성공 | `다른 기기에서 로그아웃되었습니다` 안내 후 로그인으로 |

## 7. 안 하는 것

계정 존재 여부 노출 · 이메일 변경(프로필 소관).
