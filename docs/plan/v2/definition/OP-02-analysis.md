# OP-02 · 분석 — 서브탭 2

## 1. 한 줄

기수 전체에서 **누가 처지고 어디가 무너졌는지**를 정렬·비교로 찾는다.

## 2. 진입 · 이탈

좌측 네비 · OP-01 조치 필요 → 여기. 셀·행 클릭 → 개인(교육생 상세).

## 3. 뷰

```
분석 · 7기                    [미프 3차 ▾]  [반 전체 ▾]
[ 위험·우수 ] [ 히트맵 ]
```

### 위험·우수 탭

```
  검색 · 반 ▾ · 유형 ▾ · [우수 보기]                    (툴바 전부 좌)
──────────────────────────────────────────────────────────────
  이OO  C반  [지속 저점][무효 응시]  2단미달 2/3  최저 1단 · 힌트 4회
  김OO  A반  [단계 하락]            2단미달 2/3  이전 0/3 → 이번 2/3
──────────────────────────────────────────────────────────────
  1–25 / 47                        [< 1 2 >]
```

| | |
|---|---|
| 프로젝트 회차 | **반드시 하나 선택.** "전체" 없음 — 판정이 회차 단위다 |
| 기본 | 위험만 · 사전식 정렬(2단미달 수 → 도달 단계 → 힌트) |
| 우수 | 세그먼트 토글 |

**화면 표기가 그대로 정렬 근거다.** 매니저가 왜 이 순서인지 물을 일이 없어야 한다.
단계 하락 행은 `이전 n/3 → 이번 n/3`을 같이 써서 **배지 근거가 행 안에서 끝난다.**

### 히트맵 탭

MG-02와 같은 구조. **행 드릴다운이 기수 → 반 → 팀 → 개인**으로 한 단계 위에서 시작한다.
프로젝트는 열이라 행 계층에 없다.

## 4. 데이터

위험 유형 판정 · `2단미달 n/3`(직전 대비) · 최저 도달 · 힌트 횟수 · 무효 응시 플래그 ·
우수(반 상위 1~2) · 회차 × 개념 × 조직 단위 평균 도달.

## 5. 액션

회차·반 필터 · 우수 토글 · 행/셀 클릭 → 개인.

## 6. 상태

| | |
|---|---|
| 회차 미선택 | 최근 회차 자동 선택 |
| 위험 0 | `이번 회차 위험 신호가 없습니다` |
| 집단 미달 열 | 개인 위험 사유에서 제외하고 **반 단위로 표시**(14번 9-6) |

## 7. 안 하는 것

| | 어디에 |
|---|---|
| 면담 배정·처리 | **매니저 소관** |
| 개인 이벤트 이력 | **교육생 상세** |
| 고정 시점 스냅샷 | **OP-05 리포트**(여기는 실시간 탐색) |
