## 2. 목적 & UX 설계 근거

- **"설정"이 아니라 "구성".** 이 화면은 기수의 **안정적 뼈대**(사람·소속)를 만들고 관리한다. 프로젝트·팀 같은 반복 운영은 분리(SC-M13) — 성격(안정 vs 유동)이 다르면 화면도 나눈다(D18).
- **기수 개설·매니저 배정은 총괄 매니저(`ORG_MANAGE`)만(D63).** 이 화면(기수 생성·반 구성·매니저 배정·명단)은 **총괄 매니저 권한 게이트**. 담당 매니저(미보유)는 배정된 기수만 운영하며 여기서 생성·배정 불가. 슈퍼어드민이 초대한 첫 총괄이 부트스트랩(닭-달걀 해소). 소규모 기관은 한 사람이 총괄 권한으로 개설+운영 겸직.
- **반이 소속의 축.** 교육생은 반에 배정, 매니저는 반을 담당(D16). 소규모 기수는 자동 '전체' 반 1개로 흡수(분기 없음).
- **명단은 규모가 있다 → 필터·정렬·검색 필수.** 반·계정 상태 필터, 이름/상태 정렬, 이름 검색. 없으면 수십~수백 명에서 특정 학생을 못 찾는다.
- **명단 = 계정 트리거.** 신규 교육생 등록 시 AUTH-06 초대·활성화 자동 트리거.
- **이력 보존.** 교육생 반 이동·매니저 담당 변경은 덮어쓰지 않고 기간으로(D16).

## 3. 정보 구조 & 레이아웃 (매니저 앱 셸 · 데스크톱)

**매니저 앱 셸(신규, 공유):** 상단바(IZ-Get 매니저 · **기수 선택기** · 매니저 신원) + 좌측 네비(대시보드 / 교육생 / 측정 계획 / 프로젝트 / 위험·분석 / 개입 / 리포트 / 교안). **총괄은 여기에 `운영 관리` 항목 하나가 더 붙는다**(담당 nav엔 비노출·D68) — 이 화면이 그 `운영 관리`.

**콘텐츠 — 3탭:**
1. **기수 정보(ORG-01):** 기수명·기간(시작/종료)·교육 단계·상태 · [수정] · 상단바 [기수 생성]으로 신규
2. **반 · 교육생:**
   - **반**: 목록(반명·**담당 매니저 복수 N:M**·인원) + [반 추가] · 담당 배정/변경 · **반 행 클릭 시 그 반 학생으로 명단 필터**(두 표 연결)
   - **교육생 명단**: 툴바(반·상태 필터·정렬·검색) + **[명단 추가(CSV/수기) — 이름+이메일]**(교육생 이름은 여기서 등록 · 활성화 SC-A02엔 이름 입력 없음) + **다중 선택 벌크 바(반 배정·초대 재발송·상태 변경)** + 목록(이름·이메일·소속 반·계정 상태) · 개별 반 배정도 유지
**총괄 전용 한 화면·3탭으로 통합(D67·D68):** 이 화면 전체(기수·반·명단·매니저)는 **총괄 매니저 전용 콘솔 `manager/lead-only/program-admin.html`**. nav 항목명 = **`운영 관리`**(총괄만 보임), 내부는 **한 화면 3탭**(탭 클릭 이동). 담당 매니저 nav엔 안 뜬다. 세 탭:
- **① 기수** — 기수 목록·**[기수 생성]**·종료 + 생성 모달(기수명·기간·단계·초기 명단). 전체 기수 스코프.
- **② 반·명단** — 반 구성·**담당 매니저 배정**·명단 등록(CSV/수기·이름+이메일)·반 배정·벌크. **선택 기수 스코프**(상단 기수 선택기 연동).
- **③ 매니저** — 로스터·**[+ 매니저 초대]**·권한(총괄/담당)·기수 배정. **기관 전체 스코프**(기수 종속 아님). 총괄 최소 1명 유지.
- ORG_MANAGE 없으면 네비 비노출·403. 버튼([기수 생성]·[매니저 초대])은 그 자리에서 모달 오픈.

**담당 매니저는 어디로?** 담당은 기수·반 편성 화면이 없다. **배정된 자기 학생 조회·지도는 `교육생`(SC-M11 리스트 → SC-M06 상세)** 에서. 즉 **총괄 nav엔 '프로그램 관리(기수)'가 있고, 담당 nav엔 없다 — 담당은 '교육생'으로 접근**(D67).

**경계 근거(D66·D67):** 총괄 = **조직 구조를 정하는 것**(기수 생성·반 편성·명단 등록·매니저 배정). 담당 = 배정된 학생을 **측정·지도**. "설정 vs 운영"이 아니라 *"누가 조직 구조를 정하나"* — 반·명단 편성은 자기완결적이어도 조직 구조라 총괄. "총괄 = 담당 + 프로그램 관리 nav 하나".

반응형: 웹 기준(운영 도구, 데스크톱 우선).
