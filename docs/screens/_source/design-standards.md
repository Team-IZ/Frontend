# 디자인 기준서 — 통일성 계약 & 웹 설계 체크리스트

**이 문서는 취향이 아니라 계약이다.** 모든 항목은 **숫자로 셀 수 있게** 썼다 — "일관되게 하라"는 검증 불가능하고, "배지 색 정의는 파일당 1종이어야 한다"는 grep으로 센다.

`design-system-anchor.md`가 **무엇을 쓰는가**(토큰·패턴)라면, 이 문서는 **무엇을 어기면 안 되는가**(계약·검사법)다.

---

## 0. 이 제품이 디자인에 거는 제약 (일반 SaaS와 다른 지점)

기준을 세우기 전에 **이 제품이 무엇인지**부터. 여기서 안 나오는 규칙은 그냥 취향이다.

| 제약 | 어디서 오는가 | 디자인이 감당해야 할 것 |
|---|---|---|
| **사람을 판정하는 도구다** | 위험·불균형·에이스 배지가 교육생 개인에게 붙는다 | 낙인 방지 — 배지는 **근거 문구 없이 단독 노출 금지**(A2). 색은 심각도가 아니라 **의미**를 나른다 |
| **모든 수치에 근거를 대야 한다** | ENG-01 "근거 없는 점수 금지", DASH-03 "근거 문구 없는 순위 표시 금지" | 값 옆에 근거로 가는 길이 항상 있어야 한다. 화면이 지저분해지면 **삭제가 아니라 온디맨드** |
| **값이 회차에 종속된다** | 기수 평균·표준편차·백분위는 전부 회차 due_at 스냅샷 | 비교선은 **회차별 꺾은선**이고, 변동이 작아도 **회차마다 점과 값을 찍어야** 상수로 오독되지 않는다 |
| **매니저는 하루에 이 화면을 수십 번 스캔한다** | 브리핑→시그널→상세→개입의 왕복 | 스캔 효율이 미학보다 위다. 카드 그리드는 대개 오답 |
| **교육생과 매니저가 같은 데이터를 다르게 본다** | GOV-03 열람 범위, D1 매니저 전용 | 같은 값이라도 **역할별 셸이 다르고**, 비노출은 비활성이 아니라 **응답에서 제거** |
| **발행 환경이 외부 리소스를 막는다** | Artifact CSP | CDN·웹폰트·외부 이미지 금지. 검증은 **발행본 기준** |

## 1. 통일성 계약 (검사 가능한 7개)

### C1. 타이포 기준선 — 본문 base **18px** 하나
전 화면 `html { font-size: 18px }` 또는 `body { font-size: 18px }`. 1024px 이하에서 16px.
> **검사**: `grep -o "font-size: *1[0-9]px" *.html | head -1` — 16개 파일 전부 18px여야 한다.

### C2. 색 토큰 어휘 — **의미축 6개**, 이름 하나씩
`--red-*`(위험·차단) `--amber-*`(주의·보류) `--green-*`(정상·완료) `--gray-*`(중립·미시작) `--blue-*`(진행 중) `--accent-*`(브랜드·선택·확정).
**같은 의미에 다른 이름을 만들지 않는다** — `--risk-text`와 `--red-text`가 공존하면 컴포넌트가 두 벌로 갈라진다.
> **검사**: 파일별 `--*-text` 토큰 집합이 위 6개의 부분집합이어야 한다.

### C3. 배지 어휘 — **의미축으로 수렴**, 색은 축이 정한다
배지 이름은 **상태 이름이 아니라 의미축**을 따른다. 화면마다 `badge-ok`/`badge-done`/`badge-recovered`/`badge-modified`를 새로 만들면 34종이 된다(**실제로 그랬다**).

| 의미축 | 클래스 | 쓰는 곳 |
|---|---|---|
| 위험·차단 | `badge-risk` | 위험 시그널, 실패, 필수 미입력 |
| 주의·보류 | `badge-warn` | 불균형, 정체, 재발송 필요, 표본 부족 |
| 정상·완료 | `badge-ok` | 완료, 회복, 활성, 에이스 |
| 중립·미시작 | `badge-neutral` | 미시작, 해당없음, 대기, 기각 |
| 진행 중 | `badge-progress` | 분석 중, 세션 진행 중 |
| 브랜드·확정 | `badge-accent` | 팀 이상, 최종 회차, 추천, 역할 |

**도메인 라벨은 클래스가 아니라 텍스트로.** "에이스"는 `badge-ace`가 아니라 `<span class="badge badge-ok">에이스</span>`다.
> **검사**: `grep -oh "badge-[a-z]*" *.html | sort -u` — 위 6개 + `badge`뿐이어야 한다.

### C4. 브레이크포인트 — **1024px 하나**
태블릿 경계는 1024px. 1180·900 같은 임의값을 만들지 않는다. 컴포넌트 내부 사정으로 다른 값이 필요하면 **주석으로 이유를 남긴다**.
> **검사**: `grep -oh "max-width: *[0-9]*px" *.html | sort -u`

### C5. 매니저 셸 — 사이드바 7항목, 순서 고정
브리핑·대시보드 / 시그널 분석 / 교육생 목록 / 개입 관리 / 리포트 / 이의 검토 / 설정.
> **검사**: 매니저 화면 9개의 nav 텍스트 시퀀스가 동일해야 한다. **현재 통과.**

### C6. 접근성 — 3개 전부, 전 파일
① 입력 보더 `--border-interactive`(3:1) ② 포커스 링 `outline: 2px solid var(--accent-solid)` ③ `prefers-reduced-motion` 대응.
> **검사**: 파일당 3개 다 있어야 한다.

### C7. 배치 범위 표시 — P1/P2는 **반드시 배지**
이번 배치(P0) 밖 기능을 선설계로 그리는 건 좋다. 다만 **배지 없이 그리면 P0 자리를 P1이 차지한 걸 아무도 못 본다** — 실제로 SC-M09·SC-M08에서 P0 기능이 화면에서 사라졌다.
> **검사**: 화면의 주 콘텐츠가 그 화면의 P0 FR인가. P1/P2 영역에 배지가 있는가.

## 2. 웹 설계 체크리스트 (화면을 그릴 때마다)

### 레이아웃
- 1D는 flex, 2D는 grid. `flex-wrap`으로 되는 걸 grid로 만들지 않는다.
- **카드는 기본값이 아니다.** 순서 비교가 목적이면 행 리스트, 대조가 목적이면 2패널, 상태 흐름이면 칸반. 카드를 쓰는 이유를 한 줄로 못 대면 행으로 바꾼다.
- 넓은 콘텐츠(표·코드·차트)는 **자기 컨테이너 안에서** `overflow-x: auto`. 페이지 본문이 가로로 밀리면 안 된다.
- 패널은 본문을 **덮지 않는다**. 오버레이 대신 in-flow 컬럼(SC-M08의 근거 패널이 실제로 본문을 덮었다).

### 데이터 표현
- **값의 타입이 뷰를 정한다.** 정수 5레벨(축 점수 1~5)을 꺾은선 5개로 겹치면 계단이 포개져 안 읽힌다 → 연속량만 선으로, 정수는 표로. **실제로 이 실수를 했다.**
- y축을 0부터 그리지 않는다. 관측 범위에 여유를 둔 구간 + 그리드라인 + 축 라벨.
- 변동이 작은 비교선(기수 평균)은 **점마다 값 라벨**을 찍는다. 안 그러면 수평선으로 보이고 상수로 오독된다. **실제로 그랬다.**
- 숫자가 세로로 정렬되면 `font-variant-numeric: tabular-nums`.
- **화면의 모든 숫자는 명세의 수식에 대입해 검산한다.** `Priority = S×(0.5+R)`인데 값이 안 맞는 행이 3개 있었다.
- 데이터 자체의 정합성도 본다 — 교육생 0명·세션 0건인 기관에 AI 비용 최고액이 찍혀 있었다.

### 타이포
- 본문 65~75ch. 리포트 본문 최대폭 760px.
- 제목은 크기·굵기로, 색으로 위계를 만들지 않는다.
- `text-wrap: balance`는 h1~h3에.

### 모션
- transform·opacity 위주. layout 속성 애니메이션 금지.
- ease-out 계열. bounce·elastic 없음.
- **`prefers-reduced-motion` 대응은 선택이 아니다.**

### 상태
- 정상 / 로딩 / 빈 / 에러 / **권한없음** 5개는 기본이고, 여기에 **FR 예외 case가 1:1로 더 붙는다.**
- 401(재인증)과 403(권한없음)은 **다른 화면**이다.
- 확정 액션은 낙관적 UI를 쓰지 않는다 — AuditLog 실패 시 롤백되므로 성공 토스트를 먼저 띄우면 거짓말이 된다.

### 카피
- 시스템 언어가 아니라 사용자 언어. "extract_scope"가 아니라 "전체 코드 / 커밋 기여분".
- 확정형 낙인 금지 — "프리라이더"가 아니라 "기여·이해도 불균형".
- 교육생에게 내부 운영 상태를 노출하지 않는다("교안 매핑 승인 대기 중" ✗).

### 반응형
- 1024px 이하: 사이드바를 **아이콘 레일 또는 상단 바**로 접는다. 240px를 그대로 두면 본문이 짓눌린다.
- 2패널/3패널은 1024px 이하에서 **세로 스택**으로 무너뜨린다.
- 표는 가로 스크롤, 카드로 바꾸지 않는다(비교가 목적이므로).

### 기준 감사가 파생시킨 발견 (기준을 세우지 않았으면 못 봤을 것들)

- **SC-M07에 100점 스케일이 살아 있었다 (4건).** "이해도 58점", "표준편차 9→17", "본인 62점 / 평균 78점" — 5축 교체 때 *축 이름*만 고치고 *이해도 점수*는 놓쳤다. 축 어휘 grep에 안 걸리는 자리였다. → 5축 평균(1~5) 스케일로 교정.
- **SC-S01의 사용량 데이터가 모순이었다.** AI 비용 열을 추가하고 나서야 보였다 — 교육생 0명·세션 0건인 기관에 최고액이 찍혀 있었고, "집계 실패" 기관에도 비용이 있었다.

### 남은 것

- 3패널(SC-M09 이의 검토)·문서형 3열(SC-M08)의 1024px 이하 세로 스택은 미처리. 마스터-디테일 2패널(SC-M04)은 사이드바를 접은 것만으로 1000px에서 정상 동작을 확인했다.
