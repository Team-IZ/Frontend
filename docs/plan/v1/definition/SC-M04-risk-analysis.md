# SC-M04 · 분석 · 진단

> **⚠ 병합(D88):** 구 "SC-M04 위험·분석" + "SC-M05 코호트 히트맵"을 **단일 화면 "분석·진단"(2단 렌즈)**으로 병합. 이 문서는 **［사람 렌즈］**(누가 위험한가 · DASH-10~13)를 규정하고, **［패턴 렌즈］**(어느 단계·영역이 무너지나 · DASH-14/15)는 [SC-M05-heatmap.md](SC-M05-heatmap.md)가 상세 규정한다(백엔드 FR 소스로 유지). 와이어프레임은 두 렌즈를 한 파일로: `manager/analysis.html`.
> 소스: 기능명세서 v8 DASH-10(위험 교육생 목록) + DASH-11(기여·이해도 불균형 분석 뷰) + DASH-12(에이스 뷰) + DASH-13(팀 분석 뷰) + [패턴 렌즈] DASH-14/15. 백엔드 ENG-04(자동 시그널 생성)이 이 뷰들을 먹임.
> 배치: P0(DASH-10)/P1(DASH-11)/P2(DASH-12·13·14·15). 매니저 앱 셸 공유.
> 네이밍 근거(D88): '위험'은 부정 신호 전용어라 에이스(긍정)·팀분석이 섞인 화면명으로 부적합, "코호트"는 은어 → **"분석·진단"**(사람/패턴 분석 + 취약→액션 진단).

## 2. 목적 & UX 설계 근거

- **라벨이 아니라 근거로 트리아지.** "위험" 배지만 다는 게 아니라 **"어느 축이 언제부터 얼마나 하락했는지" 서술형 근거**를 항상 앞세운다(DASH-10 규칙: 근거 없는 표시 금지·A2). 예: "반례대응 4→3→2, 2회 연속 하락, 기수 평균보다 낮음". → 매니저가 근거를 보고 판단, 그 자리에서 [개입 생성].
- **기여·이해도 불균형 = 낙인 최고 위험 지점(A1).** '프리라이더' 확정 라벨 금지. **서술형** + 세 조건 교차(기여 편차 AND 이해도 저조 AND 지속성)일 때만 표시, 기여량 단독 금지(B5·DASH-11). 원시 기여값은 "참고" 접기.
- **에이스도 근거 기반, 자동 배지 금지(D47).** 단기 고득점≠에이스 — 지속 성장·설명력·표본(B4)만 제시. 시스템이 "발표자·멘토감"이라 확정하지 않는다(과잉 라벨). 활용 판단은 매니저 몫(DASH-12).
- **팀 분석은 분포·편차·설명력 갭.** 위험 팀/균형 팀/고성과 팀(DASH-13). 표본 부족·구성 변경은 유보·병기.
- **표본 부족 유보.** 1회차 단독은 추이 문구 금지·표본 부족 표시(B4·DASH-10 case2).
- **탭 구성(D7):** 한 화면 4탭 — 위험 목록 · 기여·이해도 불균형 · 에이스 · 팀 분석.

## 3. 정보 구조 & 레이아웃 (매니저 앱 셸 · 데스크톱)

**4탭:** 위험 목록(기본) · 기여·이해도 불균형 · 에이스 · 팀 분석.

**위험 목록(DASH-10) — 스케일 대응 트리아지(D128):** 이 화면이 답하는 질문은 "누가 위험한가"(시스템이 이미 앎)가 아니라 **"이번 회차 어디에 시간을 쓰면 가장 크게 바뀌나 · 무엇을 하나"**다. **규모 전제: 담당 50~500명 → 위험군만 50~100명.** 한 명씩 큐로 훑는 마스터-디테일은 이 규모에서 붕괴한다(D127 폐기 사유). 대규모 트리아지 IA = **개관 → 세그먼트 → 일괄 처리 → 드릴인**. 산출물은 "이해"가 아니라 **결정된 개입 목록**.

**⓪ 스코프(D129·최상단):** 모집단은 **매니저 배정 범위**로 고정 — 담당은 배정 반만, 총괄은 기수 전 반(서버 `ManagerAssignment` 조인 강제·SYS-02). 개관 헤더에 배정 범위 명시("내 담당 A·B·C반 138명") + 미배정 반 비노출 안내.
**① 개관 — 개별 이름 전에 "문제의 형태"부터:** `위험 22명(배정 138명 중 15.9%) · ↑+3 vs 3회차 · 해소 −2·신규 +5`. 그 아래 **분포 바**(반별·유형별·심각도) — "A반에 집중", "설명-산출 갭 급증(+3)"이 3초에. 각 세그먼트 클릭 = 필터. 매니저는 개별 판단 전에 **어디를 볼지**부터 정한다. 회차 델타로 문제가 커지는지 판단. **반별 분포는 배정 반 ≥2일 때만** — 단일 반 배정 담당은 반 막대가 무의미하므로 접히고 **유형·심각도가 1차**(D129 접힘 규칙).
**② 세그먼트 툴바:** 검색 · 반 · 유형 · 심각도 · 개입 상태 필터 + 묶기(없음/반/유형) + 정렬(개입 가치순 기본). 500명은 스크롤이 아니라 세그먼트로 항해.
**③ 밀집 테이블 + 일괄 처리(핵심 스케일 기능):** 행 = 44px 밀집 `[☐][심각도 점][이름·반][유형 칩][신뢰도 점][상태]›`. 100행 스캔 가능. **다중 선택 → 일괄 액션**: `3명 선택 → 일괄 개입 생성 · 담당자 배정 · 관찰 유지 · CSV`. **100명을 한 명씩 결정할 수 없으므로** 세그먼트를 묶어 처리("A반 갭 유형 전원 → 멘토 배정")하고 **담당 위임**(500명은 매니저 혼자 불가). 반별 그룹 헤더에 분포 재노출. 푸터 = 범위·페이저(전역 표 표준 [[reference_table_layout_standard]]).
**④ 정렬 = 개입 가치순:** 심각도 단독이 아니라 **심각도(Priority=S×(0.5+R)·DASH-03) × 회복 가능성**. 손대면 바뀔 케이스를 위로(교육 전문가 관점 — 매니저 시간 유한). 미조치 경과(⚠︎)는 증폭 신호(D124 유지). 순위 번호는 조치 큐(SC-M01) 어휘라 안 씀.
**⑤ 근거 신뢰도 — A2의 실행형:** 점 3단계 **확인됨**(3회 반복+객관 데이터 교차+원문 보존) / **관찰 중**(2회) / **참고**(1회·표본 부족). LLM 1회·1~5점은 저해상도·고노이즈 계측기라, **점수만 흔들린 건(다른 근거 없음)은 신뢰도 낮음 → 별도 세그먼트로 강등**(도메인/측정 관점). 매니저가 노이즈를 쫓지 않게.

**⑥ 드릴인 결정 드로어 — 개별 판단이 필요한 소수만:** 행 클릭 → 우측 slide-in. **목록 맥락 유지**(뒤 목록 peek) + **세그먼트 내 ←→ 이동**(필터한 묶음을 훑으며 빠르게 결정). 드로어 내부:
  - **헤더** + 서브탭 `[개요 | 근거·궤적 | 개입 이력]` — 깊은 근거를 접어 드로어가 한 화면에 들어오게.
  - **개요:** 서사 3~4줄 + **원문 발언 1개 인용**(이 제품만의 자산 — 숫자 요약이 아니라 학생이 실제 한 말, 기획 관점) + **제안 처방**(유형+왜+과거 회복률, GOV-02는 시스템 의견까지 막지 않음). 처방에 "A반 갭 3명 그룹 멘토링" 같은 **일괄 제안**도 연결.
  - **근거·궤적:** 붕괴 origin point 타임라인(L1/L2/L3 회차별·처음 무너진 회차·외부 사건 대조) + 채점 근거 원본(DASH-09·매니저 전용). "3주차 공백에 설계논리 멘토링은 헛일" — 현재 점수가 아니라 처음 무너진 지점이 처방을 정한다(교육 관점).
  - **개입 이력:** 지난 개입 → 결과 루프(`멘토링 → 4회차 2.5 개선 방향`). **회복 확정은 Δ≥1 AND post≥3**(B7). 미회복이면 유형 변경 제안.
  - **결정 푸터(sticky):** [개입 생성](→ SC-M07 프리필) / [관찰 유지](사유+재검토 시점 필수 — "판단해서 둠"과 방치를 구분, A7). 결정 시 다음 행 자동 이동.
**⑦ 빈 상태:** 위험 0건이면 "이번 회차 위험 신호 없음 + 다음 체크포인트 일자 + 산출 유보 인원". 조용히 비우지 않는다(A7).

**나머지 3탭 공통(D130):** 위험 목록과 **동일한 스코프·크래프트**로 통일 — 상단 스코프 배너(배정 반만·SYS-02) + 카운트 헤더 + 밀집 리스트(fat 카드 금지) + 신뢰도 점·심각도 점 재사용. 탭 전환 시 딴 화면처럼 보이던 격차 제거.

**기여·이해도 불균형(DASH-11):** 밀집 리스트 — 행마다 서술형 1~2줄 + **3조건 교차 칩**(기여 편차·이해도 저조·지속성) + 신뢰도 점 + 원시 기여값 "참고" 접기 + [개입 생성]·[상세]. **2조건만 충족은 판정 안 하고 모니터링**(교차 근거 불충분 case). '프리라이더' 확정 라벨 금지·서술형(A1·B5).

**에이스(DASH-12):** 밀집 리스트 — 강점 축 칩 + 성장·설명력·표본 근거 1줄 + 신뢰도 점 + **[역할 태그](매니저가 발표자·멘토 지정)**·[상세]. **자동 "후보" 배지 없음(D47)** — 근거만. 표본 부족(단일 회차)은 확정 유보·dim 처리(B4).

**팀 분석(DASH-13):** 크래프트 테이블 — 팀별 이해도 분포(미니 히스토그램)·편차·완성도↔설명력 갭 + 위험/균형/고성과/– 분류 pill + [팀 상세]. 표본 부족(팀원 과소)은 병기·해석 유보, 구성 변경은 기간별 분리. **팀도 배정 반의 프로젝트 팀만**(스코프).

반응형: 웹 기준.
