# OP-05 · 리포트 — 문서 2종

## 1. 한 줄

**수업 진단**(미프 후) · **기수 결산**(빅프 후). 재는 대상도 발행 시점도 다르다.

## 2. 왜 둘인가

| | **수업 진단** | **기수 결산** |
|---|---|---|
| **앵커** | 교안 개념 | **본인 커밋 영역** |
| **재는 것** | 커리큘럼이 전달됐나 | 이 사람이 자기 코드를 아나 |
| **발행** | **미프 마지막 회차 후** | **빅프 종료 후** |
| **독자** | 교안 담당 · 다음 기수 설계자 | 경영진 · 매니저팀 |
| **레버** | 교안 개정 · 검증 개념 선정 · 회차 설계 | 우수 명단 · 다음 기수 운영 |

**한 문서에 섞으면 *"교안을 고칠까 사람을 볼까"* 가 뭉갠다.**

### 발행 시점이 다른 것이 더 큰 이유다

10-2: *"미프·빅프는 순차다. 미프가 앞에서 몇 개월, **빅프가 마지막 8주**."*

```
미프 1~7차 ─────────────┐
                       │← 수업 진단 확정. 교안 개정 시작 가능
                       빅프 3회 (8주) ────┐
                                          │← 기수 결산
```

빅프를 기다렸다 한 문서로 내면 **다음 기수 준비 시간 8주를 버린다.** 그 8주가 개정 기간이다.

### 셋 이상으로 늘리지 않는다

17번 294줄이 매니저 리포트를 프로젝트 하위로 흡수한 이유가 *"들어갈 때마다 회차부터
고르게 된다"* 였다. **둘이면 탭으로 끝나고 목록이 안 생긴다.**

**회차별 리포트를 만들지 않는다** — 7개면 아무도 안 읽고, 회차 단위는 **OP-04 현황 탭**이
이미 답한다.

## 3. 이 문서가 될 수 없는 것

IZ-Get이 재는 것은 **코드 이해도 하나**다. 취업률·수료율·출석·만족도를 재지 않고,
14번 1163줄이 `최종 성적 산출식`을 **범위 밖**으로, `수료생 리포트 열람`을
*"중요하지 않음"* 으로 뒀다.

> **이 문서는 "기수 종합 평가서"가 아니라 "이해도 측정 결과"다. 수료 판정을 하지 않는다.**

없는 것을 있는 척하면 **문서 전체가 못 믿을 것**이 된다.

## 4. 탐색 도구가 아니라 문서다

18번 2-4: *"고정 시점 스냅샷 · 기수 말 1회 · **외부 제출용**"*.

| | |
|---|---|
| **필터·드릴다운이 없다** | 있으면 **읽는 사람마다 다른 문서**가 된다 |
| **값이 얼어 있다** | `2026-07-04 미프 7차 발행 시점으로 고정` |
| **순서가 고정** | 목차가 곧 목차다 — **섹션 전환이지 앵커 스크롤이 아니다**(H2) |
| **나가는 링크가 없다** | **진행 중 상태에서만** OP-02로 유도한다(그건 아직 문서가 아니므로) |
| **분석 컴포넌트 재사용** | 반 비교를 새로 그리지 않고 **그 시점 값으로 얼린 것**을 넣는다(18번 명시) |

**화면 안에는 값·라벨·범례·분모만 둔다** — 설계 근거와 기획 조항 번호는 전부 크롬 밖(I3).

## 5. 수업 진단 — 섹션 3

### ① 요약 — 무엇을 빼고 세었나

4칸(교육생 250 · 미프 7회 · 검증 개념 21건 · **채점 1,631 / 1,750**) + 제외 한 줄.

**분모를 맨 앞에 둔다** — 외부 문서라 각주로 달면 **119건이 왜 빠졌는지**를 못 찾는다.

| 뺀 것 | 근거 |
|---|---|
| 미집계 119건(미응시 71 · 무효 33 · 중단 15) | 14-1 · 9-4 |
| 재시험 결과 | 11장 — *"조직 단위 수치는 1차만"* |
| 빅프 | 기수 결산 탭으로 |

### ② 개념별 도달 분포 — 본체

```
검증 개념              도달 단계 분포            2단 이하   묻지 못함
                                                            코드에 없어서
교안 AI_LLMOps v2 · 11건
Graph 구성            ██62 ███71 ███58 ██43       57%        6명
 4장 p.62 · 미프 3차·5차                       133/234명
```

| 설계 결정 | 왜 |
|---|---|
| **행이 개념이지 회차가 아니다** | 같은 개념이 여러 회차에 쓰인다 — 회차로 나누면 **그 개념에 대한 기수 전체의 답**이 흩어진다 |
| **교안·섹션으로 묶는다** | 검증 개념은 **출처 교안·섹션을 달고 다니고**(14번 438줄), 고칠 대상이 **개념이 아니라 교안 그 페이지**다 |
| **`묻지 못함`이 검증 개념 선정의 레버** | 문항이 **만들어지지 않은 것**이라 못한 게 아니고(F3), 크면 **개념 선택이 프로젝트와 안 맞았다**는 신호(18번 137줄). 개념을 고르는 사람이 오퍼레이터(6-3) |
| **2단 이하를 센다** | 9-2 위험 판정선이자 11장 재시험 대상선 — **이미 정의된 경계** |
| **평균 도달을 쓰지 않는다** | 합칠 수 없는 값(A1·A2). `2.5`는 *"절반이 멈췄다"* 와 *"모두가 어중간하다"* 를 구분 못 한다 |

### 라벨을 두 번 바꿨다

| | |
|---|---|
| `코드에 없음` | *"코드가 없다"* 로 읽힌다 — **학생이 제출을 안 한 것**처럼 |
| `문항 없음` | 여전히 **무엇이 없다**는 말이라 뜻이 안 온다 |
| **`묻지 못함`** | **시스템이 물어보지 못한 것** — 일어난 일 그대로 |

MG-08은 `코드에 없던 사람`, OP-04는 `코드 매칭 0`이라 부르는데 **둘 다 "무엇이 없다"**
쪽이다. 열 머리에 `코드에 없어서`를 작게 붙여 **범례를 안 봐도 읽히게** 한다.

색은 **MG-02 램프 그대로**(1단 `#df6150` → 4단 `#57b083`). 도달 단계는 기획에 정의된
눈금이라 **절대 색**을 쓸 수 있다 — OP-02가 상대 색을 쓰는 것과 다르다.

### ③ 회차별 — 어느 회차가 어려웠나

행 = 미프 1~7차, 그 회차 검증 개념 3건 + 분포 + 2단 이하.

**회차끼리 비교가 성립하는 이유** — 개념은 다르지만 **같은 250명이 봤다.** 3차가 무거운
것은 *"그 회차 개념 묶음이 어려웠다"* 로 읽는다. **반을 가로로 비교하는 OP-02와 축이 다르다.**

**반별 추이를 넣지 않는다** — *"어디로 가고 있나"* 는 **진행 중 도구**(OP-02)이고 끝난
기수에서는 최종 상태가 답이다.

## 6. 기수 결산 — 섹션 3

### ④ 미프 → 빅프 — 성장 지표

6-2 428줄이 근거다.

> *"계단은 양쪽 동일하다. 앵커만 다르다. 그래서 미프와 빅프의 도달 단계를 비교할 수 있고,
> **그게 성장 지표의 근거다.**"*

**`성적 미반영` ≠ `리포트 미표시`** — 미반영은 *"위험 판정·조직 수치에 안 쓴다"* 는 뜻이고
**용도가 성장 지표**라고 기획이 지정했다.

| | |
|---|---|
| **개념별로 못 묶는다** | 빅프 앵커가 **본인 커밋 영역**이라 사람마다 개념이 다르다 — **계단이 같으므로 도달 단계로만** 견준다 |
| **이동 표가 본체** | 분포 둘만 나란히 두면 *"전체가 좀 올랐다"* 까지인데, **미프에서 막혔던 57명 중 26명이 빅프에서 올라간 것**이 이 기수가 한 일이다 |
| **각 행에서 명단을 펼친다** | 인원 수만 있으면 *"그래서 누구"* 에서 끊긴다 — **화면에서만 펼치고 CSV로 뽑는다**(PDF 본문에는 인원 수만) |
| **내려간 9명도 쓴다** | 미프는 교안 개념, 빅프는 자기 코드 — **다른 것을 물었다.** 한쪽만 쓰면 성장만 보이는 문서가 된다 |
| **분모가 다르다**(234 → 229) | 빅프 미응시가 따로 있다 |

### 어느 명단이 PDF에 들어가나

| 명단 | 화면 | PDF | CSV |
|---|---|---|---|
| **우수 교육생 41명** | ⭕ 20명/쪽 | ⭕ **전부** | ⭕ |
| **미프→빅프 이동**(26 / 29 / 165 / 9명) | ⭕ 펼치기 | ❌ **인원 수만** | ⭕ |

**우수는 그 섹션의 본체**라 문서에 들어가야 한다. **이동 명단은 파생**이고, 그중
`그대로 2단 이하 29명`이 외부 문서에 **실명으로 박히면 낙인**이다(A3).

**문서와 작업용 파일은 나가는 곳이 다르다.**

### ⑤ 우수 교육생 — 명단 + 내보내기

**되돌린 것이다.** 17번 283줄이 오퍼레이터에게 남긴 테이블을 OP-02 재설계에서 같이
지웠었다.

> *"**오퍼레이터** | 250명이라 개인을 못 본다. **정렬·비교가 진짜 필요** → 테이블 유지"*
> *"**매니저** | 위험은 면담이, 오늘 것은 대시보드가 담는다 → 테이블 삭제"*

**17번이 지운 것은 매니저 쪽뿐**이고, 오퍼레이터는 **명부 메뉴가 없어**(17번 3-2) 갈 곳이
여기뿐이다.

### 위험과 우수는 대칭이 아니다

| | 집계로 되나 | |
|---|---|---|
| **위험 44명** | ⭕ | 처리는 매니저가 한다. 오퍼레이터가 알 것은 **어느 반에 몰렸나**뿐 → 반 비교가 답함 |
| **우수 41명** | ❌ | **누구인지가 정보 그 자체**다. `우수 41명`은 아무 말도 안 한다 |

### 9-3의 프로필이 여기서 완성된다

> *"미프 6~8회 × 반당 1~2명이면 **프로젝트별 프로필**이 쌓인다."*

`7회 중 5회 우수`는 **진행 중에는 안 나오는 값**이고, **1회짜리와 5회짜리는 다른 사람**이다.

| 열 | |
|---|---|
| 교육생 · 반 | |
| **미프 우수** | `5회 · 1·2·3·5·7차` — 회차 번호까지 |
| **빅프 최저 도달** | 미프 우수는 *교안 개념을 안다*, 빅프 우수는 *자기 코드를 안다* — **둘 다면 진짜**. 최저값은 9-3(*"3문제 중 최저값으로 비교"*) |

**용도를 화면이 정하지 않는다** — 이 제품은 취업 연계를 하지 않으므로 **명단을 내보내고
기관이 알아서 쓴다.** `추천`·`배치` 같은 말을 쓰면 **안 하는 일을 약속**하게 된다.

**위험자 명단은 넣지 않는다** — 기수 끝에 받아도 조치를 못 하고, *"수료했지만 이해도 낮음"*
명단은 **낙인**이다(A3).

**등수를 붙이지 않는다** — 우수 횟수 순으로 정렬만 한다.

**41명인 이유** — 9-3은 **회차마다 반당 1~2명**이라 미프 7회 × 10반이면 **판정 70~140건**,
중복을 제거하면 40명 안팎이다. **잘라 보여주지 않는다** — 컷을 두면 그 컷이 내가 만든
임계값이 된다(E8).

**대신 페이지네이션**(20명/쪽 · 3쪽) — 문서라도 한 화면에 41줄을 세로로 쌓지 않는다.
표 표준 그대로 **푸터에 `1–20 / 41명` 좌 + 페이저 중앙**(E3). **PDF에는 전부 들어간다** —
페이지네이션은 화면 사정이지 문서 내용이 아니다.

### ⑥ 반 · 집단 미달 — 운영

**둘을 한 섹션에 둔다.** 반 편차만 있으면 외부 독자가 *"C반 매니저 문제"* 로 읽는다.
**집단 미달은 개인 위험 사유에서 빠지고 반 단위로 처리된 건**이라(9-6), 같이 두면
**반 값의 일부가 개인이 아니라 구조에서 왔다**는 것이 보인다.

| | |
|---|---|
| **미프 7차 기준** | 9-2 위험 판정은 **회차 단위**이고 **기수 전체 위험자라는 개념이 기획에 없다.** 누적으로 세면 **새 정의를 만드는 것**(E8)이라, OP-01이 *"미프 2차 기준"* 이라 쓰는 것과 같이 **기준 회차를 밝힌다** |
| **등수·담당 매니저 이름을 쓰지 않는다** | 18번 116줄. **문서가 밖으로 나가면 그 통제가 안 먹으므로 애초에 넣지 않는다** |
| **기수 전체가 기준선** | 반 값만 늘어놓으면 *"이게 높은 건가"* 를 알 수 없다 |
| **OP-02 마지막 회차 열과 같은 값** | 같은 계산이어야 두 화면이 안 어긋난다(D1) |
| **드릴다운이 없다** | 문서라서. 반 안을 보려면 OP-02를 연다 |

### 집단 미달은 발생 사실만 쓴다

9-6이 *"시스템은 표시까지만 한다"* 고 했고 처리는 기관 판단이다 — **사람이 쓴 처리 기록을
화면이 요구하지 않는다.** 무엇을 했는지는 문서 밖의 일이다.

`검증 개념 / 회차·반 / 미달 N of M` 네 칸이면 끝난다. 같은 개념이 여러 건이면
(`Graph 구성` 3건) **반 운영이 아니라 교안 신호**이고 **수업 진단 탭**과 이어진다.

| **빅프 진행 중** | 기수 결산만 확정 전 — **수업 진단은 이미 확정**임을 밝힌다 · 회차를 `2 / 3회`로 |
| **집단 미달 0건** | 빈 상태 — *"위험 판정이 모두 개인 사유로 남았다"* 는 뜻을 같이 쓴다 |

**빈 상태에 "없음"만 쓰지 않는다** — 외부 문서라 **0건이 무엇을 뜻하는지**를 같이 쓴다.
그리고 **섹션을 숨기지 않는다** — 목차에서 사라지면 *"안 봤는지 없었는지"* 구분이 안 된다.

**PDF가 확정 전에 잠기는 이유** — 확정 전 값을 내보내면 **나중 값과 다른 문서**가 돌아다닌다.

## 9. 액션

섹션 전환 · **PDF 내보내기** · **명단 펼치기 + CSV 내보내기**(우수 · 미프→빅프 이동).
그 외에 나가는 곳이 없다.

## 11. 기획에 없는데 넣은 것 — 명시

근거를 댈 수 있는 것과 **제가 정한 것**을 갈라 둔다.

| | 상태 |
|---|---|
| **③ 회차별 섹션** | 18번 2-4 목차는 `개념별/반비교/집단미달` 3개뿐. **추가한 것.** 근거는 *"회차 설계가 오퍼레이터 레버(OP-03)"* 라는 추론 |
| **빅프 최저 도달** | 9-3의 *"3문제 중 최저값"* 은 **미프 우수 판정** 규칙. 빅프에 적용한 것은 **일관성을 위한 추론** |
| **`기수 결산`이라는 이름** | `수업 진단`은 14번 61줄 어휘지만 **`기수 결산`은 지어낸 말** |
| **명단 펼치기 · CSV** | 사용자 결정(*"리스트 뽑아서 회사 측에서 알아서 쓴다"*) |
| **PDF에 명단 제외** | A3(낙인)에서 파생한 **설계 판단** |
| **채점 건수 단위**(1,631건) | 14-1은 사람 상태(미응시/무효/중단)로 말한다. **세션 단위로 환산**한 것 — 미프 7회 × 250명 = 1,750건 |
| **우수 명단 페이지네이션** | 문서에 페이저를 두는 것은 **화면 사정**이지 기획 항목이 아니다 |
| **`묻지 못함` 라벨** | 기획 어휘는 `코드에 없던 사람`(MG-08) · `코드 매칭 0`(OP-04). **읽히게 고쳐 쓴 말** |
