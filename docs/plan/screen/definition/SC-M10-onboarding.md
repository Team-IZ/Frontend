# SC-M10 · 매니저 온보딩 튜토리얼

> 소스: 기능명세서 v8 UX-01(매니저 온보딩 튜토리얼). 최초 로그인 시 SC-M01 위 **오버레이 코치마크**(독립 화면 아님).
> 배치: **P2 · 중요도 하**. 매니저 앱 셸 위에 얹히는 오버레이 — 와이어는 SC-M01 백드롭 + 코치마크 목업으로 최소화.

## 2. 목적 & UX 설계 근거

- **최초 진입의 막막함을 4단계로 잡아준다(UX-01).** 매니저가 처음 로그인하면 무엇부터 설정할지 모른다 → **체크포인트 설계 → 질문 범위 → 시그널 임계값 → 열람 범위** 순서로 각 지점을 스포트라이트하며 안내. 측정 운영의 준비 순서 그대로.
- **안내까지만, 설정은 실제 화면에서(경계).** 온보딩은 코치마크로 "여기서 이걸 한다"를 짚어줄 뿐, 설정 자체는 SC-M03 등 담당 화면에서. 온보딩 안에 설정 폼을 복제하지 않는다(중복·드리프트 방지).
- **최초 1회 자동, 이후 수동(UX-01).** 완료 이력이 있으면 자동 재실행 차단(case2). 재열람은 도움말 메뉴로만, **완료 이력을 바꾸지 않는다**(case7).
- **이어보기 — 중간 이탈을 처벌하지 않는다(case3).** 단계별 진행을 저장, 재접속 시 마지막 완료 단계부터. 저장 실패해도 현재 세션 진행은 유지하고 재저장(case5).
- **권한 경계 존중(case4).** 담당 권한이 없는 설정 단계(예: 총괄 전용)는 **설명만 표시하고 직접 이동은 생략** — 못 가는 곳으로 보내지 않는다.
- **콘텐츠 조회 실패해도 막지 않는다(case6).** 튜토리얼 콘텐츠를 못 불러오면 기본 도움말 링크로 폴백.

## 3. 정보 구조 & 레이아웃 (오버레이 · SC-M01 위)

**매니저 셸(SC-M01) 백드롭 + 코치마크 오버레이.**

- **딤 백드롭** + **스포트라이트**(대상 요소 하이라이트, 나머지 흐림)
- **코치마크 카드**(대상 옆): 단계 제목 · 설명 · **단계 진행 표시(1/4)** · [건너뛰기] / [다음]
- 4단계 순서:
  1. **체크포인트 설계**(측정 계획 메뉴 스포트라이트 → SC-M03/PLAN-01)
  2. **질문 범위 설정**(추출 범위 → SC-M03/PLAN-02)
  3. **시그널 임계값**(개입·시그널 설정 지점)
  4. **교육생 열람 범위**(측정 계획 회차 설정 → SC-M03/GOV-03·D121)
- 마지막 단계 [완료] → 오버레이 종료 · 완료 이력 기록
- 이후: **도움말(?) 메뉴 → 튜토리얼 다시 보기**(수동)

반응형: 웹 기준(오버레이는 셸 폭 따름).

## 7. 인터랙션 & 화면 전이

- 최초 로그인 → SC-M01 착지 → **온보딩 오버레이 자동 시작**(1회).
- [다음] × 4 → 각 단계 진행 저장 → [완료] → 완료 이력 기록 → 오버레이 종료(SC-M01).
- [건너뛰기] → 오버레이 종료(완료 미기록, 다음 로그인 시 이어보기 아님 — 정책: 건너뛰기도 이력 기록으로 자동 재실행 방지).
- 각 단계 "이동" → 해당 설정 화면(SC-M03 등). 권한 없으면 설명만(case4).
- 도움말(?) → **튜토리얼 다시 보기**(이력 불변, case7).

## 9. UX 준수 규칙

| 규칙 | 구현 | 근거 |
|---|---|---|
| 최초 1회 자동·이후 수동 | 완료 이력 있으면 자동 차단, 도움말로만 재열람 | UX-01 case2·7 |
| 이어보기 | 마지막 완료 단계 저장·재접속 시 이어서 | UX-01 case3 |

| 재열람 이력 불변 | 수동 재열람은 완료 이력 변경 없음 | UX-01 case7 |
| 안내까지만 | 설정은 담당 화면에서, 온보딩은 코치마크만 | UX-01(안내 단계 표시) |
