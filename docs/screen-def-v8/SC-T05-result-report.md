# SC-T05 · 결과 리포트 (교육생)

> 소스: 기능명세서 v8 MEAS-07(세션 후 교육생 리포트) + RPT-02(최종 리포트) + GOV-03(열람 범위). ~~GOV-01 이의제기~~ 제외(D117).
> 배치: P0 · 교육생 루프 4번(종착점). 심의 데모의 종점.

## 2. 목적 & UX 설계 근거

- **교육생이 볼 수 있는 것만 보여준다(GOV-03·A5).** 리포트는 매니저용/교육생용 2버전. 교육생용은 **공개 허용 항목만** — 강점·취약 축·성장 추이(요약). **루브릭·점수 근거·시그널은 절대 비노출**.
- **공개 범위 3단(GOV-03).** 전체(강약점+추이) / 요약(핵심만) / 비공개(잠금). 미지정·조회 실패 시 **기본 비공개**(안전).
- **처방이 아니라 위치 안내(B10).** 취약점에 대해 문제를 만들어주지 않는다. **교안의 어디를 보라**까지만(자동 연결된 매핑이 있고 신뢰도가 충분할 때, D96). 안내할 위치가 없으면 블록 자체 생략.
- **등급은 최종 회차만(B3).** 중간 회차는 강약점·추이만, 최종 회차 리포트(RPT-02)에서만 등급.
- **결과에 대한 이의제기 절차는 없다(D117).** 점수·루브릭이 A5로 비노출이라 학생이 무엇을 무슨 기준으로 논박할지가 성립 불가. 오측정 안전망은 학생 이의가 아니라 **GOV-02(매니저 인간 검토)+ENG-05(재채점 안정성)**. 화면은 결과를 "받아보는" 문서로 순수하게 둔다.

## 3. 정보 구조 & 레이아웃 (교육생 셸 · 데스크톱)

**"내 리포트" = 이 화면이다(별도 목록 화면 없음, D116).** 교육생 셸 상단 네비의 [내 리포트]와 홈의 [전체 보기 →]는 **SC-T05로 진입**하며, 기본은 **가장 최근 리포트**를 연다. 회차 이동은 화면 전환이 아니라 **회차 선택기**(칩 목록: 회차 번호 + 잠금/준비 중 상태)로 처리한다.
- **왜 목록 화면을 안 만드나:** 교육생의 리포트는 회차 수만큼(3~5개)뿐이라 페이징·검색·필터가 필요 없다 — 3~5행 목록에 화면 하나를 파는 건 과설계. 회차 간 이동이 같은 화면 안이면 "2회차 → 3회차" 비교의 맥락도 유지된다(뷰 패턴: 맥락 유지 > 화면 이동). D7(한 화면 + 탭/섹션)과도 정합.
- **선택기 상태:** 공개된 회차(이동 가능) / **비공개·미지정 회차(잠금 표시, 선택 시 T6)** / 세션 미완료·생성 중(준비 중 표시, 선택 시 T7).

**상단:** 회차·리포트 유형(회차 결과 / 최종) + **공개 범위 배지**(전체/요약/비공개) + 생성 시각·프로젝트·회차 성격("중간 회차 — 등급은 최종 회차 후").

**본문(공개 범위별):**
- **요약 공개:** 잘한 점 · 더 볼 부분(**서술형** + 관련 축 칩) · **교안 위치 안내**(자동 연결·고신뢰일 때만)
- **전체 공개:** 위 + **이해 상태 궤적**(회차별 견고/부분/표면 + 변화 서술)
- **비공개:** 잠금 카드. **설정 미지정·조회 실패도 동일**(기본 비공개 = 안전 기본값, R-2)

**점수 표기 원칙(A5 구체화):** 리포트는 **서술형 + 이해 상태**로 표현하고 **점수 숫자·눈금·순위·타인 비교는 표시하지 않는다.** 막대 높이 같은 준(準)점수 표현도 금지 — 정확한 값을 숨긴다면서 형태로 알려주는 건 A5 우회다. 궤적은 **1회차 단독 판정 금지(B4)** 때문에 2회차부터 의미를 갖는다. 순위·백분위는 낙인·경쟁 조장으로 배제(B5·D29).

**하단:** 이의제기 없음(D117). 궁금한 점은 담당 매니저 문의(문의 경로만, 준사법 절차 아님).

**교안 위치 안내(R-5):** 안내할 위치가 없으면(미링크·미커버·저신뢰) **블록 자체를 생략**(빈 껍데기·"자료 없음" 표시 금지).

반응형: 웹 기준, 문서형 세로 스크롤.
