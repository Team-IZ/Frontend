v1 구조를 유지한다. 변형 A(오퍼레이터·매니저)와 변형 B(교육생), 교육생 이름 읽기전용, 동의 항목 차등이 전부 그대로다. 바뀐 것은 하나 — 초대 모달의 권한(담당/총괄) 선택이 사라졌다. 매니저가 한 종류뿐이라 초대하는 화면이 곧 역할이다.

  • 초대 링크 클릭이 이메일 소유 증명이다. 별도 인증 메일 단계가 없고 이메일 필드는 초대값 읽기전용이다.
  • 토큰이 변형을 결정한다. 사용자가 고르지 않고, 직접 URL로는 들어올 수 없다.
  • 교육생에게 이름을 다시 받지 않는다. 명단(OP-06)에 이름+이메일이 이미 있다 — 활성화 전에도 반 편성·미제출 관리가 돌아야 해서 그때 이름이 필요하다.
  • 동의 항목 수가 다른 이유: 교육생은 코드·문답·이탈 기록까지 처리 대상이다.
