> **백엔드가 2026-08-19 배포로 공개/비공개 개념 자체를 없애면서 폐지됐다.**

> 여는 절차가 사라졌다. 걷어낸 PR: #287(이슈 #285).
>

> 안 마친 개념만 `qa`·`explanation`이 빠진다. 현재 화면 상태는
> `mg-08-result-mapping.md`를 본다.
