# SC-T02 · 코드 제출

> 소스: 기능명세서 v8 MEAS-01(코드 제출) + AUTH-07(커밋 이메일 등록·검증) + MEAS-02A(기여분석)·MEAS-02B(DP 추출, 백그라운드).
> 배치: P0 · 교육생 루프 2번. 교육생 앱 셸 공유(SC-T01).

## 2. 목적 & UX 설계 근거

- **제출은 3단계 선형.** ① 커밋 이메일 검증(AUTH-07) → ② 코드 제출(MEAS-01) → ③ 분석 대기(MEAS-02). 순서 의존이라 **스텝 흐름**으로 안내.
- **커밋 이메일 = 귀속의 전제.** 미검증이면 기여분석 부정확 → 검증을 제출 앞단에 둔다. OAuth 우선, 실패 시 매니저 수동 승인 폴백. 미검증도 제출은 허용하되 **경고 표기**(AUTH-07 규칙, A8).
- **제출 방식 2가지.** GitHub URL(권장) / ZIP+git log(폴백). OS별 git log export 명령 안내(MEAS-01 규칙).
- **분석은 백그라운드, 상태는 투명하게.** 제출 후 기여분석→DP 추출이 도는 동안 **진행 상태**를 보여주고, DP_READY면 세션 CTA. 내용(DP·포커스)은 비노출.
- **재응시 없음.** 기한 초과는 지각 정책 따름, 마감 후 제출 불가.

## 3. 정보 구조 & 레이아웃 (교육생 셸 · 데스크톱)

**상단:** 뒤로(홈)·화면 제목·회차·프로젝트(유형 배지)·응시 기한·**추출 범위(본인 커밋 기여분/전체 코드)** 컨텍스트(스트립).

**스텝 흐름 — 단계가 상태에 따라 접히고 펼쳐진다:**
1. **커밋 이메일(AUTH-07):** 등록·OAuth 검증·상태 배지(검증됨/미검증 경고/매니저 승인 대기).
   - **검증됨 → 한 줄 배지로 접힘**(`✓ 커밋 이메일 검증됨 · 주소 · [변경]`) — 매번 묻지 않음.
   - **미검증 → 펼침 + 경고**: "인증 안 해도 제출은 되지만 **내 기여로 인식되지 않을 수 있어요**"(A8). [GitHub로 인증] / [매니저 승인 요청](OAuth 실패 폴백).
2. **제출할 코드(MEAS-01) — 레포는 팀/학생 단위(D18):**
   - **팀 프로젝트:** 팀에 연결된 저장소를 **읽기 전용으로 표시**(`🔗 연결됨`) + 브랜치 선택. 학생이 URL을 타이핑하지 않는다(변경은 매니저 요청).
   - **개인 프로젝트:** 방식 토글(GitHub 저장소 / ZIP 업로드) — **토글이 콘텐츠를 실제로 가른다**(URL 모드에서 ZIP 안내 미노출). ZIP 모드에서만 드롭존 + **복사 가능한 git log export 명령(OS별)**.
   - **재제출은 세션 진행 여부로 3분기(중요, B2·재응시 없음):**
     | 시점 | 재제출 | 근거 |
     |---|---|---|
     | 분석 전/중 · **세션 미시작** | ✅ 허용(스냅샷 교체·분석 재시작) | 아직 측정 안 함 |
     | **세션 시작~진행 중** | ❌ **잠금** | 세션은 그 스냅샷의 DP 세트로 진행 중 — 코드를 갈면 이미 답한 내용이 존재하지 않는 코드에 대한 답이 됨(측정 오염) |
     | **세션 완료** | ❌ **잠금** | 이 회차 측정 종료. 재제출=재응시=금지 |
   - 잠금 화면은 "다시 제출할 수 없음" + **[세션 이어하기]**(진행 중) 또는 결과 안내(완료)로 다음 행동 제시(막다른 길 금지).
   - **재제출 = 그 회차 스냅샷 교체**(B2), 분석은 처음부터 재시작. **교육생 화면에 이전 제출물 이력은 두지 않는다** — 측정 단위가 회차 스냅샷이라 이력 대상이 아니고, 감사 추적은 백엔드 AuditLog 소관(MEAS-01 부수효과).
3. **분석 진행(MEAS-02A/02B):** 4단계 체크리스트(코드 가져오기 → 기여 분석 → 검증 질문 준비 → 세션 준비), 각 단계 **done · now · wait · error** + 서브라벨(파일 수·커밋 수·소요 안내). 진행 중 CTA는 **비활성**("준비 중").
4. **분석 완료(DP_READY):** 전 단계 완료 + **세션 톤 선제 완화 안내**("코드 보며 설명·점수 비노출·10~15분·중간에 나가도 이어서", D108~111) + [검증 세션 시작하기](→T04) / [나중에 하기](홈).
5. **분석 실패:** 실패 단계를 `error`로 표시 + **교육생이 스스로 복구할 수 있는 안내**(예: A-1 귀속 커밋 0건 → "커밋 이메일 확인하기" + [다시 분석 시도"]). 내부 원인은 노출하지 않음.

반응형: 웹 기준.
