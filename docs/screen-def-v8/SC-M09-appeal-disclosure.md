## 2. 목적 & UX 설계 근거

- **회차별 공개 설정이 핵심이다.** 교육생 리포트(SC-T05)는 회차별로 공개/비공개가 갈린다(T05 회차 선택기의 회차별 잠금). 따라서 공개 범위는 **기수 단일 스위치가 아니라 회차별**이어야 한다 — **기수 기본값(비공개) + 회차별 오버라이드**. 이걸 기수 단일 스위치로 두면 "1회차만 비공개"가 불가능해 T05와 어긋난다(이번 재설계의 교정점).
- **설정 결과를 미리 보고 정한다.** 매니저가 전체/요약/비공개를 고를 때 교육생이 실제로 뭘 보는지 모르면 오설정 위험 → **T05 미리보기**를 옆에 붙여 선택 즉시 확인(비공개 선택 시 미리보기도 잠금 화면).
- **어느 설정이든 항상 제거(A6).** 전체/요약 어느 쪽이든 **내부 루브릭·채점 근거·점수 공식·처방형 콘텐츠는 항상 제거**. 학습 위치 안내까지만, 처방 금지.
- **확정은 사람이 한다(GOV-02).** 저장은 **매니저 명시 액션**으로만 적용(자동 적용 없음). 설정은 버전·설정자·시각 기록(불변), 변경 중 교육생 조회는 **마지막 확정 버전** 응답(중간 상태 노출 안 함).
- **기본 비공개(GOV-03).** 설정 안 한 회차·기수는 비공개(안전 기본값).
- **이의 검토(GOV-01)는 이 화면에 없다(D117).** 교육생 이의제기가 제거돼 입력이 없고, 점수 수정은 측정층 불변 위반. 매니저의 판정 재량은 점수 편집이 아니라 위험·개입·등급 화면에서 행사한다.

## 3. 정보 구조 & 레이아웃 (매니저 앱 셸 · 데스크톱)

**단일 뷰 · 3열**(탭 없음 — GOV-03 단일 목적).

1. **회차 목록(좌):** 기수 기본값 표시 + 회차별 현재 공개 상태(전체/요약/비공개, 오버라이드는 `·수동` 표기). 회차 클릭 → 가운데·오른쪽 갱신. 준비 중 회차(측정 전)도 미리 설정 가능.
2. **설정(가운데):** 선택 회차의 세그먼트(전체/요약/비공개) + "항상 제거" 안내(A6) + [이 회차 저장] + [기수 기본값으로 되돌리기] + GOV-02 안내(매니저가 눌러야만 적용·변경 중엔 마지막 저장값 노출) + **설정 이력**(버전·설정자·시각·불변).
3. **미리보기(우, sticky):** 선택 회차·범위에서 교육생이 보는 T05 화면(강약점·궤적) + 제거 항목 안내. **비공개면 미리보기도 잠금 화면**(교육생이 실제로 보는 것 그대로).

반응형: 웹(데스크톱) 기준. 좁으면 3열 → 세로 스택.

## 7. 인터랙션 & 화면 전이

- 회차 선택 → 설정·미리보기 갱신. 범위 선택 → 미리보기 즉시 반영(비공개면 잠금 화면).
- [이 회차 저장] → 버전 기록 + T05 공개 필터에 즉시 반영(그 회차만). [기수 기본값으로 되돌리기] → 오버라이드 제거.
- 저장 결과 → **SC-T05** 회차별 노출/잠금에 반영(T05 회차 선택기의 잠금 상태와 1:1).
