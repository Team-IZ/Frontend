# 교육생 화면 테스트 — 4명 분담 계획

> **처음 테스트하는 사람을 위한 문서다.** 무엇을 누르고 무엇이 보여야 하는지를 그대로
> 적었다. 화면 문구는 **실제로 띄워 확인한 것**이고, 확인 못 한 것은 그렇다고 적었다.
>
> 실측 2026-08-18 · 계정은 로그인 화면의 `교육생 케이스별 계정`에서 고른다.

---

## 0. 시작하기 전에 — 3분

### 계정 고르는 법

로그인 화면에서 **`교육생 케이스별 계정 194개` → 펼치기**.

```
전체  강민수  노경천  박종호  손진원              ← ① 내 이름을 누른다
미응시 20/109   분석실패 2/15                    ← ② 내 몫만 남는다
분석완료 4/21   응시중 0/2                       ← 0이면 내 계정이 없다는 뜻
```

계정을 누르면 **비밀번호까지 채워져 바로 로그인된다.**

### 누가 무엇을 보나

**학생이 지나가는 순서로 네 구역**이다. 각자 자기 구역만 판다 — 넷이 같은 것을 보면
같은 버그를 네 번 찾고 나머지는 아무도 안 본다.

| 담당 | 구역 | 케이스 | 계정 |
|---|---|---|---|
| **강민수** | 제출 전 | 미응시 · 분석실패 | 22 |
| **손진원** | 응시 시작 | 분석완료 | 4 |
| **박종호** | 이탈·복귀 · 못 들어간 상태 | 응시중 · 응시정지 · 창닫힘 | 3 |
| **노경천** | 리포트 · 끝난 상태 | 발행 · 무효 · 응시완료 · 중단 | 6 |

### 🔴 절대 하지 말 것

| | 왜 |
|---|---|
| **남의 담당 계정 쓰기** | 계정은 **한 번 쓰면 되돌아오지 않는다.** 남이 볼 것을 없앤다 |
| **`이해도 확인 시작하기` 함부로 누르기** | 60분 시계가 돌기 시작하고 **취소가 없다** |
| 같은 계정으로 세션 두 번 | 처음 상태로 안 돌아온다 |

**세션 화면(`/trainee/session`)은 들어가기만 해도** 시간이 지난 문제를 서버가 닫는다.
구경만 하려고 들어가지 않는다.

### 지금 고장 나 있는 것 — 이건 버그가 아니다

발견하면 **다시 적지 않아도 된다.** 이미 백엔드에 요청했다.

| 무엇 | 증상 |
|---|---|
| **답변 제출** | 90초 뒤 *"답변을 보내지 못했어요"* — 서버가 채점을 못 한다 |
| **ZIP 제출** | *"파일을 저장하는 중 문제가 생겼어요"* — 서버 저장 실패 |
| **다시 보기 힌트** | 다시 보기에는 힌트가 안 나온다(정책 변경 요청 중) |

### 이상하면 이렇게 적는다

무엇이 잘못인지 몰라도 된다. **아래 중 하나라도 걸리면 그대로 적는다.**

```
계정        s016@algohouse.io
어디서      홈 → 이해도 확인 시작하기
기대        시작 전 안내가 뜬다
실제        빈 화면
```

| 걸리는 것 | 예 |
|---|---|
| 두 화면이 같은 것을 다르게 말한다 | 홈은 "미응시"인데 리포트는 "발행 전" |
| 숫자가 안 맞는다 | "3군데"라는데 문제가 2개 |
| 눌렀는데 아무 일도 없다 | 버튼을 눌러도 화면 그대로 |
| 글자가 잘리거나 겹친다 | 창을 좁히면 특히 |
| 문장이 스스로 부딪힌다 | "기다려 주세요"라면서 버튼은 눌린다 |
| 10초 넘게 도는 화면 | |

> **첫 접속이 20초쯤 걸리는 것은 정상이다.** 서버가 자다 깨느라 그렇다.

## 1. 강민수 — 제출 전 (계정 22개)

**학생이 아직 코드를 안 낸 구간.** 홈 카드 2종과 제출 화면 전부.

### ① 미응시 계정 (20개)

`미응시`에서 아무 계정이나 골라 로그인 → **홈**

**이렇게 보여야 한다**

```
진행바   [코드 제출]→ 코드 분석 → 이해도 확인 → 리포트     ← 첫 칸이 강조
제목     코드를 제출할 차례예요
남은시간  3일 3시간 남음 · 제출 마감 08-21 23:59
버튼     코드 제출  (눌린다)
```

**볼 것**

1. **진행바 첫 칸만 강조**돼 있나 (나머지는 흐리게)
2. 남은 시간이 **제출 마감**을 가리키나 (응시 마감이 아니라)
3. `코드 제출` → 제출 화면으로 가나
4. 제출 화면에 **`GitHub 저장소` / `ZIP 업로드` 탭 둘**이 있나

### ② GitHub 제출 — 지금 유일하게 되는 경로

`GitHub 저장소` 탭에서:

| 넣는 것 | 눌러야 할 것 | 이렇게 나와야 한다 |
|---|---|---|
| `https://github.com/Team-IZ/Backend` | 주소 확인 | ✅ `Team-IZ/Backend 확인했어요` |
| `https://github.com/없는계정/없는저장소` | 주소 확인 | 🔴 `저장소 주소 형식이 올바르지 않습니다` |
| 빈 칸 | — | `제출` 버튼이 **안 눌려야** 한다 |

주소를 고치면 **`확인했어요`가 사라져야 한다**(옛 주소 결과가 남으면 안 된다).

**제출까지 누르면** 홈이 `코드 분석이 진행 중이에요`로 바뀐다. **계정 하나가 소모된다** —
20개 중 2~3개만 쓴다.

### ③ ZIP 제출 — 실패를 확인하는 자리

`ZIP 업로드` 탭에서:

| 올리는 것 | 이렇게 나와야 한다 |
|---|---|
| 정상 zip 파일 | 🔴 `파일을 저장하는 중 문제가 생겼어요` (서버 문제, 알려진 것) |
| **50MB 넘는 파일** | 올리기 **전에** 막혀야 한다 |
| zip이 아닌 파일(.txt 등) | `압축 파일을 열지 못했어요. 다시 압축해서 올려 주세요` |

**중요** — 실패 문구가 **두 종류로 갈리는지**를 본다. 다 똑같이 나오면 잘못된 것이다.

### ④ 분석 실패 계정 (2개)

`분석실패`에서 골라 로그인 → **홈**

```
제목     코드를 분석하지 못했어요
배지     분석 실패
안내     제출한 코드를 분석하지 못했어요. 제출 화면에서 이유를 확인할 수 있어요.
        고쳐서 다시 제출하면 분석이 다시 시작돼요.
버튼     다시 제출  (눌린다)
```

**볼 것** — 제출 화면에 **실패 사유**와 **내가 낸 코드**가 함께 보이나. 사유 없이
"실패했어요"만 있으면 적는다.

## 2. 손진원 — 응시 시작 (계정 4개)

**🔴 가장 조심해야 하는 구간이다.** 시작 버튼을 누르면 되돌릴 수 없다.

### ① 홈 카드 먼저 (누르지 말고)

`분석완료`에서 골라 로그인 → **홈**

```
진행바   코드 제출 → 코드 분석 → [이해도 확인] → 리포트   ← 세 번째 칸 강조
제목     이해도 확인을 시작할 차례예요
안내     내가 쓴 코드 2군데에 대해 왜 그렇게 했는지 이야기하는 시간이에요.
        문제마다 20분, 전체 1시간까지 쓸 수 있어요.
        점수는 표시되지 않아요. 모르면 다시 설명해 달라고 할 수 있고, 불이익이 없어요.
남은시간  155:23:30 남음 · 08-25 08:00까지
보조      늦어도 21:36까지 끝나요
버튼     이해도 확인 시작하기
```

**볼 것 — 여기가 핵심이다**

1. **`코드 N군데`의 N이 계정마다 다른가** (2 또는 3). 항상 3이면 잘못된 것이다
2. `늦어도 HH:MM까지 끝나요`가 **지금 시각 + 1시간**과 맞나
3. 남은 시간이 **응시 마감**을 가리키나 (제출 마감이 아니라)

### ② 시작한다 — 계정 1개만

**계정 4개 중 하나만** 쓴다. 나머지는 서버가 고쳐진 뒤를 위해 남긴다.

`이해도 확인 시작하기` → 시작 전 안내 → 체크박스 → `전체화면으로 시작하기`

**이렇게 보여야 한다**

```
상단     [문제 제목] · 1 / 3 · 00:47:12 남음 · 12분 경과
왼쪽     코드 (파일 전체, 줄 번호 1부터)
        ▸ 질문이 가리키는 줄이 파랗게 강조 · 그 줄이 화면에 자동으로 보인다
        ▸ 아래 「이 코드를 부르는 곳 N곳」 (있을 때만)
오른쪽   ◆ 코드 이해
        [질문] … ↳ 파일명:48–51
        [답 입력칸] · 다시 설명해 주세요 2번 남음 · 답변 제출
```

**볼 것**

1. **줄 번호가 1부터** 시작하나 (48 같은 숫자부터면 잘못된 것)
2. **강조된 줄이 처음부터 화면에 보이나** (스크롤해서 찾아야 하면 적는다)
3. 코드 패널 제목이 **한 줄에 하나씩** 나오나 (세로로 한 글자씩 쌓이면 적는다)

### ③ 힌트 — 되돌릴 수 없다

`다시 설명해 주세요`를 **한 번만** 누른다.

| 언제 | 이렇게 되어야 한다 |
|---|---|
| 누른 직후 | 버튼이 `설명을 찾는 중`으로 바뀌고 **안 눌린다** · 코드가 흐려진다 |
| 몇 초 뒤 | `다시 설명하면` 파란 상자에 설명이 뜬다 · `1번 남음` |
| 두 번 다 쓰면 | 버튼이 사라지고 `더 이상 설명해 드릴 수 없어요` |

**새로고침해도 연 힌트가 그대로 있어야 한다.**

### ④ 답변 — 실패를 확인한다

답을 쓰고 `답변 제출`.

```
누른 직후  내 답변이 오른쪽에 뜨고 「답변을 확인하고 있어요」 · 입력 잠김
90초 뒤    🔴 답변을 보내지 못했어요. 쓰신 내용은 그대로 있으니 다시 제출해 주세요.
```

**이게 지금 정상이다**(서버 문제). 볼 것은 **쓴 내용이 그대로 남아 있는가** —
사라지면 적는다.

### ⑤ 붙여넣기가 막히나

답 입력칸에 **Ctrl+V**로 붙여넣기 → **안 들어가야 한다.** 드래그로 끌어다 놓는 것도.

## 3. 박종호 — 이탈·복귀 · 못 들어간 상태 (계정 3개)

**계정이 전체에 5개뿐**이라 가장 아껴야 한다. 대신 **가장 중요한 구간**이다 —
학생이 실수로 나갔을 때 시험을 잃느냐 마느냐다.

### ① 이어하기

`응시중` 계정으로 로그인 → **홈**

```
제목     이해도 확인이 진행 중이에요
안내     이해도 확인이 끝나지 않은 채로 남아 있어요.
버튼     이어서 하기  (눌린다)
```

**누르면** 세션 화면으로 가고 — **볼 것**

1. **몇 번 문제였는지 그대로인가** (1/3 → 다시 1/3)
2. **이미 답한 것이 남아 있나**
3. **이미 연 힌트가 그대로인가** (`1번 남음` 같은 숫자까지)
4. 시간이 **이어서 흐르나** (0분부터 다시 세면 잘못된 것)

### ② 새로고침

세션 화면에서 **F5**. 위 네 가지가 **그대로 남아 있어야 한다.**

### ③ 창을 나갔다 온다

세션 화면에서:

| 하는 것 | 이렇게 되어야 한다 |
|---|---|
| **다른 탭**으로 갔다가 5초 뒤 돌아옴 | 까만 토스트 — `N초 자리를 비웠어요` |
| **다른 앱**(메모장 등)으로 갔다가 돌아옴 | 같은 토스트가 떠야 한다 |
| 1초 안에 갔다 옴 | 토스트가 **안 떠야** 한다 |

> ⚠️ **다른 앱 전환은 아직 사람이 확인해 본 적이 없다.** 자동 테스트로는 확인이
> 불가능해서, **이 항목이 이번 테스트에서 가장 값진 확인이다.** 안 뜨면 꼭 적는다.

### ④ 인터넷을 끊는다

와이파이를 끄고 10초 뒤 다시 켠다.

```
끊긴 동안   화면이 어두워지고 「연결이 끊겼어요」
다시 켜면   원래대로 돌아온다 · 쓰던 답은 그대로
```

### ⑤ 20분을 넘긴다 (시간이 되면)

세션을 열어 둔 채 **20분 이상** 두면 서버가 그 문제를 닫는다.
→ 화면이 **다음 문제로 알아서 넘어가야** 한다. `문제를 불러오지 못했어요`가 뜨면 적는다.

### ⑥ 아예 못 들어가는 상태 — 창닫힘 (계정 1개)

응시 창이 닫혀 **시작조차 못 하는** 경우다. 위와 반대편이라 함께 본다.

`창 닫힘` 계정으로 로그인 → **홈**

```
제목     응시 기한이 지났어요
배지     응시 창 닫힘  (분석 실패가 함께 뜨기도 한다)
안내     응시 창은 08-14 20:40에 닫혔어요. 이번 회차는 미응시로 기록됩니다.
        사정이 있었다면 매니저에게 알려 주세요.
```

**볼 것**

1. **언제 닫혔는지**가 적혀 있나 (날짜·시각 없이 "닫혔어요"만 있으면 적는다)
2. `이해도 확인 시작하기` 버튼이 **없거나 안 눌리나** (눌리면 잘못된 것)
3. 주소창에 `/trainee/session`을 직접 쳐도 **`응시 기한이 지났어요`** 가 뜨나
   → 여기서 시작 화면이 나오면 **큰 문제다.** 꼭 적는다

## 4. 노경천 — 리포트 · 끝난 상태 (계정 6개)

앞의 셋보다 항목이 많다. **①②는 끝난 상태**(응시완료·중단), **③~⑥은 리포트**다.

### ① 끝난 상태 — 두 계정이 같아 보이는 게 정상이다

`응시완료`와 `중단` 계정으로 각각 로그인 → **홈**

```
제목     리포트를 기다리는 중이에요
안내     이해도 확인이 끝났어요. 08-13 20:40 제출됨.
        리포트는 회차 마감 후 한꺼번에 발행됩니다. 발행되면 알려드릴게요.
버튼     내 리포트  (회색 · 안 눌린다) + 옆에 「발행되면 알려드릴게요」
```

**볼 것**

1. 버튼이 **회색으로 안 눌리나** (눌리면 잘못된 것)
2. 버튼 옆에 **왜 못 누르는지**가 적혀 있나
3. 진행바가 **마지막 칸(리포트)** 을 가리키나

> ⚠️ **`응시완료`와 `중단`이 똑같이 보이는 것은 지금 정상이다.** 서버가 둘 다
> `리포트 대기`로 준다 — 다르게 보여야 한다고 생각되면 그건 버그가 아니라 **의견**으로
> 적어 달라.

### ② 끝난 계정으로 세션에 들어가 본다

주소창에 `/trainee/session`을 직접 친다.

```
이렇게 나와야 한다 →  이해도 확인을 마쳤어요
                    리포트는 회차 마감 후 한꺼번에 발행됩니다.
                    [홈으로]
```

**빈 화면이나 오류가 뜨면 적는다.**

### ③ 지난 회차 목록

홈 아래쪽 `지난 회차`에서:

1. 회차가 **최신순**인가
2. `완료`인 회차에 `리포트 보기 →`가 있나
3. `미응시`인 회차는 링크가 **없어야** 한다
4. **`리포트 보기`를 눌러 실제로 열리나** ← 최근에 고친 부분이라 꼭 본다

### ④ 리포트 화면 전체

`리포트 발행` 계정으로 로그인 → **홈**

```
제목     리포트가 나왔어요                    ← 최근에 고침
안내     개념별로 어디까지 설명했는지 확인할 수 있어요.
버튼     내 리포트  (눌린다)
```

> 예전에는 `리포트를 기다리는 중이에요`라고 하면서 버튼은 눌렸다. **문장과 버튼이
> 어긋나면** 그게 버그다 — 다른 곳에도 있는지 봐 달라.

**리포트 화면에서 볼 것**

```
왼쪽    회차 목록 (6차 · 5차 · 4차 …)
오른쪽  고른 회차의 본문
```

1. 회차를 바꾸면 **오른쪽만 바뀌나** (화면 전체가 다시 로딩되면 적는다)
2. **발행 안 된 회차**를 고르면 `아직 발행 전이에요`가 뜨나
3. 발행된 회차에 **개념마다 도달 단계**와 **교안 근거**(`교안 4장 · p.22–24`)가 있나
4. 잠긴 회차에서 **자물쇠 안내가 맨 위에 한 번만** 뜨나 (개념마다 세 번 뜨면 잘못된 것)

### ⑤ 주소를 직접 고쳐 본다

주소창의 `?round=` 뒤를 **아무 글자로 바꾸고** 새로고침.

→ **화면이 죽으면 안 된다.** 최신 회차가 열리면 정상이다.

### ⑥ 다시 보기 · 무효 응시

`다시보기` 계정이 있으면:

```
홈 제목   다시 볼 수 있는 문제가 N개 있어요
버튼      다시 보기
```

**누르면 세션이 시작된다 — 되돌릴 수 없다.** 화면 상단에 `기록에만 남아요` 배지가
있는지만 보고, **시작은 하지 않는다**(힌트 정책이 정해진 뒤에 한다).

`무효 응시` 계정으로 홈과 리포트가 **무엇이라고 말하는지** 적는다. 아직 화면 설계가
확정되지 않은 자리라, **보이는 그대로 적어 주는 것**이 필요하다.

---

## 5. 다 같이 보는 것

자기 구역 안에서 **각자** 확인한다.

| | 어떻게 |
|---|---|
| **좁은 화면** | 브라우저 창을 반으로 줄인다 → 글자가 잘리거나 겹치나 |
| **확대** | `Ctrl` + `+` 로 200% → 버튼을 누를 수 있나 |
| **뒤로가기** | 화면을 옮긴 뒤 뒤로가기 → 이상한 화면으로 가나 |
| **느린 연결** | 개발자도구 → Network → `Slow 3G` → 로딩 표시가 나오나 |

## 6. 계정이 없는 케이스

배정이 라운드로빈이라 **일부는 담당 계정이 없다.** 케이스 버튼에 `0/2`처럼 보이면
그 케이스는 내 몫이 없다는 뜻이다.

| 담당 | 없는 것 | 어떻게 |
|---|---|---|
| **노경천** | 다시보기 · 그 외 | 재배정 요청 중 — 오면 그때 본다 |

나머지 셋은 자기 구역 계정이 다 있다. **`0`으로 보이면 그 항목은 건너뛴다.**

> `그 외`는 계정이 **전체에 하나뿐**(미응시 확정)이라, 손진원이 그 화면만 한 번 봐
> 주기로 한다 — 카드 하나 확인이라 금방이다.
