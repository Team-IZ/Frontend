# SA-03 · 플랫폼 설정 — 탭 2

## 1. 한 줄

전 기관에 걸리는 **모델·단가·계정**을 관리한다.

## 2. 진입 · 이탈

**우상단 톱니.** 네비 자리를 주지 않는다 — 화면이라기보다 설정 항목이다.

## 3. 뷰

```
플랫폼 설정
[ 모델 · 단가 ] [ 슈퍼어드민 계정 ]
```

### 모델 · 단가

```
채점        고정 · claude-x         ← 전 기관 공통. 바꾸면 재캘리브레이션
질문 생성   정확도 우선 / 균형 / 비용 우선   3티어 ↔ 모델 매핑
단가        모델별 입력·출력 토큰 단가
```

**채점 모델은 플랫폼이 고정한다.** 기관이 바꿀 수 없다 — 바뀌면 점수를 비교할 수 없다.
**3티어 추상화**라 모델이 단종돼도 기관은 아무것도 하지 않는다.

**변경 시 경고:** 채점 모델을 바꾸면 **전 기관 재캘리브레이션**이 필요하고, 버전이 다른
결과끼리는 화면에서 비교를 막는다.

### 슈퍼어드민 계정

목록 · 초대 · 정지. **마지막 한 명은 정지할 수 없다.**

## 4. 데이터

티어↔모델 매핑 · 단가 · `calibration_version` · 슈퍼어드민 계정.

## 5. 액션

매핑 변경(확인 모달) · 단가 수정 · 계정 초대/정지.

## 6. 상태

| | |
|---|---|
| 채점 모델 변경 직후 | `재캘리브레이션 필요` 배너가 전 기관 화면에 걸린다 |
| 단가 미입력 | 비용 화면에 `단가 미설정`으로 표시하고 0으로 계산하지 않는다 |
