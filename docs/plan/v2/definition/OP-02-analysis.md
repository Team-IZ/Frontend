# OP-02 · 추이 — 우리가 나아지고 있나

## 1. 한 줄

**OP-01은 스냅샷, 여기는 흐름.** 회차를 걸친 변화와 기수 간 비교를 본다.

## 2. 이 화면을 세 번 다시 만든 이유 — 고유 질문이 없었다

오퍼레이터의 질문을 전부 나열하면 **대부분 다른 화면이 답한다.**

| 질문 | 답하는 화면 |
|---|---|
| 지금 회차가 정상인가 | **OP-01** 파이프라인 |
| 조치할 게 있나 | **OP-01** 조치 필요 |
| 어느 반이 처지나 | **OP-01** 반 비교 |
| 이 회차 설계가 완결됐나 | **OP-03** |
| 반별 제출·응시율 · 개념 공백 | **OP-04 현황** |
| 교안에 뭐가 있나 | **OP-06 교안** |
| 매니저 배정 | **OP-06** |
| 비용 | **OP-01 · OP-06** |

그래서 히트맵을 그려도, 발견 카드를 그려도, 반 비교표를 그려도 **다른 화면의 변형**이었다.

**18번이 정한 두 탭도 그렇다** — `위험·우수`는 MG-03과 모집단이 같고(오퍼레이터는 처리
못 한다), `히트맵`은 MG-02와 같다. **둘 다 매니저 화면의 확대판**이다.

> **답이 없던 질문은 하나** — *"우리가 나아지고 있나."* OP-01은 **지금**만 본다.

## 3. 위험자 비율은 회차가 달라도 비교된다

*"회차마다 개념이 달라 비교 불가"* 라고 계속 말했는데 **예외가 있다.**

| | 회차 간 비교 |
|---|---|
| 평균 도달 | ❌ **다른 것을 물은 값**이다 |
| **위험자 비율** | ⭕ 판정 기준(`2단 이하 개념 2개 이상`)이 **회차와 무관하게 같다** |

9-2가 개념 이름이 아니라 **개수**로 위험을 정의한 이유가 여기서도 작동한다.

**OP-01 반 비교 막대와 같은 값**이다 — 그 막대가 **이 표의 맨 오른쪽 열**이고, 클릭해서
넘어왔을 때 **숫자가 이어져야** 한다. **9-6으로 빠진 개념도 같이 빠진다**(같은 계산이어야
두 화면이 안 어긋난다).

## 4. 뷰 — 탭 2개

```
[ 회차 흐름 ] [ 기수 간 비교 ]
```

### ① 회차 흐름

```
[반별|팀] [정렬 최근 회차 높은 순 ▾] [⚠ 계속 오르는 반만]
──────────────────────────────────────────────────────────────────
 반              미프1차  미프2차  미프3차  미프4차   1차 → 최근
 기수 전체 250명   12%     16%     19%      ▨       +7p 계속 오름
                  30/250  40/250  47/250
 C반 25명 김서연   16%     24%     32%      ▨      +16p 계속 오름
 F반 25명 담당없음  16%     20%     24%      ▨       +8p 계속 오름
 G반 25명 한지민    8%      8%     12%      ▨       +4p 보합
──────────────────────────────────────────────────────────────────
⚠ 기수 전체가 세 회차 연속 올랐다 · 10개 반 전부 같은 방향
```

**가로가 흐름이고 오른쪽 열이 방향**이다. 셀 아래 **실수**를 같이 쓴다 — 비율만 쓰면
모집단이 작을 때 튄다.

### 3회차부터 방향을 말한다

2회로는 **오르는 중인지 한 번 튄 것인지** 갈리지 않는다 — 9-2가 위험을 **2회 비교**로
판정하는 것과 같은 논리다. **값은 2회차에도 보이고 화면이 해석만 미룬다.**

### 전체가 오르는 것과 한 반만 오르는 것

| | 뜻 | 목적지 |
|---|---|---|
| **전체가 오른다** | 회차가 어려워지거나 **누적 공백** — 어느 쪽인지는 회차 설계를 봐야 갈린다 | 기수 간 비교 · 회차 설계 |
| **한 반만 오른다** | **회차 난이도로 설명되지 않는다** | 매니저 배정 |

### 팀은 추세로 읽으면 안 된다

**팀은 회차마다 재편성된다**(TeamMembership이 프로젝트 종속). 가로로 읽으면 **다른
사람들의 값을 이어 붙이는 것**이다 — 팀 뷰는 *"반 안에서 어느 팀이 이번에 무너졌나"* 를
보는 것이고, 화면이 그 사실을 말한다.

**3명 팀에서 1명이면 33%** 라 비율이 크게 튄다. 실수를 같이 쓴다.

### ② 기수 간 비교 — 같은 교안 · 같은 개념만

```
[비교 6기 ▾] [같은 교안 · 같은 개념만] [정렬 나빠진 순 ▾]
──────────────────────────────────────────────────────────────
 검증 개념                              6기    7기    변화
 Graph 구성                             2.9    2.5    -0.4 나빠짐
  교안 AI_LLMOps · 4장 p.62 · 미프 3차
 HITL Trigger                          2.7    2.8    +0.1 비슷
 State 관리                              —     3.3    6기에 없던 개념
──────────────────────────────────────────────────────────────
⚠ Graph 구성이 교안을 v2로 바꾼 뒤 오히려 나빠졌다
```

**커리큘럼이 같으면 같은 것을 물은 값**이라 비교가 성립한다. 14번 61줄이 근거다 —
*"평소엔 개인, **기수 끝나면 수업(다음 기수 개선)**"*.

| | |
|---|---|
| **여기서는 평균 도달을 쓴다** | 같은 개념이므로 비교 가능하다 — 회차 흐름과 값이 다른 이유 |
| **회차가 달라도 된다** | 6기 미프 2차와 7기 미프 3차에서 같은 개념을 물었다면 **개념끼리** 비교한다 |
| **교안 버전을 함께 쓴다** | *"교안을 고친 것이 효과가 있었나"* 가 이 표의 핵심 질문이고 버전이 없으면 답할 수 없다 |
| **새 개념은 비교 대상이 아니라고 말한다** | 빈칸으로 두면 *"0점"* 이나 *"나빠졌다"* 로 읽힌다 |

**다른 기관 평균을 만들지 않는다** — 커리큘럼이 다른 값이다. 기수가 하나면 이 탭은
빈 상태를 보여준다.

## 5. 데이터

**회차 흐름** — 회차별 위험자 수/모집단(기수·반·팀) · 9-6 제외 반영 · 담당 매니저 ·
1차→최근 변화폭.

**기수 간 비교** — 같은 교안·같은 개념의 **평균 도달**(양 기수) · 교안 버전 ·
그 개념이 쓰인 회차 · 집단 미달 반 수.
