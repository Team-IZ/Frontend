비밀번호 재설정

v1 그대로다. 요청 → 설정 2단계, 계정 존재 비노출, 성공 시 전 세션 무효화가 전부 유지된다.

  • 요청 결과는 계정 유무와 무관하게 같은 문구다. 다르게 답하면 어떤 이메일이 가입돼 있는지 알려주는 셈이 된다.
  • 미활성 계정은 재설정이 아니라 활성화로 보낸다(AU-02). 아직 비밀번호가 없는 계정이라 재설정할 것이 없다.
  • 변경에 성공하면 다른 기기에서 로그아웃된다는 것을 먼저 알린다 — 되돌릴 수 없는 것은 되돌릴 수 없다고 쓴다.
