파생 상태 계약 (연계 FR 없음 — 인접 FR에서 파생)

SC-T01은 직접 명세 case가 없다(게이트 A는 MEAS·GOV-03 소관). 히어로 CTA는 이 표의 "지금" 상태 하나에 묶인다. 활성 회차가 여럿이어도 히어로는 항상 1개(가장 급한 것), 나머지는 목록 배지로.

#상태표현히어로 CTA / 다음 행동위 화면
H-1진행/예정 회차 없음휴지휴지 히어로 "지금 할 일이 없어요" + 다음 예정✔
H-2커밋 이메일 미검증warning상단 배너 + [지금 인증] (AUTH-07)✔ (H-6)
H-3미제출 · 기한 내info히어로 CTA [코드 제출하기] (→T02)✔
H-4응시 기한 임박(D-1/당일)warning마감 라인만 경고색(평소 차분)✔ (H-6/H-7)
H-5응시 기한 마감-마감 히어로 · 제출 불가(재응시 없음)✔
H-6제출 완료 · 세션 대기info히어로 CTA [검증 세션 시작하기] (→T04)✔
H-7세션 진행 중warning히어로 CTA [세션 이어하기] · 저장 지점 안내✔
H-8회차 완료 · 결과 공개info지난 회차 [결과 보기] (→T05)✔ (목록)
H-9회차 완료 · 결과 비공개잠금"결과가 아직 공개되지 않았어요" (GOV-03)✔ (H-1)
H-10분석 진행 중(제출 후)info대기 히어로 비활성 "분석 중 · 준비되면 알림"✔
H-11분석 실패(제출 후)warning히어로 CTA [확인하러 가기] → T02 S8 (스피너 영구 정지 차단)✔
