# SC-S01 · 슈퍼어드민 플랫폼 콘솔

> 소스: 기능명세서 v8 SYS-01(기관 계정·사용량 관리). 매니저 관리·슈퍼어드민 온보딩·기관 상태·콘솔 IA는 **명세 공백을 B2B 관점에서 설계**(D12·D15).
> 배치: P0 · 진입 순서 3번. 슈퍼어드민이 시스템을 부트스트랩하는 화면(기관·매니저가 여기서 생성).

| 항목 | 내용 |

| 진입 경로 | 슈퍼어드민 로그인(SC-A01) → SC-S01 |

## 2. 목적 & UX 설계 근거 (B2B)

- **1차 객체는 기관(테넌트).** 콘솔의 모든 것이 기관에 속한다(매니저도). → **기관 중심 마스터-디테일**: 기관 목록(마스터) → 기관 상세(디테일 탭). 매니저를 플랫 목록으로 두면 "어느 기관 매니저인지" 맥락이 사라져 오운영 위험(D15).
- **부트스트랩 화면(범위 제한).** SYS-01: 기관 생성 → org_id 발급 → **첫 총괄 매니저 초대**. 슈퍼어드민의 책임은 **여기까지** — 기수 개설·명단·담당 매니저 초대·기수 배정은 총괄이 매니저 앱(SC-M02)에서(테넌트 경계·D63). 슈퍼어드민이 테넌트 내부 운영을 대신하면 경계 위반·운영 부담 전가.
- **AI 비용 가시화가 셀링 포인트.** SYS-01 비고: 기관별 월간 AI 비용(호출수·토큰·모델단가)·예산 상한 초과 경고. → 요약·기관 행·상세에 **비용을 1급 지표**로. 투자심의에서 "AI 예산 통제 가능"을 보여주는 근거.
- **슈퍼어드민은 고객 화면과 분리.** 이 콘솔은 매니저용 대시보드(SC-M01)와 별개 셸. 슈퍼어드민 온보딩(추가 계정)도 여기 내부에서(고객 SC-A02 미사용, D12).
- **읽기 밀도 + 안전한 파괴 액션.** 기관 정지·삭제는 soft-delete·보존기간(SYS-01 규칙)으로 즉시 물리삭제 차단.

## 3. 정보 구조 & 레이아웃 (데스크톱 콘솔)

**콘솔 셸:** 상단 바(RealiZe 플랫폼 콘솔 · 슈퍼어드민 신원·로그아웃) + 좌측 네비(**기관** / 슈퍼어드민 관리 / 설정). 콘솔 셸은 매니저 대시보드(SC-M01)와 **별도 셸**.

**뷰 1 — 기관 목록(마스터, 기본):**
- 상단 **요약 지표 행**: 총 기관 · 총 교육생(활성 세션 보조 표기) · 이번 달 AI 비용(예산 대비) · 저장량
- **기관 목록 테이블**: 기관명 · **기수 수** · 매니저 수 · 교육생 수 · 이번 달 AI 비용 · 상태(활성/정지/**예산 초과**) · 생성일 (기수 관리는 매니저 SC-M02 몫, 여기선 지표만)
- 상단 **검색(기관명)·상태 필터** 툴바. 신규·무매니저 기관은 **"총괄 매니저 미배정"** 경고 행.
- 우상단 **[+ 기관 생성]** 버튼 → **모달**(기관명 실시간 중복 확인 + 보존기간). **매니저 초대는 생성과 분리**(D63) — 생성 후 상세에서 첫 **총괄 매니저** 초대. 작은 인라인 폼을 화면에 상주시키지 않음. (요금제/플랜은 v1 미포함 — 과금 후속.)

**뷰 2 — 기관 상세(디테일, 행 클릭):** 브레드크럼(기관 목록 › {기관명}) + **4탭 전부 구성**
- **① 개요**: 핵심 지표(기수·교육생·AI비용·저장량) + 정보 행(org_id·상태·생성일·매니저 수·보존기간·공개 범위 기본값). 기관 한 장 요약.
- **② 총괄 매니저**: 슈퍼어드민은 **총괄 매니저만** 다룬다. **[+ 총괄 매니저 초대] → 모달**(이메일만, `ORG_MANAGE` 부여 — 담당 기수 배정 없음. 총괄은 기관 전체 담당). 로스터(이름·이메일·권한·담당 기수·상태)는 **지원용 읽기전용 조회**. **담당 매니저 초대·기수 배정·정지는 총괄이 매니저 앱(SC-M02)에서** — 슈퍼어드민 아님(테넌트 경계·D63). 슈퍼어드민의 유일 매니저 액션 = 총괄 지정/복구(부트스트랩·총괄 이탈 시 복구). 계정 soft-delete·과거 기수 이름 보존(D16).
- **③ 사용량·AI 비용**: **저장량 구성**(코드 제출물·세션 대화 전문 로그·채점 근거·리포트/export PDF 분해) + 사용 규모(교육생·세션·채점 회차·리포트) + **AI 비용 모델별 표**(채점 ENG-01·세션 MEAS-06·요약 RPT/INTV-02: 호출·토큰·비용) + 예산 대비 바. 기간 필터.
- **④ 설정**: 기관 상태(활성/정지)·AI 월 예산 상한·데이터 보존기간·신규 기수 공개 범위 기본값 + **위험존 기관 삭제**(soft-delete).

**입력은 모달로.** 기관 생성·매니저 초대는 화면에 작은 폼을 상주시키지 않고 버튼→모달 오버레이(딤 배경). 콘솔 밀도를 해치지 않음.
반응형: 웹 기준. 콘솔은 데스크톱 우선(운영 도구), 모바일은 목록 열람 수준으로 축소(옵션).

## 7. 인터랙션 & 화면 전이

- 로그인(SC-A01, role=SUPER_ADMIN) → **SC-S01**.
- 기관 행 클릭 → 기관 상세 뷰(콘솔 셸 유지, 브레드크럼).
- 기관 생성 성공 → 목록 갱신 + 해당 매니저에게 초대 메일 → 매니저는 **SC-A02**로 가입.
- 매니저 초대 → 매니저 SC-A02 가입 유도.
- 슈퍼어드민 관리(네비) → 슈퍼어드민 초대(내부).
