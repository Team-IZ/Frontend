공개 범위 관리 (GOV-03)

매니저가 교육생이 결과 리포트(SC-T05)에서 볼 수 있는 범위를 정하는 화면. 회차별로 전체/요약/비공개를 설정하고(기수 기본값 + 회차별 오버라이드), 교육생 화면을 미리보기로 확인. 어느 설정이든 내부 루브릭·채점 근거·처방형 콘텐츠는 항상 제거(A6). 저장은 매니저 명시 액션·버전 기록(자동확정 금지 GOV-02).

⚠️ 명세 이탈 (D117 한 쌍): 이전 M09는 이의 검토(GOV-01) 탭을 가졌으나 제거했다. 교육생 이의제기가 D117로 없어져 입력이 존재하지 않고, 판정(점수) 수정은 측정층 불변 원칙 위반이다. 매니저의 판정 재량은 점수 편집이 아니라 위험(M04)·개입(M07)·등급(M08) 화면에서 행사한다. GOV-01은 의식적 제외(누락 아님). 오측정 안전망 = GOV-02 인간 검토 + ENG-05 재채점 안정성.

#상태처리표현 / 다음 행동
G-1설정 미지정기수 기본=비공개회차별 설정 안 하면 기수 기본값(비공개) 적용
G-2허용 안 된 범위값저장 차단전체/요약/비공개 값만 허용
G-3기수 관리 권한 없음변경 차단담당 아님 시 설정 변경 불가(RBAC·SYS-02)
G-4처방형 콘텐츠 탐지콘텐츠 제거공개 데이터에서 처방형 콘텐츠 제거(A6)
G-5내부 루브릭·채점 근거 탐지제거·재검증공개 데이터에서 제거 후 재검증(A6)
G-6설정 저장 실패기존 유지실패 시 마지막 확정 설정 유지
G-7설정 변경 중 교육생 조회확정 버전 응답마지막 확정 설정 버전 기준 응답(중간 상태 노출 안 함)
G-8비공개에서 공개 요청응답 차단비공개 회차는 공개 요청 거부(T05 잠금)
GOV-02 · 자동확정 금지 (공개 설정 확정에 적용 · 전역 계약)
